# 生命个体 — 综述

> - 设计状态：待讨论
> - 适用范围：身体、生理、生命周期及子模块划分

## 目标与边界

定义单个生命体的身体、生理和生命周期，以及这些过程与环境、遗传和心智的关系。

## 拟定子模块

| 子模块 | 待讨论内容 |
| --- | --- |
| 身体结构 | 部位、功能、结构差异与能力 |
| 生理过程 | 能量、营养、体温、健康与损伤 |
| 生命周期 | 出生、成长、繁殖、衰老和死亡 |
| 身体内在状态 | 具有世界机制含义的身体需求和个体差异；与主观情绪、偏好及信念的接口 |
