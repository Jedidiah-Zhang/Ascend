# 世界框架 — 综述

> - 设计状态：讨论中
> - 适用范围：世界基础语义与环境机制的职责划分
> - 上级：[世界](../综述.md)

## 目标与边界

定义世界的空间、时间、存在物与演化规律，以及地形、天气、生态、物质等环境过程。每个子模块同时负责自身的设计与实现说明。

世界结构和具体模型重新讨论，不由既有代码决定。各模块记录通用能力、参数和接口，具体使用方式由调用方配置。

## 设计进度与待决依赖

空间和时间基础可供后续模块参考，具体接口和数值配置仍有缺口；当前优先收束整体架构，状态与实体暂停推进。机制演化、随机与数值需共同细化状态读写及求值契约；环境模块尚未开始新方案设计。
