# 世界框架 — 综述

> - 设计状态：讨论中
> - 适用范围：世界基础语义与环境机制的职责划分
> - 上级：[世界](../综述.md)

## 目标与边界

定义世界的空间、时间、存在物与演化规律，以及地形、天气、生态、物质等环境过程。每个子模块同时负责自身的设计与实现说明。

世界结构和具体模型重新讨论，不由既有代码决定。各模块记录通用能力、参数和接口，具体使用方式由调用方配置。

## 设计进度与待决依赖

空间和时间基础可供后续模块参考，具体接口和数值表示仍有缺口。两模块各自声明公开量与方法并提供实现，声明接入边界见各自设计第 4 节；世界基础固定步长由 [TIME-03](时间系统/设计.md#time-03-固定本地步长与步内阶段)维护。当前这两个模块只讨论自身行为、实现及相互联动；位置量化、时钟数值、调度和连接接口在两模块内细化，不以其他待设计模块的方案为前提。

状态与实体暂停推进；其余模块继续保留待讨论议题，尚未形成的新方案不写入时间与空间的基础契约。
