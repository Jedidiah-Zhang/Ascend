# 空间系统 — 设计

> - 设计状态：基础确定
> - 适用范围：二维空间实例、位置、范围、层序与几何接口
> - 已确定范围：矩形欧氏空间、同层不重叠、全域计算、米制非负位置及有限精度
> - 尚未覆盖：轴向、动态尺寸、连接映射、量化规则；位置精度暂按 0.001 米
> - 上级：[世界框架](../综述.md) · [实现](实现.md)

## 1. 目标与职责

定义状态所在的位置、空间覆盖范围和几何关系，为定位、查询和连接提供基础。具体作用机制自行维护通行、碰撞、传输和边界效果。

本模块不保存所有环境量，不替作用机制决定越界后的反弹或出流。时间推进引用[时间系统](../时间系统/设计.md)，环境场取值与实体占用由相应状态和机制设计。

## 2. 概念与术语

| 概念 | 含义 |
| --- | --- |
| 空间实例 | 有身份、绝对位置、层序和矩形范围的二维欧氏空间 |
| 层序 | 空间上下关系的有序标识，不是连续第三维坐标或物理高度 |
| 绝对／局部位置 | 在统一平面参照中的位置／在所属空间内的位置 |
| 范围内／可通行 | 几何上存在合法位置／具体实体可以到达，两者不同 |
| 位置精度 | 权威位置状态可区分的最小刻度，不只是显示位数 |
| 环境分辨率 | 一份环境状态代表的采样点或区域大小，不等于位置精度 |

## 3. 已确认规则

### SPACE-01 空间结构与层序

采用有界二维矩形欧氏空间，大小在实例化时配置。洞穴等不规则活动区域由内部不可通行区域表达；不可通行区域仍可具有状态。

空间具有稳定区分其归属的身份、绝对位置和层序。同层空间范围不能重叠，异层可有相同水平范围；重叠本身不建立连通或跨层作用。层序不自动赋予实际高度差。

### SPACE-02 全域计算与读取分离

每个详细运行的空间实例是完整计算单位，空间范围等于计算范围，不在内部另设移动计算窗口。需演化的状态按各机制周期推进，不要求所有机制每个时间步都更新。

观测与渲染读取不决定演化覆盖范围。生成、加载和演化是不同操作，加载不补齐未计算的历史。分块和索引不能使未读取区域漏掉应有更新。

### SPACE-03 位置与合法范围

一个坐标单位对应一米，位置允许小数，不必对齐地块中心。绝对与局部位置均非负，空间原点在矩形一角；轴向尚未决定。位移、速度等方向量可有负分量。

有效位置范围左闭右开：局部位置满足 `0 <= x < W`、`0 <= y < H`。上界仍可作为几何边界描述，但不是可直接读取的内部位置。实体中心在范围内不自动保证整个占用形状在范围内，具体占用规则待设计。

### SPACE-04 有限精度与运动

精度约束位置状态本身，不只影响显示。中间计算与写入分开，在明确的位置写入点量化；具体舍入、校验顺序及超精度输入处理未定。

一次更新可不移动，非零空间内位置变化不得小于一个位置刻度；不引入亚刻度位移累计。运动周期和位移规则须与这一约束相容。

位置精度不自动决定环境格网、速度、时间或中间算术的精度；有限精度本身也不单独保证全部计算确定。

**暂定参数**：位置精度为 `0.001 米`。数值实现和移动规则确定前复核该值，不能据此认定毫米格网或整数毫米存储已获确认。

### SPACE-05 边界与跨空间访问

空间只声明边界，拒绝直接访问范围外位置，不自动夹取、环绕或读取相邻空间。各机制定义自身的阻挡、出流、传热等效果。

跨空间访问需显式定位到合法目标。连接两端的几何映射和允许作用分别定义；时间上的交接边界由时间模块维护。

## 4. 对外契约

下表为**候选接口分解**，行为须满足 SPACE-01～05，字段及签名未定。

| 能力 | 输入与输出方向 | 已定边界／未定部分 |
| --- | --- | --- |
| 空间注册 | 身份、层序、绝对位置、尺寸 → 空间描述 | 同层不重叠；范围变更和校验错误表示未定 |
| 位置定位 | 层序＋绝对位置 → 归属空间或未定位 | 不隐式生成空间；定位算法未定 |
| 坐标转换 | 空间与位置 → 局部／绝对位置 | 非负和左闭右开；轴对齐及映射细节未定 |
| 几何查询 | 点、形状或路径 → 包含、相交或边界位置 | 仅给几何事实，不决定实际通行 |
| 连接描述 | 两端空间、端点或区域 → 几何连接 | 传输类型、开关和耗时归作用机制 |

批量定位与校验为候选能力。环境读取接口由状态及各场模块负责，不在空间中提供会隐藏推进或修改状态的通用取值入口。

## 5. 配置与边界情况

| 项目 | 状态 | 约束／说明 |
| --- | --- | --- |
| 实例尺寸 | 已确认可配置 | 实例化后能否调整未定 |
| 层序与绝对位置 | 已确认具备 | 编号、轴向和运行中调整未定 |
| 坐标单位 | 已确认 | 米 |
| 位置精度 | 暂定 | 0.001 米，复核条件见 SPACE-04 |
| 范围端点 | 已确认 | 左闭右开，越界访问拒绝 |
| 环境格网 | 候选 | 与位置精度分开，具体分辨率未定 |

量化后的边界落点、形状跨界和连接出口位置需共同设计，不能用默认夹取掩盖非法访问。空间内不要求一格一实体；身体占用与环境采样是不同议题。

## 6. 取舍与候选方案

矩形和全域计算使范围判定与演化覆盖清楚；不可通行区承担内部不规则形状。小数位置支持地块内部定位，避免把身体尺寸和环境格网绑定。

**候选几何约定**：全局轴对齐，左下角原点，`x` 向右、`y` 向上；局部／绝对位置只做平移。覆盖范围为 `[ox, ox + W) × [oy, oy + H)`，同层可边缘相接而无共同内部位置。跨空间距离和可达性不只由平面距离或层序差决定。以上轴向与映射尚未确认。

**环境场的关联候选**：规则格网可以保存温度、含水量等有限精度数值，并按场语义插值；类别、身份不做无意义混合。插值不增加真实细节，也不自动保证守恒。边缘采样须由场声明规则，不能直接越界；需要依赖追踪的取样应能对应底层值和权重。可解析场可由有限参数求值，有局部历史的场仍需保存相应状态。具体选择由状态及环境模块确定。

数值存储与空间索引候选见[实现方案](实现.md#2-实现方案)。

## 7. 验收标准

以下为已确认规则的验收场景，尚无新实现证据。

| 依据 | 条件与操作 | 预期 |
| --- | --- | --- |
| SPACE-01 | 创建同层重叠及异层重叠空间 | 前者不合法，后者可区分归属且不自动连通 |
| SPACE-02 | 固定初态、计算配置和输入，改变只读范围 | 满足确定性契约的运行组合中轨迹不变；各处按计划更新 |
| SPACE-03、05 | 查询零点、上界及范围外位置 | 零点属于内部；上界及越界访问拒绝，不自动换空间 |
| SPACE-04 | 写入并保存恢复位置 | 符合届时确认的精度与舍入规则 |
| SPACE-04 | 更新实体位置 | 不依赖隐藏的亚刻度运动累计，非零变化至少一个刻度 |

动态范围、连接映射及量化临界值的具体判据在相应规则确认后补齐。
