# 空间系统 — 设计

> - 设计状态：基础确定
> - 适用范围：二维空间实例、位置、范围、层序与几何接口
> - 已确定范围：矩形欧氏空间、同层不重叠、全域计算、米制非负位置及有限精度
> - 尚未覆盖：轴向、动态尺寸、连接映射、量化规则；位置精度暂按 0.001 米
> - 上级：[世界框架](../综述.md) · [实现](实现.md)

## 1. 目标与职责

定义空间身份、覆盖范围、位置表示和几何关系，提供定位、坐标转换、范围查询与连接描述。

当前讨论范围为上述能力自身的行为、实现及与[时间系统](../时间系统/设计.md)的联动。空间负责连接两端的定位与几何关系，时间负责连接生效时的同步推进。

## 2. 概念与术语

| 概念 | 含义 |
| --- | --- |
| 空间实例 | 有身份、绝对位置、层序和矩形范围的二维欧氏空间 |
| 层序 | 空间上下关系的有序标识，不是连续第三维坐标或物理高度 |
| 绝对／局部位置 | 在统一平面参照中的位置／在所属空间内的位置 |
| 位置精度 | 权威位置状态可区分的最小刻度，不只是显示位数 |
| 连接描述 | 两端空间及其端点或区域的关联与几何映射 |

## 3. 已确认规则

### SPACE-01 空间结构与层序

采用有界二维矩形欧氏空间，大小在实例化时配置。

空间具有稳定区分其归属的身份、绝对位置和层序。同层空间范围不能重叠，异层可有相同水平范围；重叠本身不建立连通或跨层作用。层序不自动赋予实际高度差。

### SPACE-02 全域计算与读取分离

每个运行中的空间实例是完整计算单位，空间范围等于计算范围，不在内部另设移动计算窗口。该范围约束计算覆盖，不表示所有位置都必须在每个时间步执行相同计算。

只读查询的范围不决定更新覆盖范围。创建、恢复与推进是不同操作，读取或恢复空间描述不补齐未计算的历史。分块和索引不能使未读取区域漏掉应有更新。

### SPACE-03 位置与合法范围

一个坐标单位对应一米，位置允许小数。绝对与局部位置均非负，空间原点在矩形一角；轴向尚未决定。位移等方向量可有负分量。

有效位置范围左闭右开：局部位置满足 `0 <= x < W`、`0 <= y < H`。上界仍可作为几何边界描述，但不是合法的内部位置。点的包含判定与形状整体的包含判定分别处理。

### SPACE-04 有限精度与位置更新

精度约束位置状态本身。中间计算与写入分开，在明确的位置写入点量化；具体舍入、校验顺序及超精度输入处理未定。

一次更新可保持位置不变，非零空间内位置变化不得小于一个位置刻度；不引入亚刻度位移累计。位置更新须满足这一约束。

位置精度不自动决定时间或中间算术的精度；有限精度本身也不单独保证全部计算确定。

**暂定参数**：位置精度为 `0.001 米`。数值表示、量化规则及与时间步长的配合确定前复核该值，不能据此认定整数毫米存储已获确认。

### SPACE-05 边界与跨空间访问

空间声明边界，拒绝直接访问范围外位置，不自动夹取、环绕或读取相邻空间。

跨空间访问需显式定位到合法目标。连接两端的定位和几何映射由本模块定义，连接生效、同步推进与断开后的独立变速遵循[时间设计 TIME-09](../时间系统/设计.md#time-09-同步连接与时钟组合并)。几何相邻或范围重叠不自动建立连接，连接描述与生效状态的具体接口待两模块共同确定。

## 4. 对外契约

下表为**候选接口分解**，行为须满足 SPACE-01～05，字段及签名未定。

| 能力 | 输入与输出方向 | 已定边界／未定部分 |
| --- | --- | --- |
| 空间注册 | 身份、层序、绝对位置、尺寸 → 空间描述 | 同层不重叠；范围变更和校验错误表示未定 |
| 位置定位 | 层序＋绝对位置 → 归属空间或未定位 | 不隐式创建空间；定位算法未定 |
| 坐标转换 | 空间与位置 → 局部／绝对位置 | 非负和左闭右开；轴对齐及映射细节未定 |
| 几何查询 | 点、形状或路径 → 包含、相交或边界位置 | 点与形状的包含分别判断；具体签名未定 |
| 连接描述 | 两端空间、端点或区域 → 连接描述与几何映射 | 生效与断开对接时间系统，具体接口未定 |

批量定位与校验为候选能力。只读定位与几何查询不隐式推进空间或改写空间描述。

## 6. 取舍与候选方案

矩形和全域计算使范围判定与更新覆盖清楚；有限精度的小数位置支持米以下的定位。

**候选几何约定**：全局轴对齐，左下角原点，`x` 向右、`y` 向上；局部／绝对位置只做平移。覆盖范围为 `[ox, ox + W) × [oy, oy + H)`，同层可边缘相接而无共同内部位置。平面距离或层序差不自动确定连接关系。以上轴向与映射尚未确认。

数值存储与空间索引候选见[实现方案](实现.md#2-实现方案)。

## 7. 验收标准

以下为已确认规则的验收场景，尚无新实现证据。

| 依据 | 条件与操作 | 预期 |
| --- | --- | --- |
| SPACE-01 | 创建同层重叠及异层重叠空间 | 前者不合法，后者可区分归属且不自动连通 |
| SPACE-02 | 固定初始条件、输入及确定的更新计算，改变只读范围 | 更新结果不变；各处按计划更新 |
| SPACE-03、05 | 查询零点、上界及范围外位置 | 零点属于内部；上界及越界访问拒绝，不自动换空间 |
| SPACE-04 | 写入并保存恢复位置 | 符合届时确认的精度与舍入规则 |
| SPACE-04 | 更新位置 | 不依赖隐藏的亚刻度位移累计，非零变化至少一个刻度 |
| SPACE-05、TIME-09 | 创建几何相邻空间，再显式建立连接 | 相邻本身不触发同步；连接生效遵循共同下一帧和统一流速规则 |

动态范围、连接映射及量化临界值的具体判据在相应规则确认后补齐。
