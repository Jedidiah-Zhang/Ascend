## 1. 目标与意义

定义空间身份、覆盖范围、位置表示和几何关系，提供定位、坐标转换、范围查询与连接描述。空间回答事物在哪里、范围有多大；[时间系统](../时间系统/设计.md)回答何时推进。空间负责连接两端的定位与映射，时间负责连接生效时的同步；其他因果环境不因缺少空间而被拒绝接入。

## 2. 目标与验收

落地范围由[实现](实现.md#3-当前实现范围与限制)维护，验证入口见[测试](测试.md)。以下包含尚待实施的目标，量化等未定规则的验收须在决策后细化。

| 目标 | 验收条件 | 规则 |
| --- | --- | --- |
| 有界空间与层序 | 同层重叠拒绝，异层重叠可区分归属且不自动连通 | SPACE-01 |
| 全域计算与读取分离 | 固定初态、输入和确定更新，改变查询／显示范围不改变结果，所有应更新处按计划更新 | SPACE-02 |
| 位置与边界 | 零点为内部位置，上界及越界拒绝，不夹取、环绕或换到相邻空间 | SPACE-03、05 |
| 有限精度 | 写入与保存恢复遵循届时确认的量化规则，非零更新至少一个刻度，无隐藏亚刻度累计 | SPACE-04 |
| 连接与时间联动 | 相邻不触发同步；显式连接按共同下一帧生效并统一流速 | SPACE-05、TIME-09 |
| 声明接入 | 提供公开量与几何操作，分别说明接口检查范围和几何实现证据 | 第 5 节 |

## 3. 概念与术语

空间实例是具有身份、绝对位置、层序和矩形范围的二维欧氏空间。层序是上下关系的有序标识，不是连续第三维或实际高度差。绝对位置使用统一平面参照，局部位置使用所属空间参照，两者平移转换；位置精度约束权威状态的最小刻度。

连接描述关联两端空间、端点或区域及几何映射，连接是否生效由时间系统维护。

## 4. 已确认规则

### SPACE-01 空间结构与层序

空间为有界二维矩形，尺寸在实例化时配置，具有稳定区分归属的身份、绝对位置与层序。同层范围不能重叠，异层可有相同水平范围；重叠不建立连通或跨层作用，层序不自动赋予高度差。

### SPACE-02 全域计算与读取分离

每个运行中的空间是完整计算单位，空间范围等于计算范围，不设内部移动计算窗口。这约束更新覆盖，不要求所有位置每步执行相同计算。只读查询范围不决定更新覆盖，分块与索引不能使未读取区域漏掉应有更新。

创建、恢复与推进是不同操作；读取或恢复空间描述不补齐未计算历史。

### SPACE-03 位置与合法范围

一个坐标单位为一米，位置允许小数。绝对与局部位置均非负，原点位于矩形一角，轴向未定；位移等方向量可有负分量。

有效范围左闭右开：局部位置不小于零且小于对应尺寸。上界可描述几何边界，但不是内部位置；点包含与形状整体包含分别处理。

### SPACE-04 有限精度与位置更新

精度约束位置状态本身。中间计算与写入分开，在明确的写入点量化；舍入、校验顺序与超精度处理未定。更新可保持位置不变，非零变化不得小于一个刻度，不引入亚刻度位移累计。

位置精度不决定时间或中间算术精度，也不单独保证确定性。**暂定精度为 0.001 米**，在数值表示、量化及与时间步长配合确定前复核；不据此将整数毫米存储视为已确认方案。

### SPACE-05 边界与跨空间访问

拒绝直接访问范围外位置，不自动夹取、环绕或读取相邻空间。跨空间访问须显式定位到合法目标。

连接的定位与几何映射归本模块，生效、同步推进及断开后的独立变速遵循 [TIME-09](../时间系统/设计.md#time-09-同步连接与时钟组合并)。相邻或重叠不自动连接；具体接口由两模块共同确定。

### 实施基线（暂定）

下列选择可用于首版实现；复核条件成立时重新评估，不改变对应问题的待决状态。

| 项目 | 暂定选择 | 复核条件 |
| --- | --- | --- |
| 刻度与存储 | 位置与尺寸使用 1/1000 米的 64 位有符号整数刻度，无浮点位置状态 | 精度、舍入与超精度规则确定，并与时间步长共同验证 |
| 身份与层序 | 非空且不重复的字符串身份，32 位有符号层序 | 公开量类型定稿或需要跨工具链标识 |
| 创建后固定 | 尺寸、位置与层序不可变 | 动态变更及连接映射形成结论 |
| 失败表示 | 创建返回错误类别与说明，越界转换返回空 | 接入与诊断接口确定，评估统一结构化文本 |
| 查询范围 | 点包含、按层定位、局部／绝对转换 | 形状、路径及连接描述细化 |

## 5. 对外契约

### 声明接入

空间模块定义并实现公开量与几何操作，其他模块通过引用使用；通用分工见 [ENV-07、08](../../../研究平台/实验环境与声明接入/设计.md#env-07-模块声明公开量与方法)。引擎不预置空间概念，也不从名称生成计算。单位与几何含义由本模块说明，类型、形状、实例归属及方法输入输出供绑定和已支持的检查使用；空间合法性由模块代码检查，说明与接口匹配不替代几何验证。

| 操作 | 输入、结果与边界 |
| --- | --- |
| 创建 | 身份、层序、绝对位置与尺寸形成描述，创建过程检查同层不重叠；正式变更接口与错误表示待定，首版见暂定基线 |
| 定位与转换 | 按层序和绝对位置定位或报告未命中，不隐式创建；局部／绝对平移结果遵循 SPACE-03、05 |
| 几何查询 | 点、形状或路径的包含、相交及边界查询；只读查询不推进或改写描述；形状／路径接口待细化，批量查询为候选 |
| 连接描述 | 两端空间、端点／区域及映射；空间校验两端位置与映射结果，时间处理同步组生效与断开，具体接口待定 |

## 6. 边界与失败行为

位置、范围与越界规则见 SPACE-03～05。动态尺寸、位置与层序调整尚未确定；量化后的边界落点、形状跨界及连接映射目标须共同设计，不能以默认夹取掩盖非法访问。

## 7. 取舍与候选方案

矩形与全域计算使包含、边界和更新覆盖有统一依据；有限精度支持米以下定位。

- **几何候选**：全局轴对齐、左下角原点、轴向右／向上、坐标仅平移；同层可边缘相接且无共同内部位置。轴向及映射尚未确认，平面距离或层差不决定连接。
- **表示候选**：整数长度刻度便于精确比较；浮点中间计算加写入量化便于衔接几何算法。两者均须验证范围、舍入、溢出和超精度处理。张量接口的维度、类型与形状待定，二维空间不要求稠密坐标场。
- **查询候选**：按层范围索引、批量归属查询和区域相交。比较时测量实例数、批量、更新时间、内存与构建成本，不裁剪更新覆盖。
