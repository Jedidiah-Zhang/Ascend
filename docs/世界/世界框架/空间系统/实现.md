## 1. 设计依据

依据 [SPACE-01～05](设计.md#4-已确认规则) 与[暂定实施基线](设计.md#实施基线暂定)。几何与数值规则由设计维护，具体落地限制见第 3 节。

## 2. 代码结构与工程方案

世界库位于 `olam/`，采用 C++17 与 CMake，构建为静态库 `ascend_olam`，调用方链接目标为 `ascend::olam`，不依赖声明引擎、Qt、Godot、Python 或第三方运行库。公共头文件为 [space.hpp](../../../../olam/include/olam/space.hpp)，实现为 [space.cpp](../../../../olam/src/space.cpp)，命名空间为 `olam`；测试位于 `testbench/olam/`。

`SpaceDescription` 汇总身份、层序、绝对原点与尺寸，登记时一次校验。`Space` 是登记后的只读空间，提供身份、层序、原点、尺寸、上界、点包含判定及局部与绝对位置的平移转换。`SpaceSet` 持有全部空间，按身份与层序建立索引，提供创建、查找与定位。

登记依次校验身份、尺寸、原点、上界溢出、身份唯一性及同层重叠，失败返回 `SpaceError`。索引分配失败则回滚已推送空间并重新抛出 `std::bad_alloc`，不留下部分登记。几何判定与转换遵循设计，越界或未命中返回空。

## 3. 当前实现范围与限制

已实现的范围包括：创建校验与同层不重叠、异层重叠；按身份查找、按层序与绝对位置定位；点包含（左闭右开）、局部与绝对位置转换及越界拒绝；登记顺序的只读遍历；失败不改变已有空间。测试用例见[测试文档](测试.md)。

尚未实施：形状与路径查询、批量查询、范围与位置及层序的动态变更、连接描述与几何映射、保存恢复、声明接入（ENV-07/08）与语言资源、更新覆盖与调度。

使用限制：单线程宿主接口，返回空间指针在下次 `add` 前有效；位置与尺寸使用暂定整数刻度，无浮点入口或超精度舍入；错误为默认语言原文，尚无结构化文本。没有性能测量，不作吞吐承诺。

## 4. 构建与运行入口

依赖 CMake 3.20 及支持 C++17 的编译器。在仓库根目录执行：

```bash
cmake -S olam -B build/olam -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build/olam --config Debug --parallel 4
ctest --test-dir build/olam --build-config Debug --output-on-failure
```

构建产物位于已忽略的 `build/olam/`；Visual Studio 等多配置生成器在 `build/olam/<配置>/` 下生成对应可执行文件。测试程序的用例清单与运行方式见[测试文档](测试.md)。
