## 1. 设计依据

依据设计中的 [SPACE-01～05](设计.md#4-已确认规则) 与[实施基线（暂定）](设计.md#实施基线暂定)的暂定选择。声明接入、形状与路径查询、连接描述和保存恢复尚未实施；几何语义、量化与连接细则仍由设计维护，本文不重复。

## 2. 代码结构与工程方案

世界库位于 `olam/`，采用 C++17 与 CMake，构建为静态库 `ascend_olam`，调用方链接目标为 `ascend::olam`，不依赖声明引擎、Qt、Godot、Python 或第三方运行库。公共头文件为 [space.hpp](../../../../olam/include/olam/space.hpp)，实现为 [space.cpp](../../../../olam/src/space.cpp)，命名空间为 `olam`；测试位于 `testbench/olam/`。

`SpaceDescription` 汇总身份、层序、绝对原点与尺寸，登记时一次校验。`Space` 是登记后的只读空间，提供身份、层序、原点、尺寸、上界、点包含判定及局部与绝对位置的平移转换。`SpaceSet` 持有全部空间，按身份与层序建立索引，提供创建、查找与定位。

校验顺序为身份非空、尺寸为正、原点非负、原点加尺寸不越出刻度范围、身份唯一、同层无共同内部位置。校验失败返回 `SpaceError`（类别、相关空间与说明）；索引分配失败时回滚已推送的空间并重新抛出 `std::bad_alloc`，两者都不产生部分登记。边缘相接允许，异层可以重叠。越界转换返回空，不夹取、不环绕、不换到相邻空间；定位未命中返回空，不隐式创建。

## 3. 当前实现范围与限制

已实现的范围包括：创建校验与同层不重叠、异层重叠；按身份查找、按层序与绝对位置定位；点包含（左闭右开）、局部与绝对位置转换及越界拒绝；登记顺序的只读遍历；失败不改变已有空间。验证证据见[测试文档](测试.md)。

尚未实施：形状与路径查询、批量查询、范围与位置及层序的动态变更、连接描述与几何映射、保存恢复、声明接入（ENV-07/08）与语言资源、更新覆盖与调度。

边界与限制：单线程宿主接口；返回的空间指针在下次 `add` 前有效；位置与尺寸为 1/1000 米整数刻度（暂定），没有浮点入口，超精度输入的舍入规则未定；错误说明为默认语言原文，未接入结构化文本；内存分配失败以 `std::bad_alloc` 抛出，登记路径先回滚再抛出，集合保持原状；没有性能测量，不作吞吐承诺。

## 4. 构建与运行入口

依赖 CMake 3.20 及支持 C++17 的编译器。在仓库根目录执行：

```bash
cmake -S olam -B build/work/olam -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build/work/olam --config Debug --parallel 4
ctest --test-dir build/work/olam --build-config Debug --output-on-failure
```

构建产物位于已忽略的 `build/work/olam/`；Visual Studio 等多配置生成器在 `build/work/olam/<配置>/` 下生成对应可执行文件。测试程序的用例清单与验证环境见[测试文档](测试.md)。
