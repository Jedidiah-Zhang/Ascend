# 空间系统 — 测试

> - 用例：6 项
> - 适用范围：空间创建、同层不重叠、定位、坐标转换与只读查询
> - 上级：[世界框架](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

本文记录空间系统首版实现的自动化测试用例与设计目的，不记录逐次运行结果与通过状态。用例检验创建校验、同层不重叠、按层序定位、点包含边界、局部与绝对转换，以及失败不改变集合。覆盖范围限于整数刻度、创建后固定的只读查询；形状与路径查询、连接描述、保存恢复和更新覆盖没有对应用例。用例通过时说明相应行为在当前实现与运行环境内成立，不构成完整空间的正确性证明，也没有性能结论。

## 2. 运行方式与验证环境

在仓库根目录执行：

```bash
cmake -S olam -B build/olam -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build/olam --config Debug --parallel 4
ctest --test-dir build/olam --build-config Debug --output-on-failure
```

`ascend_space_tests` 由命令行参数选择用例，CMake 把每个用例注册为一项 CTest。运行环境为 Linux x86-64：GCC 与 Clang 的 Debug／Release 构建，以及 Clang 的 AddressSanitizer＋UndefinedBehaviorSanitizer 构建。

[Olam World CI](../../../../.github/workflows/olam_world.yml)在 Linux 与 Windows 上构建并运行同一测试集（macOS 暂未纳入）；跨平台覆盖以 CI 实际运行为准。分配失败回滚不在自动化用例内：它需要替换全局分配器，跨平台维护成本高。没有性能测量。

## 3. 用例

### space.create

登记合法空间并读取身份、层序、原点、尺寸与上界；空身份、非正尺寸、负原点、原点加尺寸溢出与重复身份分别报告对应错误；失败的登记不改变集合。它验证创建校验与失败不留下部分结果。

### space.overlap

同层完全包含、相同范围、跨边界与仅一个刻度相交都被拒绝；边缘相接、对角相接与异层重叠允许登记。它验证同层不重叠按共同内部位置判定，边缘本身不占用位置。

### space.locate

零点与最后一个内部刻度可定位；上界点、层内空隙与范围外点未命中；异层重叠由层序区分归属，不跨层查找；未知层序未命中。它验证按层序定位和左闭右开边界。

### space.convert

局部与绝对位置按平移转换并往返一致；上界、负值与超出尺寸的局部输入被拒绝；边缘相接处边界点属于相邻空间，本空间不接收。它验证越界不夹取、不换到相邻空间。

### space.bounds

单刻度空间的点包含与局部包含判定；接近刻度上限的空间仍可登记，上界紧邻最后一个合法位置且不溢出。它验证包含边界和刻度范围校验。

### space.readonly

查询、未命中定位与失败的登记都不改变集合内容与登记顺序。它验证首版只读查询不产生副作用。
