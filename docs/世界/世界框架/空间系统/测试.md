# 空间系统 — 测试

> - 适用范围：空间创建、同层不重叠、定位、转换与只读查询
> - 上级：[世界框架](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

验证整数刻度、创建后固定的空间查询、失败不改变集合，以及声明接入的公开量、方法、状态契约与模块包。形状／路径查询、连接、模块状态以外的文件级持久化及更新覆盖尚无对应用例；查询无副作用不等于已验证全域调度。测试通过只说明当前实现与环境下的对应行为，不构成完整空间正确性证明或性能结论。

## 2. 运行方式与验证环境

构建与整套 CTest 命令见[实现](实现.md#4-构建与运行入口)。程序为 `build/olam/tests/ascend_space_tests` 与 `ascend_space_module_tests`，参数选择用例，多配置生成器加配置子目录；注册清单见 [CMakeLists.txt](../../../../testbench/olam/CMakeLists.txt)，具体输入与断言见 [test_space.cpp](../../../../testbench/olam/test_space.cpp) 与 [test_space_module.cpp](../../../../testbench/olam/test_space_module.cpp)。

开发环境为 Linux x86-64，使用 GCC／Clang 的 Debug／Release 及 Clang AddressSanitizer＋UndefinedBehaviorSanitizer 构建。[CI](../../../../.github/workflows/olam_world.yml) 覆盖 Linux、Windows 与 macOS；跨平台通过情况以实际运行为准。

## 3. 用例

| 用例 | 关键保证与验证目的 |
| --- | --- |
| `space.create` | 合法描述可登记，空身份、非正尺寸、负原点、上界溢出及重复身份分别拒绝，失败不部分登记 |
| `space.overlap` | 同层有共同内部位置即拒绝（含一个刻度相交）；边缘／对角相接和异层重叠允许 |
| `space.locate` | 按层序区分归属，零点与最后内部刻度命中；上界、空隙、范围外及未知层不命中 |
| `space.convert` | 局部／绝对平移往返一致，非法位置不夹取、不换到相邻空间 |
| `space.bounds` | 单刻度与接近整数上限的包含判断正确，上界计算不溢出 |
| `space.readonly` | 查询、未命中与失败登记不改变集合内容及顺序 |
| `space_module.values` | 默认单空间与空 `spaces` 集合的计数、首空间字段及空集合哨兵值正确 |
| `space_module.queries` | 多空间集合按层与绝对位置定位、包含与局部坐标，越界和跨层未命中返回 `-1` |
| `space_module.state` | 状态契约保存 `spaces` 数组，恢复后查询一致；缺字段、错误类型、重复身份、同层重叠与负原点均报告 `invalid_state` 且不替换集合 |
| `space_module.config_errors` | 非对象配置、未知字段、错误字段类型、非法尺寸、负原点、上界溢出、层序越界、重复身份与同层重叠分别拒绝 |
| `space_module.package` | 清单导出、`.amod` 往返、模块库载入、资源计数、工厂空配置探测与卸载重载一致 |
| `space_module.package_tool`、`space_module.package_file` | 包工具生成的文件可由模块库载入，清单状态契约与语言资源保留 |

分配失败回滚未纳入自动化：替换全局分配器的跨平台维护成本较高。空间文件持久化与性能测量不在本切片范围；模块包文件 I/O 仅由包工具的生成与载入用例覆盖。
