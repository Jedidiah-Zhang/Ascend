# 空间系统 — 测试

> - 适用范围：空间创建、同层不重叠、定位、转换与只读查询
> - 上级：[世界框架](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

验证整数刻度、创建后固定的空间查询及失败不改变集合。形状／路径查询、连接、保存恢复及更新覆盖尚无对应用例；查询无副作用不等于已验证全域调度。测试通过只说明当前实现与环境下的对应行为，不构成完整空间正确性证明或性能结论。

## 2. 运行方式与验证环境

构建与整套 CTest 命令见[实现](实现.md#4-构建与运行入口)。程序为 `build/olam/tests/ascend_space_tests`，参数选择用例，多配置生成器加配置子目录；注册清单见 [CMakeLists.txt](../../../../testbench/olam/CMakeLists.txt)，具体输入与断言见 [test_space.cpp](../../../../testbench/olam/test_space.cpp)。

开发环境为 Linux x86-64，使用 GCC／Clang 的 Debug／Release 及 Clang AddressSanitizer＋UndefinedBehaviorSanitizer 构建。[CI](../../../../.github/workflows/olam_world.yml) 覆盖 Linux 与 Windows，macOS 未纳入；跨平台通过情况以实际运行为准。

## 3. 用例

| 用例 | 关键保证与验证目的 |
| --- | --- |
| `space.create` | 合法描述可登记，空身份、非正尺寸、负原点、上界溢出及重复身份分别拒绝，失败不部分登记 |
| `space.overlap` | 同层有共同内部位置即拒绝（含一个刻度相交）；边缘／对角相接和异层重叠允许 |
| `space.locate` | 按层序区分归属，零点与最后内部刻度命中；上界、空隙、范围外及未知层不命中 |
| `space.convert` | 局部／绝对平移往返一致，非法位置不夹取、不换到相邻空间 |
| `space.bounds` | 单刻度与接近整数上限的包含判断正确，上界计算不溢出 |
| `space.readonly` | 查询、未命中与失败登记不改变集合内容及顺序 |

分配失败回滚未纳入自动化：替换全局分配器的跨平台维护成本较高。文件 I/O 与性能测量不在本切片范围。
