# 地形与水文 — 设计

> - 设计状态：讨论中（首版切片规则已确认；水体、材质与 streaming 待建立）
> - 适用范围：空间实例化、1 米高程网格、逐格修改、精确与近似实现边界
> - 上级：[世界框架](../综述.md) · [实现](实现.md) · [测试](测试.md)

## 1. 目标与边界

地形回答空间中的固体地表是什么样：每个位置的高程、坡度，以及后续的材质与地表状态。水文回答水体如何生成与演化。二者共同构成生态、移动、建造与资源过程的底图。

首版只实现固体地表的**高程与派生坡度**，并建立空间实例化、确定性生成、逐格修改和精确性校验。水体、材质、侵蚀、河流、湖泊与分层加载不在本切片内；它们不改变本模块的场契约。

本模块使用[空间系统](../空间系统/设计.md)的有界二维空间与毫米刻度，不重新定义空间语义。世界尺寸由调用方配置，模块不设固定尺寸上限。

## 3. 概念与术语

- **基础地形**：由生成身份、种子、参数与空间决定的确定性高程场。它不进入运行状态，可随时重建。
- **修改层**：逐格绝对高程覆盖，是运行状态的一部分。
- **有效地形**：修改覆盖优先、否则取基础地形得到的高程场。
- **地形格**：1 米 × 1 米的权威采样单元；空间位置可以是毫米，但格内没有更细的权威地形。
- **精确覆盖**：任意格查询都返回与生成身份一致的精确值；缓存与按需计算可以存在。
- **近似实现**：在声明范围内允许返回近似值的实现，仅供游戏侧使用，研究侧拒绝。

## 4. 已确认规则

### TERRAIN-01 空间实例化与 1 米网格

一个地形实例实例化一个二维空间及其规则网格：

```text
格大小 = 1 米 = 1000 空间刻度
空间宽度 = columns × 1000
空间高度 = rows × 1000
```

- `columns`、`rows` 为正整数，由配置给出；世界尺寸不写死，也不设固定格数上限。
- 空间原点与层序由配置给出；空间尺寸必须完整覆盖网格，不产生半格。
- 空间身份、同层不重叠与原点非负沿用[空间系统](../空间系统/设计.md)的创建校验。
- 空间尺寸必须是 1 米的整数倍；不足 1 米或非整数倍在创建时拒绝。
- 一个地形实例只登记自己的空间；不同地形实例之间的同层重叠不在本模块检查。世界级共享空间集合由后续装配层负责。

### TERRAIN-02 单一权威场与表示透明

世界只有一个地形定义，按位置查询。不存在“宏观地形”和“细节地形”两套语义：

- 机制、实体、观测与干预都通过按格/按位置查询访问地形。
- 分块、缓存、LOD、多分辨率求解都是内部表示或求解手段；加载与卸载、查询顺序、缓存命中不得改变世界状态或查询结果。
- 所有生成使用世界坐标与全局种子，不使用会因分块重置而产生接缝的局部随机源。
- 为性能使用粗网格或近似时，必须声明近似范围与适用机制；需要精确结果的机制不得读取近似缓存。

### TERRAIN-03 毫米位置与格级采样

空间位置使用毫米；权威地形按格定义：

```text
column = floor((absolute_x - origin_x) / 1000)
row    = floor((absolute_y - origin_y) / 1000)
```

- 格覆盖区间左闭右开；位置正好在格边界时属于下一格。
- `sample_cell(position)` 返回所在格的权威值，格内恒定；格内小数只用于定位，不表示亚格地形。
- 越界位置不命中、不夹取、不环绕、不换到相邻空间。
- 整数查询方法的越界结果使用显式缺失标记（`INT64_MIN`），不能用 `-1` 表示缺失：高程是完整 `int32` 范围，`-1` 是合法高程。
- 高程使用 32 位有符号毫米；与空间刻度同单位。
- 坡度是派生量：四邻域最大高程差，单位为毫米/米（千分比）；边界格只比较存在的邻居，单格世界坡度为 0。
- 插值采样只用于预览、渲染等派生视图，不进入世界机制。

### TERRAIN-04 确定性基础地形

基础地形由以下身份共同确定：

```text
生成器标识 + 生成器版本 + seed + 参数 + 空间原点 + 网格尺寸
```

- 相同身份与参数必须生成逐位相同的高程；不依赖浮点环境、平台字长、读取顺序或缓存状态。
- 首版采用整数分形值噪声：`octaves` 为 1～8，`feature_cells` 为第一层特征格数，后续层逐次减半；`base_elevation` 与 `amplitude` 以毫米计。
- 生成结果超出 32 位高程范围的参数在创建时拒绝。
- 基础高程统计与校验和是派生缓存，可重算；修改层不改变基础校验和。

### TERRAIN-05 逐格修改层

- 修改是**格级绝对覆盖**：设置某格高程为给定毫米值，而不是相对于基础地形的增量。
- 有效地形 = 修改覆盖优先，否则基础地形。
- 修改进入运行状态；清除修改后该格回落到基础地形。
- 修改某格会影响该格及相邻格派生坡度；坡度不单独存储为状态。
- 有效地形按“覆盖优先”合成，不是基础高程与覆盖值相加。
- 首版只支持逐格修改；区域修改、平滑、笔刷与子格编辑属于后续工具或优化。
- 配置可以携带初始修改，便于作者在装配文件中直接写出带修改的世界。

### TERRAIN-06 身份、恢复与重放

运行状态保存：

```text
生成器标识与版本、seed、参数、空间身份/原点/层序
columns、rows、格大小
校验和格数成本上限
基础高程校验和
逐格修改
```

- 基础地形不进入状态；恢复时按同一身份重建基础地形并核对校验和。
- 状态可携带校验和格数成本上限；超过上限的网格在创建或恢复时拒绝，默认 `0` 表示不限制。
- 校验和不匹配、生成器版本不匹配或参数非法时报告 `invalid_state`，不替换现有地形。
- 缓存不属于状态；缓存丢弃与重建不改变恢复结果。
- 恢复失败不产生部分地形：先构造并核对新地形，成功后才替换当前实例。

### TERRAIN-07 全量精确与实现分层

同一语义定义 `olam.terrain` 可以有多个实现：

| 实现 | 用途 | 精确性 |
| --- | --- | --- |
| `olam.terrain.full.v1` | 研究宿主、工作台 | 任意格查询精确；允许按需计算与缓存 |
| `olam.terrain.streaming.v1` | 游戏宿主（后续） | 已加载精确区与研究一致；远处可近似，须声明范围与误差 |

- “全量”指精确覆盖，不要求所有字节常驻内存；按需计算与缓存可接受，只要结果不变。
- 模块公开 `exact` 标志；研究宿主与记录核对实现标识，拒绝在需要精确值时使用近似实现。
- 实现差异不改变公开量、方法、状态契约或世界语义。

### TERRAIN-08 水体与材质边界

- 水体是独立权威层，不塞入地形材质。首版不生成海平面、河流、湖泊或海洋。
- 地形材质只表达固体地表属性；材质表、分类规则与状态参数后续作为数据层接入。
- 水体方案需要重新探索时，不改变地形的高程、网格、修改层与精确性契约。

## 5. 首版实施基线（暂定）

| 项目 | 首版选择 | 复核条件 |
| --- | --- | --- |
| 格与单位 | 1 米格；高程、位置均为毫米；高程 `int32` | 需要亚米地形或更高高程范围时 |
| 生成算法 | 整数分形值噪声，1～8 层，特征 1～1,000,000 格 | 地形质量、侵蚀与水文接入后 |
| 默认配置 | 512×512 格、seed 0、6 层、特征 128 格、基准 0、振幅 150000 毫米 | 世界尺寸与内容需求明确后 |
| 修改载体 | `Config` 对象，键为行优先格索引，值为 `{elevation}` | 修改量增大或需要二进制载体时 |
| 状态成本 | 可配置 `checksum_limit_cells`；默认 `0` 不限制 | 增量校验和或二进制状态载体 |
| 状态校验 | 基础高程 FNV-1a 校验和（63 位非负） | 需要更强身份或跨工具链指纹时 |
| 高程总和 | 64 位有符号累计；溢出时饱和并标记 | 需要精确总和时改用更宽载体 |
| 精确实现 | 按需生成 + 可重建缓存；公开 `exact=1` | 流式实现接入时 |
| 水体与材质 | 不实施 | 水体方案与材质数据确定后 |
