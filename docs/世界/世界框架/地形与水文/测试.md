# 地形与水文 — 测试

> - 适用范围：空间实例化、1 米高程、确定性生成、逐格修改、状态恢复与模块接入
> - 上级：[世界框架](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

验证地形格与毫米位置的映射、基础地形的确定性、逐格修改与派生坡度、基础校验和、状态恢复的 fail-closed 行为，以及声明模块与工作台会话的接入。水体、材质、侵蚀、河流、湖泊与 streaming 实现尚无对应用例；测试通过不构成完整地形质量或性能结论。

## 2. 运行方式与验证环境

构建与整套 CTest 命令见[实现](实现.md#4-构建与运行入口)。核心与模块程序为 `build/olam/tests/ascend_terrain_tests` 与 `ascend_terrain_module_tests`，参数选择用例，多配置生成器加配置子目录；注册清单见 [CMakeLists.txt](../../../../testbench/olam/CMakeLists.txt)，具体输入与断言见 [test_terrain.cpp](../../../../testbench/olam/test_terrain.cpp) 与 [test_terrain_module.cpp](../../../../testbench/olam/test_terrain_module.cpp)。

工作台会话用例为 `build/workbench/tests/ascend_session_tests terrain_module`，界面包用例为 `ascend_workbench_tests terrainModulePackage`。开发环境为 Linux x86-64，使用 GCC/Clang 的 Debug/Release 构建；[CI](../../../../.github/workflows/olam_world.yml) 覆盖世界库的 Linux、Windows 与 macOS，工作台用例由 [Workbench CI](../../../../.github/workflows/workbench.yml) 覆盖。跨平台通过情况以实际运行为准。

## 3. 用例

| 用例 | 关键保证与验证目的 |
| --- | --- |
| `terrain.create` | 任意列/行数创建；1 米格内毫米位置归入同一格；格边界左闭右开；原点偏移、绝对/局部格原点、行优先索引往返；越界不命中 |
| `terrain.generate` | 相同描述逐位一致；不同 seed 不同；零振幅为常数面；按需查询与物化基础高程一致；1×1、7×3、128×64 等尺寸无固定世界上限 |
| `terrain.edits` | 逐格绝对覆盖、有效/基础高程分离、覆盖与清除、相邻格影响坡度、基础统计与校验和不受修改影响 |
| `terrain.bounds` | 角落只比较存在的邻居；单格世界坡度为 0；格边界与越界行为 |
| `terrain.errors` | 宽/高非 1 米整数倍、宽/高零尺寸、格数溢出、负原点、空身份、非法层数/特征/振幅与高程范围分别拒绝；合法描述通过 |
| `terrain_module.values` | 默认、空对象与自定义配置的公开值一致；空间尺寸、参数、基础统计、校验和、修改数量、基础/修改高程和的饱和标记、成本上限与 `exact=1` |
| `terrain_module.queries` | `contains`、按绝对位置的列/行与高程查询、基础/有效高程、坡度；合法高程 `-1` 与越界缺失标记 `INT64_MIN` 可区分；逐格设置与清除；越界修改报 `execution_failed` |
| `terrain_module.state` | 状态契约保存基础校验和、成本上限与修改；恢复到同参数实例后有效高程一致，恢复到不同空间身份/原点/层序的实例时以状态为准；校验和、版本、成本上限、修改索引与结构错误报 `invalid_state` 且不替换现有地形 |
| `terrain_module.config_errors` | 非对象、未知字段、错误类型、零列/行、非法格大小/版本/种子/层数/特征/振幅、负原点、成本上限与非法修改（非对象、缺高程）分别拒绝 |
| `terrain_module.package` | 包载入、清单版本/实现/状态契约与资源、工厂默认配置、卸载与重载 |
| `terrain_module.package_tool`、`terrain_module.package_file` | 包工具生成的 `.amod` 可由模块库载入并使用默认配置实例化 |
| `terrain.preview_tool`、`terrain.preview_file` | 独立预览工具按指定尺寸与参数生成 PGM；校验 P5 头、16×12 尺寸与 16*12 像素数据长度 |
| `session.terrain_module` | 工作台会话载入包、添加实例、修改配置与初始逐格修改；观测、检查点、状态字段、逐格干预分支与重放；基础校验和不因修改改变 |
| `workbench.terrainModulePackage` | 工作台从构建目录载入生成的 `olam.terrain.amod`，检查包概要与默认配置字段；添加地形实例并卸载后恢复内置登记 |

尚未覆盖：水体与材质分类、侵蚀/河流/湖泊、streaming/LOD、区域修改、工作台配置面板创建初始 `edits`、预览工具交互与多种导出格式、大世界校验和性能与饱和边界、C ABI 插件。
