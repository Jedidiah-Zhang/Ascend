# 地形与水文 — 实现

> - 实现状态：部分实施（单层高程、坡度、逐格修改与精确校验）
> - 适用范围：空间实例化、1 米高程网格、模块适配与工作台接入
> - 上级：[世界框架](../综述.md) · [设计依据](设计.md) · [测试](测试.md)

## 1. 设计依据

依据 [TERRAIN-01～08](设计.md#4-已确认规则) 与[首版实施基线](设计.md#5-首版实施基线暂定)。本切片只实现固体地表的高程与派生坡度；水体、材质、侵蚀、河流、湖泊与 streaming 实现尚未落地。

## 2. 代码结构与工程方案

核心地形库位于 `olam/`，不依赖声明引擎、Qt、Godot 或第三方运行库：

- 公共头文件：[terrain.hpp](../../../../olam/include/olam/terrain.hpp)
- 实现：[terrain.cpp](../../../../olam/src/terrain.cpp)
- 命名空间：`olam`

核心类型：

| 类型 | 职责 |
| --- | --- |
| `TerrainDescription` | 空间描述与生成参数；创建时一次校验 |
| `TerrainParameters` | seed、octaves、feature_cells、base_elevation、amplitude |
| `Terrain` | 空间实例、按需基础高程、逐格修改、坡度、统计与校验和 |
| `TerrainError` / `validate_terrain` | 空间、网格、参数与高程范围的结构化校验 |

`Terrain` 在构造时只登记空间与网格，不物化整张高程；`base_elevation` 按格调用整数分形值噪声。`materialize_base` 供测试、预览或性能缓存使用，结果不进入状态。修改层是 `std::map<uint64_t, Elevation>`，索引为 `row * columns + column`。

声明接入是独立目标 `ascend_olam_module`，位于 `olam/module/`：

- 公共头文件：[terrain_module.hpp](../../../../olam/module/include/olam/module/terrain_module.hpp)
- 实现：[terrain_module.cpp](../../../../olam/module/src/terrain_module.cpp)
- 语言资源：[terrain.zh-CN.json](../../../../olam/module/i18n/terrain.zh-CN.json)
- 包工具：[terrain_package.cpp](../../../../olam/module/tool/terrain_package.cpp)
- 独立预览工具：[terrain_preview.cpp](../../../../olam/tool/terrain_preview.cpp)

模块定义标识 `olam.terrain`，首版实现标识 `olam.terrain.full.v1`，状态契约 `olam.terrain.state.v1`。模块实例对应一个 1 米网格空间；公开值报告网格、空间、生成参数、基础统计、修改数量与 `exact=1`；公开方法提供格查询、基础/有效高程、坡度、逐格设置与清除。

构造配置字段：

| 字段 | 默认值 | 语义 |
| --- | --- | --- |
| `id` | 实例名 | 空间身份 |
| `layer` | `0` | 空间层序 |
| `origin_x`、`origin_y` | `0` | 空间绝对原点（毫米） |
| `columns`、`rows` | `512`、`512` | 网格列数与行数；世界尺寸不写死 |
| `cell_ticks` | `1000` | 固定 1 米；其他值拒绝 |
| `seed` | `0` | 非负噪声种子 |
| `octaves` | `6` | 1～8 层 |
| `feature_cells` | `128` | 第一层特征格数，1～1,000,000 |
| `base_elevation` | `0` | 基准高程（毫米） |
| `amplitude` | `150000` | 第一层振幅（毫米） |
| `generator_version` | `1` | 必须与当前实现一致 |
| `checksum_limit_cells` | `0` | 状态校验和的格数成本上限；`0` 不限制 |
| `edits` | 空对象 | 初始逐格覆盖，键为格索引，值为 `{ "elevation": 毫米 }` |

公开值：`columns`、`rows`、`cell_ticks`、`origin_x`、`origin_y`、`width`、`height`、`layer`、`seed`、`octaves`、`feature_cells`、`base_elevation`、`amplitude`、`generator_version`、`checksum_limit_cells`、`min_elevation`、`max_elevation`、`elevation_sum`、`elevation_sum_saturated`、`base_checksum`、`edit_count`、`edit_elevation_sum`、`edit_elevation_sum_saturated`、`exact`。基础统计与校验和首次读取时计算并缓存；修改不影响它们。

公开方法：

| 方法 | 输入 | 结果 |
| --- | --- | --- |
| `contains` | 列、行 | 在网格内返回 1，否则 0 |
| `contains_position` | 绝对 x、y（毫米） | 在空间内返回 1，否则 0 |
| `cell_column`、`cell_row` | 绝对 x、y（毫米） | 所在列/行；越界返回缺失标记 `INT64_MIN` |
| `cell_base_elevation` | 列、行 | 基础高程毫米；越界返回 `INT64_MIN` |
| `elevation` | 列、行 | 有效高程毫米；越界返回 `INT64_MIN` |
| `base_elevation_at`、`elevation_at` | 绝对 x、y（毫米） | 按位置读取基础/有效高程；越界返回 `INT64_MIN` |
| `slope` | 列、行 | 四邻域最大高程差（毫米/米）；越界返回 `INT64_MIN` |
| `set_elevation` | 列、行、高程 | 设置绝对覆盖；非法格或超范围报 `execution_failed` |
| `clear_elevation` | 列、行 | 移除覆盖返回 1，无覆盖返回 0 |

状态契约保存空间身份/原点/层序、`columns`、`rows`、`cell_ticks`、生成参数、`generator_version`、`checksum_limit_cells`、`base_checksum` 与 `edits`；不保存基础高程数组。恢复时重建基础地形、核对校验和与成本上限、应用修改，成功后才替换当前实例。校验和不匹配、版本或成本上限不匹配、修改索引越界或结构错误报告 `invalid_state`。状态中的空间身份、原点与层序是权威值；恢复不要求它们与目标实例的构造配置一致（与空间模块一致）。

空配置 `null` 与空对象都使用同一份 `terrain_preset()`，避免包探针、工作台预填与运行时默认值漂移。模块包由 `ascend_olam_terrain_package` 生成 `olam.terrain.amod`；工作台宿主登记内置 `olam.terrain` 并在界面构建时把包生成到可执行文件同目录的 `modules/`。工作台内可在系统编辑器添加 `olam.terrain` 实例；首版不提供地形预览面板。

## 3. 当前实现范围与限制

已实现：

- 任意正列数/行数的 1 米网格空间实例化，不设固定世界尺寸上限；
- 整数分形基础高程，按需计算；毫米位置到格的左闭右开映射，以及按绝对位置查询列/行/高程；
- 基础高程统计、确定性校验和、饱和标记与逐格修改；
- 可配置的状态校验和格数成本上限；
- 四邻域派生坡度；
- 模块公开值/方法、状态捕获/恢复、初始修改、包生成与工作台接入；
- 研究会话中的检查点、逐格修改干预、分支与重放。

尚未实施：

- 材质表与材质分类；
- 海平面、水体、侵蚀、汇流、河流与湖泊；
- 区域修改、平滑、笔刷与子格编辑；
- streaming/LOD/分块加载与近似实现；
- 预览工具的交互界面、着色与除 PGM 外的导出格式；
- C ABI 地形插件；
- 超大地形的校验和增量计算与二进制状态载体。

使用限制：

- 格大小固定 1 米；空间尺寸必须是 1000 刻度的整数倍。
- 基础地形按需计算；`base_checksum`、`min_elevation`、`max_elevation` 与 `elevation_sum` 首次读取会遍历全网格，超大地形需等待。
- `elevation_sum` 使用 64 位有符号累计；超出范围时饱和，并由 `elevation_sum_saturated` 标记。`edit_elevation_sum` 同样饱和并由 `edit_elevation_sum_saturated` 标记。需要精确总和时改用更宽载体。
- 修改层使用 `Config` 对象；逐格修改数量增大时，状态编码与工作台字段列表会变重。
- `set_elevation` 是三参数方法；当前工作台输入推导只识别单参数方法。配置面板把对象型 `edits` 显示为只读结构，无法在界面内创建第一条覆盖：首条覆盖需通过系统文件/API 写入，之后可在状态面板干预已有覆盖；独立的逐格编辑工具待后续接入。
- 状态恢复会重建基础地形并计算校验和；这是精确性要求，缓存优化不得改变结果。`checksum_limit_cells` 可在创建与恢复时约束这项成本，默认 `0` 不限制。
- 一个地形实例只登记自己的空间；跨地形实例的同层重叠不在本模块检查，世界级共享空间集合待装配层接入。
- 预览工具输出 8 位灰度 PGM，尚未接入工作台或提供交互界面。
- 研究宿主对 `exact` 的强制核对尚未接入；当前只有 full 实现，接入 streaming 前必须在包载入或会话检查中拒绝 `exact=0`。
- 当前噪声生成器是占位骨架，地形质量与侵蚀塑形不属于本切片。

## 4. 构建与运行入口

依赖 CMake 3.20 及支持 C++17 的编译器。在仓库根目录执行：

```bash
cmake -S olam -B build/olam -DCMAKE_BUILD_TYPE=Debug -DBUILD_TESTING=ON
cmake --build build/olam --config Debug --parallel 4
ctest --test-dir build/olam --build-config Debug --output-on-failure
```

生成模块包：

```bash
build/olam/ascend_olam_terrain_package build/olam/modules olam/module/i18n/terrain.zh-CN.json
build/olam/ascend_olam_terrain_preview terrain.pgm 512 512 0 6 128 0 150000
```

预览工具默认随世界库构建；需要减小构建量时加 `-DASCEND_OLAM_BUILD_PREVIEW=OFF`。工作台子项目已关闭该目标。

工作台界面构建会把包生成到可执行文件同目录的 `modules/olam.terrain.amod`，并随语言资源复制到 `resources/olam/module/i18n/`；在「文件 → 载入模块包…」选择该文件后，可在系统编辑器中添加 `olam.terrain` 实例。工作台构建与测试入口见[工作台实现](../../../研究平台/因果建模工作台/实现.md#4-构建与运行入口)。

测试入口与覆盖限制见[测试](测试.md)。
