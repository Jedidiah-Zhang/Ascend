> - 实现状态：部分实施（基础时钟内核、声明接入与工作台包）
> - 适用范围：时间数值、单根时钟树、状态捕获／恢复与模块接入
> - 上级：[世界框架](../综述.md) · [设计依据](设计.md) · [测试](测试.md)

## 1. 设计依据

实现 [TIME-01～09](设计.md#4-已确认规则) 中可由首版数值与接口承载的部分：固定本地步长、独立时钟域、单父嵌套、暂停与恢复、相对／有效倍率、本地时间与帧读出，以及完整状态捕获。同步时钟组、跨域交付、目标／完成进度调度和步内阶段仍遵循设计中的待决边界。

## 2. 代码结构与工程方案

### 核心时间库

时间核心位于 `olam/include/olam/time.hpp` 与 `olam/src/time.cpp`，随 `ascend_olam` 构建，不依赖声明引擎、Qt 或第三方运行库。

- `TimeBase` 保存固定本地步长；构造 `ClockTree` 时必须显式给出，步长不大于零时拒绝。
- `ClockTree` 为单根、父关系创建后不变的时钟树；每个 `Clock` 保存身份、父域、本地时间、逻辑帧、相对倍率、有效倍率与暂停状态。
- 本地时间使用 64 位整数微秒；`Rate` 使用 64 位有符号有理数（分子不小于零、分母为正），登记与设置时按最大公约数规范化。
- 组合倍率按父链交叉约分后相乘，并检查乘法溢出；失败不改变任何时钟。
- 推进一个本地步只改变目标时钟；自身或任一祖先暂停时不推进；未知时钟与整数溢出也不改变状态。流速只影响调度节奏，不阻止宿主显式推进本地步。
- `ClockTree::snapshot()` 保存步长与按父先于子排列的时钟记录；`restore()` 校验步长、身份、父关系、非负进度与倍率后整体重建，失败保持原树不变。

### 声明接入与模块包

声明接入目标仍为 `ascend_olam_module`，时钟适配文件为 [time_module.hpp](../../../../olam/module/include/olam/module/time_module.hpp) 与 [time_module.cpp](../../../../olam/module/src/time_module.cpp)，语言资源为 [time.zh-CN.json](../../../../olam/module/i18n/time.zh-CN.json)。

| 项目 | 首版落地 |
| --- | --- |
| 定义／实现／状态契约 | `olam.clock`／`olam.clock.v1`／`olam.clock.state.v1` |
| 模块实例 | 单根时钟树；构造配置指定根时钟身份（缺省取实例名）、相对倍率与初始暂停状态；步长由模块固定示例提供 |
| 公开量 | `local_microseconds`、`frame`、`rate_numerator`、`rate_denominator`、`effective_numerator`、`effective_denominator`、`paused` |
| 公开方法 | `advance()`、`set_paused(paused)`、`set_rate(numerator, denominator)` |
| 状态捕获 | `id`、`local_time`、`frame`、`rate_numerator`、`rate_denominator`、`paused`；恢复逐字段校验并重新建立时钟树；步长不属于状态，由模块固定示例提供 |

模块使用固定示例步长 `1000` 微秒（1 毫秒），仅用于形成可运行的示例；它不是实例配置字段、公开量或世界默认步长。世界基础接入后，步长仍应由世界创建参数给出，普通运行与空间配置不提供覆盖入口。

[time_package.cpp](../../../../olam/module/tool/time_package.cpp) 从代码登记实例导出清单、附加语言资源并生成 `olam.clock.amod`；可选第三个参数写入 `ascend_olam_time_plugin` 的二进制。生成前通过模块库载入路径预校验，写入采用临时文件替换。工作台宿主登记 `olam.clock` 内置实现，并在界面构建时生成 `modules/olam.clock.amod`；同名动态包可覆盖内置定义。

## 3. 当前实现范围与限制

已实现：固定步长校验、单根时钟树、独立本地时间与帧、相对／有效倍率、暂停与祖先暂停、显式单步推进、倍率与时间算术溢出拒绝、完整状态捕获与恢复、模块公开接口、包清单与 `.amod` 生成、工作台载入／添加／推进。

尚未实施：

- 目标进度、完成进度、现实时间配对与调度算法；当前只提供宿主显式推进的单个本地步。
- TIME-06 跨域下一更新接收与待交付输入的保存／恢复。
- TIME-09 同步时钟组合并、断开、重新对齐，以及与空间连接的联动。
- 同一逻辑帧内父域控制与输入的处理顺序；当前控制按调用顺序立即写入，下一次推进读取。
- 运行中更换父域；首版父关系创建后固定。
- TIME-05 的步内阶段调度；该约束由环境执行结构承担，不由本时钟树自动生成。

使用限制：倍率只记录在公开值与状态中，首版 `advance` 仍按固定步长推进一个完整本地步，不按倍率折算；零倍率同样不阻止宿主显式推进。暂停时 `advance` 调用成功但不推进，调用方以帧号判断实际进展。状态契约首版无迁移规则；公开值只描述根时钟，子时钟通过核心库读取；没有性能测量，不作吞吐承诺。

## 4. 构建与运行入口

核心与声明接入随世界库构建，共用[世界库构建命令与选项](../空间系统/实现.md#4-构建与运行入口)。测试位于 `testbench/olam/`，用例入口见[测试](测试.md)。

手工生成时钟模块包：

```bash
build/olam/ascend_olam_time_package build/olam/modules olam/module/i18n/time.zh-CN.json
# 可选第三个参数：把 C ABI 插件二进制写入包内
build/olam/ascend_olam_time_package build/olam/modules olam/module/i18n/time.zh-CN.json build/olam/olam.clock.plugin.so
```

工作台界面构建生成含 `ascend_olam_time_plugin` 二进制的 `build/workbench/modules/olam.clock.amod`；在「文件 → 载入模块包…」选择后覆盖同名内置定义，系统编辑器添加 `olam.clock` 实例，选择 `clock/advance` 为推进入口，可用单参数方法 `clock/set_paused` 作为输入在每步前暂停或恢复。
