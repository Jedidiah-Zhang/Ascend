## 2. 实现方案

### 候选：整数刻度与有理数倍率

用整数保存已完成本地时间，倍率以 `p/q` 表达，`q > 0`。父子时间映射可用锚点表示：`τ_s = a_s + r_s × (τ_p - a_p)`；创建时 `a_s = 0`，变速时保存对应锚点。具体范围、舍入和溢出规则未定。

例如倍率为 `2/3` 时，三个父刻度对应两个本地刻度，但单个父刻度不一定对应完整本地刻度。可用整数交叉相乘判断到期，或保存精确分数相位；不得逐次舍弃余数使调用次数影响结果。该相位不是实体的亚毫米运动累计。

任意分母不能都对齐到一个预先固定的小公共刻度；不预设通过最小公倍数强行统一全部更新周期。

### 候选：时钟描述与控制队列

描述可包含父域身份、相对倍率、父子锚点、固定步长、完成帧号及待生效控制。单父无环树为待确认表示方案；有效倍率由关系组合，不永久改写后代的相对倍率。

控制在演化前的边界处理，暂停时仍处理恢复；队列及同刻顺序待确定。保存恢复需包含不可重建的相位与待生效控制，或保存足以精确重建它们的数据。

### 候选：执行与跨域交接

下一期限调度、固定协调批次等方案均需满足设计语义；本轮不选择算法。暂停后的恢复不能只依赖未来演化期限。接收方不得越过尚未确定交付关系的边界，具体协调规则待设计。

交接记录可包含稳定身份、来源、目的地、载荷和接收状态；一次性接收、失败处理、保存和恢复接口待状态模块讨论。

局部随机地址可按种子、域、机制和本地帧派生，避免根时刻或调度顺序改变抽样；具体地址规则由随机系统定义。阶段执行保留设计规定的版本读取，不隐式读取可变存储中的最新值。

### 候选：读出与性能

从一致边界读取时间信息，区分目标进度与完成进度。批量推进、父链有效倍率缓存及调度索引均需证明不改变已定语义；相位恢复、长父链、大量暂停域与高分母倍率应进入性能测量场景。
