# 时间系统 — 设计

> - 设计状态：基础确定
> - 适用范围：通用时钟域、空间本地更新与跨域输入的时间语义
> - 已确定范围：秒制、世界基础固定步长及声明边界、创建时的时间从属、嵌套流速、连接同钟与隔绝后独立变速、暂停恢复、接收边界及步内因果顺序
> - 尚未覆盖：精度与步长数值、调度算法、同批输入裁决及接口签名
> - 上级：[世界框架](../综述.md) · [实现](实现.md)

## 1. 目标与职责

为独立推进的空间提供可组合的时间关系，明确本地时间、更新边界、步内顺序和跨空间输入的生效时刻。

当前讨论范围为时钟创建与推进、数值表示、控制与调度、时间读出，以及与[空间系统](../空间系统/设计.md)的连接联动。对应承载方案记录在本模块的实现文档中。

## 2. 概念与术语

| 概念 | 含义 |
| --- | --- |
| 时钟域 | 具有本地时间及与参考时钟关系的计时单元 |
| 同步时钟组 | 共用一个组时钟、作为统一时间主体推进的一组空间，具有统一有效流速和更新边界 |
| 根时钟 | 协调其他时钟关系的参照，不直接作为空间本地更新计算的时间输入 |
| 本地时间 | 某时钟域内部实际经过的时长；与现实执行耗时分开 |
| 本地步长 | 世界基础规定的一次完整空间更新覆盖的本地时间间隔 |
| 逻辑帧 | 完整更新的编号与状态边界，不额外形成一套帧时钟 |
| 步内阶段 | 一次更新内部的求值依赖顺序，不自动代表额外时长 |
| 相对／有效倍率 | 相对父时钟的配置倍率／组合上游关系后相对根时钟的倍率 |
| 目标／完成进度 | 按时钟关系应到达的位置／状态实际完成演化的位置 |
| 时钟进度 | 尚未形成完整本地步的映射进度，与位置的亚刻度位移累计不同 |

## 3. 已确认规则

### TIME-01 秒制与精度

时间以秒为单位，精度在一次运行中固定。空间步长必须能被配置的时间精度精确表示。精度数值和存储类型尚未选择；时间精度与更新步长是不同概念。

### TIME-02 独立、可嵌套的时钟域

空间创建时本地时间从零开始，恢复已有空间不重置时钟。不同创建时刻的空间即使同速，本地时间也可以不同。

时间从属关系在空间创建时指定，确定其父时钟域。空间与外界完全隔绝后可以调整相对父时钟的倍率，上级变速仍按嵌套关系影响其有效流速。时间从属不等于交互连接，连接与隔绝遵循 TIME-09。

时钟关系允许嵌套。下游保留自己的相对倍率，上游变速生效后其有效流速自然联动，不逐层追加变速指令或延迟。祖先暂停会停止关联子树推进，后代不能用非零倍率绕过它。各空间仍保留自己的本地时间与完成进度。

根时钟只协调关系，空间内更新按本地时间计算；不要求从本地时刻逆推唯一根时刻。具体父关系表示及是否允许运行中改变父关系见待决问题。

### TIME-03 固定本地步长与步内阶段

本地步长由世界基础固定规定。同一套世界基础下，各次运行及所有空间均沿用该步长，运行中新建空间也不例外；步长不作为普通实验或空间实例的可调参数。加速、减速和暂停只改变推进节奏。一次完整空间更新对应一个本地时间步，具体步长数值尚未确定。

步长属于支撑世界运行的执行结构，不列入世界语义声明或自动暴露为机制可读取的全局量。世界内经过的时长与内部更新步长分别定义。改变步长属于世界基础的替换或重大修改，需要重新审视相关机制与数值行为；执行和复现所需的基础信息由运行记录维护。

统一本地步长不等于所有空间统一流速、本地时间零点或更新相位；同步连接的协调规则见 TIME-09。

一次更新可以含多个有先后依赖的求值阶段。阶段只表达步内顺序，不自动细分时间或等分步长。通用时钟域的计时能力与空间按固定步长更新的方式分开。

### TIME-04 变速、暂停与恢复

允许正流速与零流速，默认相对流速相同，根时钟也可暂停。流速变更在下一逻辑帧开始前生效，不打断当前帧。

暂停停留在边界，仍能处理控制请求；恢复不能依赖暂停时钟先完成下一帧。处理恢复请求不提前推进本地时间或执行空间更新。变速、暂停、恢复均保留本地时间与不足一步的时钟进度，不补算本地暂停期间未经过的时长。

当前不支持负流速。零流速空间参与连接、合并及待接收输入的处理顺序仍需在本模块细化。

### TIME-05 明确读取版本与因果顺序

一次更新内的计算须明确读取步开始状态还是本步前序阶段产生的新值。使用新值的计算必须等待其依赖完成；读取步开始状态则不必等待对应新值产生。同阶段只读取该阶段开始前已确定的状态，阶段内写入归属明确。

求值依赖展开后无环，不能由容器遍历或线程先后改变结果。双方互相依赖尚未产生的新值时，不能擅自将一方改为读取步开始状态。

帧边界读取不暴露中间状态，不妨碍后续阶段使用已明确依赖的中间结果。上述约束规定步内计算的先后与读取边界，不由时间步长推导具体计算内容。

### TIME-06 跨域下一更新接收

跨空间通信在接收方下一更新点生效；发送与接收边界同刻时，本次输出不进入接收方本次更新。接收帧由逻辑时间规则确定，不取决于线程执行或消息实际抵达的先后。

接收后的输入可以参与该步后续计算，不要求每个步内依赖再等待一步。待交付输入的接收边界如何记录与恢复，在本模块细化，具体表示尚未确定。

帧边界读取不暴露部分更新，但可以反映输入尚未接收或连接尚未完成切换的情况。

### TIME-07 流速与局部确定性

给定相同初始条件、参数、逐本地步输入及确定的本地更新计算，变速安排或现实执行耗时不改变按本地步比较的结果序列。根时钟、流速和现实执行耗时不作为本地更新计算的直接输入；流速只改变推进节奏。

空间在隔绝期间的相对流速及重新连接的时机可以影响连接后的输入内容与生效帧，所以仅有相同初始条件不保证后续结果一致。时钟到达目标不意味着更新已经完成，不能只修改时间值而跳过计算。

### TIME-08 时间读出

提供秒制本地时间及时间关系的读出能力，供外部与现实时间配对。配置倍率与实际执行速率分开；现实时间采样不成为本地更新计算的隐式输入。具体字段与一致性接口见下文候选。

### TIME-09 同步连接与时钟组合并

建立跨空间交互连接时，参与空间合并为同步时钟组，显式指定合并后的统一有效流速，不按空间面积或连接方向自动选取流速。参与方已有同步时钟组时，合并涵盖相应组的全部空间，连接期间保持统一流速和更新边界。

同组空间在时间推进上视为一个整体，共用组时钟，不再由各成员独立控制流速；各空间仍保留自己的身份、几何范围与已完成进度。只有空间或空间组与外界完全隔绝后，才能独立改变相对外界的时间流速。仍有交互连接时不能单独变速。

隔绝的空间或空间组再次连接外界时重新同步。隔绝不取消创建时的时间从属关系。完全隔绝按生效的跨空间连接判断；连接两端与几何映射由空间系统描述，连接登记、生效、断开及待交付输入的处理由两模块共同细化。

相位以共同的下一逻辑帧对齐：连接从该共同边界生效，此后各空间按统一步长和流速同步推进。这里的同时更新指逻辑边界一致，不要求计算在现实时间中同时执行；串行或并行执行均须保持 TIME-06 的接收语义。

各空间保留自己的本地时间零点和已完成进度，不要求本地时间数值相等。对齐不得通过改写时间跳过演化或丢弃已有不足一步的时钟进度。到达合并边界的调度、零流速参与方及嵌套父关系的处理细则仍需细化。

## 4. 对外契约

### 声明接入

时间模块负责公开时间量与方法的定义及实现，其他模块通过公开接口引用。研究接入中的声明用途与检查边界遵循 [ENV-07、08](../../../研究平台/实验环境与声明接入/设计.md#env-07-模块声明公开量与方法)。本地时间的含义与秒制单位由本模块说明，具体数据访问、推进和控制由模块代码实现。

世界语义量、外部控制与诊断读出分别确定使用范围。TIME-08 的外部读出不自动授予本地机制读取全部时间信息的能力；机制输入仍受 TIME-07 约束。步长遵循 TIME-03，队列、相位及调度数据由实现维护，保存或诊断用途不使其自动成为世界语义声明项。公开量的类型、归属和读取版本，以及方法绑定方式尚未定稿。

### 操作接口

下表整理已确认的行为语义，尚不是函数签名。未确定部分不得自行补成默认行为。

| 能力 | 输入与前提 | 结果／生效时机 | 未定或失败边界 |
| --- | --- | --- | --- |
| 创建空间时钟 | 初始参考关系、精度及所用世界基础 | 本地从零开始，沿用基础规定的步长，形成可推进时钟 | 关系结构、非法数值及错误编码 |
| 修改流速 | 目标域或同步组和新倍率；独立于外界变速须已完全隔绝 | TIME-04、09；保持时间、进度和步长，组内共同变速 | 不支持负值；同批控制顺序未定 |
| 暂停／恢复 | 目标域和控制请求 | 边界处理；暂停中可恢复 | 父子同时控制、恢复后待接收输入顺序未定 |
| 同步连接／合并 | 参与空间或时钟组、显式指定的合并后有效流速 | TIME-09；从共同下一逻辑帧起统一流速和更新边界 | 到达合并边界的调度、零流速及父关系处理细则未定 |
| 隔绝／分离 | 切断目标空间或空间组与外界的交互连接 | 完全隔绝后允许独立调整相对倍率，保留时间从属关系 | 连接登记、断开生效及待交付输入的处理细则未定 |
| 推进与交付 | 指定的时间目标和输入 | TIME-03、TIME-06；只暴露对应已完成状态 | 调度策略、发送方完成与接收边界协调未定 |
| 读取时间 | 指定时钟域 | TIME-08，不因读取推进时钟或空间 | 完成进度、目标进度等字段为候选 |

候选读出字段：域身份、本地秒数、帧号、父域身份、相对与有效倍率、暂停状态、目标与完成进度。应取自一致边界，具体一致性实现待定。

## 5. 配置与边界情况

| 配置／状态 | 已确定约束 | 未确定内容 |
| --- | --- | --- |
| 时间单位 | 秒 | 无 |
| 时间精度 | 运行内固定 | 数值、全局统一或域间配置关系 |
| 空间步长 | 世界基础固定规定；同一基础下各次运行及所有空间共用 | 具体数值及与时间精度的相容性 |
| 流速 | 可变，默认同速，可为零，不支持负值 | 倍率范围、算术表示及溢出处理 |
| 时间相位 | 变速与暂停恢复不丢失已有进度 | 精确保存或重建方式 |

位置精度和最小非零位置变化遵循空间设计；世界基础的步长定值需与位置量化共同验证，不从毫米精度推导唯一时间步长。

## 6. 取舍与候选方案

- **独立本地时间与根协调**：保留不同流速的表达，同时避免本地更新计算直接依赖外部执行速度。
- **世界基础固定步长**：各次运行沿用基础规定的更新尺度，消除跨空间交互中的多步长协调；变速只改变推进节奏。
- **连接同钟、隔绝后独立变速**：合并流速由调用方显式指定，从共同下一帧对齐更新边界；完全隔绝后才允许相对外界独立变速，避免连接双方持续进行异速、异相位交互。保留各空间的本地时间零点及时间从属关系。
- **步内依赖与时间分开**：既允许同一步中因果求值，又不把每个中间计算误当时间子步。
- **候选数值实现**：整数刻度、有理数倍率、父子锚点及精确到期比较，见[实现方案](实现.md#2-实现方案)。统一本地步长不等于选定根时钟上的公共调度刻度。
- **候选待交付输入记录**：保存来源与目标空间、接收帧及完成标记，恢复时保持交付次序与次数；具体表示见实现候选。

## 7. 验收标准

以下是已确认规则的验收场景，尚无实现验证结果。示例数字不是默认参数。

| 依据 | 条件与操作 | 预期 |
| --- | --- | --- |
| TIME-01～03 | 在同一次运行的不同创建时刻建立空间时钟，并配置不同流速 | 各自从零开始，每次完整更新增加相同的本地时长；后创建的空间也沿用统一步长 |
| TIME-03 | 使用同一套世界基础建立多次运行，改变初始条件、空间组合与流速 | 均沿用基础固定步长，普通运行和空间配置不提供步长覆盖能力 |
| TIME-02 | 相对倍率依次为 2、1/2；上游改为 4 | 下游相对倍率不改，有效倍率从 1 变为 2 |
| TIME-02、09 | 创建与外界完全隔绝的空间，指定父时钟域，并改变其相对倍率 | 时间从属保留，空间可独立调速；改变父时钟流速仍影响其有效流速 |
| TIME-04 | 有未满一步进度时暂停，再在边界恢复 | 恢复请求不额外推进时间，已有进度和步长保持 |
| TIME-02、04 | 暂停根时钟或祖先时钟，然后提交恢复控制 | 后代不能绕过暂停；控制无需等待本地时间前进 |
| TIME-02、04 | 不足一步时保存、恢复并继续推进 | 本地时间不置零，时钟进度不丢失、不重复推进 |
| TIME-04 | 本帧提出变速 | 本帧完成不受影响，下一帧开始前应用 |
| TIME-05 | 后序计算读取前序新值，改变无依赖计算的执行分组 | 依赖先完成，输出不因无关排序改变 |
| TIME-06 | 两空间同刻更新并产生输出 | 输出不进入对方本次更新，执行先后不改变接收帧 |
| TIME-07 | 固定初始条件、逐步输入及确定的更新计算，改变倍率和执行批次 | 按本地步比较的结果序列一致 |
| TIME-08 | 高倍率运行时，机器未完成映射出的目标进度 | 读出能区分配置与已完成进度 |
| TIME-09 | 将流速、相位及本地时间不同的空间组同步连接，显式指定合并流速 | 连接从共同下一帧生效，各组全部成员统一流速和更新边界；本地时间零点保留 |
| TIME-09 | 空间与外界连接时请求仅改变该空间流速，再完全隔绝并请求独立变速 | 连接期间不允许单独变速；完全隔绝后可按边界规则改变相对倍率，父关系保留 |
| TIME-09 | 独立加速的隔绝空间重新连接外界 | 按显式指定流速重新合组并对齐下一帧，不保留连接双方的流速差 |
| TIME-06、09 | 对已同步连接的空间改变串行顺序或并行分组 | 逻辑更新边界和接收轮次不变，本轮输出不进入对方本轮更新 |

待交付输入在时间信息保存恢复后不丢失或重复的检查，在交付接口确认后补充具体判据。
