# 时间系统 — 测试

> - 适用范围：固定步长、单根时钟树、倍率、暂停、状态恢复与模块接入
> - 上级：[世界框架](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

验证整数微秒刻度、单根时钟树、相对／有效倍率、暂停与祖先暂停、显式本地步推进、状态捕获／恢复，以及时钟模块的公开量、方法、清单和包工具。同步时钟组、跨域交付、目标／完成进度与同一逻辑帧控制顺序尚无对应用例；测试通过只说明当前实现与环境下的对应行为，不构成完整时间语义或性能证明。

## 2. 运行方式与验证环境

构建与整套 CTest 命令见[实现](实现.md#4-构建与运行入口)。程序为 `build/olam/tests/ascend_time_tests` 与 `ascend_time_module_tests`，参数选择用例，多配置生成器加配置子目录；注册清单见 [CMakeLists.txt](../../../../testbench/olam/CMakeLists.txt)，具体输入与断言见 [test_time.cpp](../../../../testbench/olam/test_time.cpp) 与 [test_time_module.cpp](../../../../testbench/olam/test_time_module.cpp)。

开发环境为 Linux x86-64，使用 GCC／Clang 的 Debug／Release 及 Clang AddressSanitizer＋UndefinedBehaviorSanitizer 构建。[CI](../../../../.github/workflows/olam_world.yml) 覆盖 Linux 与 Windows，macOS 未纳入；跨平台通过情况以实际运行为准。

## 3. 用例

| 用例 | 关键保证与验证目的 |
| --- | --- |
| `time.create` | 非正步长拒绝；单根、父子登记、重复／空身份、第二个根、缺失父域与非法倍率分别拒绝；倍率规范化 |
| `time.advance` | 本地时间与帧按固定步长推进；独立时钟互不推进；暂停与祖先暂停阻止推进；流速为零不阻止宿主显式推进 |
| `time.rates` | 父子组合倍率正确；根倍率变化传播；非法倍率与组合溢出拒绝且不改变已有树 |
| `time.state` | 快照保存步长、父关系、本地时间、帧、倍率与暂停；恢复后继续推进；步长不一致、负进度、缺失父域与非法倍率均拒绝且不替换目标树 |
| `time.overflow` | 本地时间或帧达到上限时推进返回溢出且状态不变 |
| `time_module.values` | 固定示例步长、初始值、推进、暂停／恢复与倍率控制；参数错误转为执行诊断 |
| `time_module.state` | 模块状态契约捕获并恢复暂停／倍率／进度；缺字段、身份不一致、负进度、非法倍率／暂停值与未知字段均报告 `invalid_state` |
| `time_module.config_errors` | 非对象配置、非正步长、非法倍率、非法暂停值、未知字段与错误类型分别拒绝 |
| `time_module.package` | 清单导出、`.amod` 往返、模块库载入、资源计数、空配置探测与卸载重载一致 |
| `time_module.package_tool`、`time_module.package_file` | 包工具生成的文件可由模块库载入，状态契约与语言资源保留 |

分配失败回滚未纳入自动化；现实时间配对、同步组合并与跨域交付尚无对应用例。
