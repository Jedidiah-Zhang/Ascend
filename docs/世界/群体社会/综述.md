# 群体社会 — 综述

> - 设计状态：待讨论
> - 适用范围：世界内社会关系、组织与交换机制的职责划分
> - 上级：[世界](../综述.md)

## 目标与边界

定义世界中显式存在的关系、组织记录及社会交互机制，并区分这些规则、主体对它们的认识和作为结果观察的宏观现象。该模块仍是待讨论议题，不预设所有社会现象都由世界规则直接规定。

## 拟定子模块

| 子模块 | 待讨论内容 |
| --- | --- |
| 社会关系 | 世界中关系的载体、形成和变化，以及向主体提供信息的接口 |
| 组织与制度 | 群体归属、角色、协作、权力和制度规则 |
| 交换与分配 | 资源交换、分配、承诺与履行 |

子模块尚未创建；讨论时分别建立 `设计.md` 与 `实现.md`。

## 设计进度与待决依赖

当前只列议题，无已确认机制或新实现。先区分世界中的关系记录、智能体的主观认识和研究统计量，再确定哪些过程需要显式规则；具体模型依赖实体关系与行动接口。

## 关联模块

物质过程对接[世界框架](../世界框架/综述.md)。本模块记录世界中的实际关系、资源归属、制度执行及相应的交互与读取接口；主观信念和策略通过外部行动与这些机制发生联系。
