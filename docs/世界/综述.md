# 世界 — 综述

> - 设计状态：讨论中
> - 适用范围：世界库职责、模块划分和对外边界
> - 上级：[整体架构](../整体架构.md)

## 1. 职责

定义世界是什么、如何生成、如何演化，以及外部作用怎样产生后果；提供运行这些规律所需的执行能力。

本目录只记录世界本身的概念、状态、机制、接口与实现。具体使用方如何选择参数、驱动接口和组合能力，由使用方的文档记录。

世界库是[研究平台](../研究平台/综述.md#自定义因果实验环境)可采用的一种实验环境实现。研究者也可整体替换官方世界，按研究规则声明其他因果系统；本目录的空间、实体和游戏时间约定不自动约束这些环境。

## 2. 模块

| 模块 | 负责内容 |
| --- | --- |
| [世界框架](世界框架/综述.md) | 空间、时间、状态、机制、随机与数值、生成、环境及物质过程 |
| [生命个体](生命个体/综述.md) | 身体、生理、生命周期与身体需求 |
| [基因系统](基因系统/综述.md) | 遗传信息、性状表达、遗传变异和改造的世界效果 |
| [群体社会](群体社会/综述.md) | 世界中实际存在的关系、组织与交互机制；与主观认知和统计评价分开 |
| [运行支撑](运行支撑/综述.md) | 世界装配、执行、记录、快照与验证等公共能力 |

## 3. 对外边界

- 向使用方提供世界配置、初始化、推进、外部作用及结果读取等能力，具体契约随模块讨论确定。
- 定义哪些动作合法、何时生效及如何改变世界。
- 提供作用执行、状态读取与求值记录能力。
- 世界可以独立运行，对外部输入的来源保持独立。

## 4. 设计进度与待决依赖

[世界框架](世界框架/综述.md)已有空间基础切片，其余世界能力尚未实施；具体设计成熟度与限制由所属模块维护。[声明与装配](运行支撑/声明与装配/设计.md)继续讨论运行接入边界。

生命、遗传与社会为后续候选议题，不表示全部纳入首期。跨模块重点是状态、时间、数值与机制接口的协调；空间与时间先明确自身行为及相互联动，不预设其他未定方案。
