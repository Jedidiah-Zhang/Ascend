# AI 原生 NPC — 行为层设计

> **本模块未实现。** 行为层的正式设计：NPC 行为从"需求奖励 + 世界模型想象
> 评估"中**涌现**——无 LLM 决策层、无手写行为树。LLM 仅保留为表现层
> （对话/叙事）的未来可选外围组件。
> 本设计替代过往以 LLM 为中心的决策架构表述（"LLM 决策层""LLM 唤醒"
> "LLM Provider"等一律无效）；研究侧的对应论证见
> [`docs/研究理论/因果理论验证/`](../../研究理论/因果理论验证/)。

**本游戏的核心差异化定位：AI 是一等公民。** NPC 不是行为树 + 对话表的组合，
而是**真正学习出来**的决策者——它的常识来自世界模型（这个世界的物理规律），
它的目标来自需求系统（这个世界的第一性规则），它的行为是两者的交汇产物。
基因、记录、关系图谱等所有子系统存在的意义，首先是为 NPC 输送结构化、
可检索的上下文。

市面上现有游戏的做法的共同缺陷是：智能体挂在外面，只能看到"此刻的快照"
——没有持续性目标、没有长期记忆、行为与对话脱节。本游戏从机制层面解决：
**NPC 的每一寸行为都源于它所在世界的规则**。

## 行为层架构

```
           基因参数 ──────→ 需求层（生理/生存需求 = 确定性奖励函数）
                                     │
                                     ▼
    ┌──────────────────────────────────────────────┐
    │  动机层：需求优先级 + 人格塑形方案选择        │
    └──────────────────┬───────────────────────────┘
                       │ 需求向量
                       ▼
    ┌──────────────────────────────────────────────┐
    │  行为层（策略网络）                            │
    │  输入：世界状态表征 + 需求向量 + 记忆摘要      │
    │  输出：行动分布（技能候选/目标选择）           │
    │  └─ 训练期由世界模型做想象评估（actor-critic） │
    └──────────┬───────────────────────────────────┘
               │ 选定动作
               ▼
    ┌──────────────────────────────────────────────┐
    │  执行层：技能模板动作序列展开（preconditions）│
    └──────────────────────────────────────────────┘

    外围（表现层，可选）：LLM 对话/叙事——不进决策环、不进世界模型
```

五层结构保留（角色 / 目标与愿望 / 技能 / 动机 / 执行），在此之上新增**行为层**（策略网络），决策出口从外部模型生成改为策略网络涌现：

- **角色层**：持久身份，产出维护性子目标。"开酒馆"→角色"酒馆老板"。
  目标完成时自动转化，可嵌套
- **目标与愿望层**：1 个当前目标 + 2-3 待办 + 长期愿望，按 priority + deadline
  排序。简单需求目标由需求层自动生成
- **技能列表**：能力边界（先天/习得/角色赋予），在目标与执行之间过滤候选方案
- **动机层**：生理需求 + 心理满足度 → 目标 priority；人格塑形方案决定
  同一目标的不同实现方式
- **行为层（策略网络）**：需求向量 + 状态表征 → 行动分布。**行为从这里涌现**
- **执行层**：技能模板展开为动作序列，preconditions 声明式前置

## 核心链条：需求 → 常识 → 行为

```
基因参数 ──→ 需求层（确定性奖励函数：饥饿/体温/体力/安全…）
                   │
                   ▼
        【自己怎么生活】由策略网络决定：
        输入（世界状态 + 需求向量 + 记忆）→ 行动分布
                   ▲                │
            世界模型（常识）          ▼
        "做了 A 会怎样"         环境反馈 → 演化 → 下一代
        （想象评估 = actor-critic）
```

- **需求层**：目标来源。生理/生存需求是引擎的确定性规则（奖惩反馈），
  按基因参数化（饥阈值、惧冷、冲动……）。需求优先级天然把"为冬天存粮"
  这类长程目标拆成阶段性短程优先级
- **世界模型**：常识。"下雨时躲进屋子""浆果有毒"——由世界模型按已知因果图
  离线训练（见 [研究理论/因果理论验证](../../研究理论/因果理论验证/)），运行期作为想象模拟器评估策略后果
- **策略网络**：决策器。固定架构 + 固定权重 + 可控随机流，行为全程
  **可干预、可复现**——这就是"AI 原生"的实义：行为从学习中产生，
  不是状态机手写、不是 LLM 借壳

## 训练管线

```
离线：引擎（存在即产生数据）──→ 事件/状态归档 ──→ 世界模型训练
幻想：世界模型当"想象模拟器" ──→ actor-critic 在想象中评估策略 ──→ 行为涌现
探索：内在动机/好奇奖励（可复现，固定种子流）──→ 覆盖行为初期的"幼稚期"
```

- 无示范数据、无 LLM 老师——目标由需求系统提供，行为从想象评估涌现
- 行为初期的"幼稚"（NPC 会饿死冻死）是演化的诞生过程，属世界观卖点

## 演化闭环

```
基因 → 需求参数 → 行为分化 → 环境选择 → 基因频率漂移 → 下一代
```

演化作用于**行为性状**而非只是外形：惧冷/高产/冲动等需求参数在群体中
筛选、漂移——这同时是研究路线 B（认知性状演化）的语义闭环，全链无外部介入。

## 记忆与反思（替代"LLM 唤醒"）

原"显著性评分"机制保留其思想，但用途改为**记忆沉淀与反思时机**，而非
唤醒外部模型：

| 触发源 | 频率 | 行为 |
|---|---|---|
| **外部事件中断** | 事件发生时 | 三层显著性评分（事件分类 → 人格映射 → 状态抑制）决定记忆深度；高显著性事件产生强记忆痕迹（进长期记忆），低显著性衰减 |
| **目标状态变更** | 目标受阻/条件丧失时 | frustration 达阈值触发反思（重新评估目标策略）；条件丧失标记待复查，合并到反思时处理 |
| **周期性自我反思** | 由人格决定间隔 | 高求新性 NPC 频繁反思，低求新性安于现状。反思时用世界模型预测当前目标走向，重新采样行动分布 |

玩家告知：绕过评分，形成**强记忆痕迹**——玩家成为信息传播者。

## 对话即行为（表现层）

对话不是决策的核心，而是**表现层的外围组件**（未来可选，LLM 或规则接棒
均可）：对话内容写入双方行为记录、关系值按结果微调、关键信息更新玩家信息
不对称。**NPC 的"说的话"和"做的事"是同一个策略网络的产物**——不会出现
"嘴上信任但行为背叛"的割裂，除非它的基因如此。

## 已有系统如何服务行为层

- **基因系统**：为每个 NPC 提供不可改变的"需求参数与人格底色"，是长期
  行为一致性与演化差异的锚点
- **记录驱动模拟**：视野内 NPC 行为产生真实记录，视野外概率记录；记录作为
  策略网络的记忆摘要输入
- **关系图谱**：社会上下文输入——对他人态度影响行动分布与目标选择
- **信息不对称**：不能直接查询他人态度，必须通过交互获取——策略网络行为
  与表现层对话让"社交获取信息"不可预测、不可穷尽

## 研究侧价值（为什么这样设计）

- **全链白盒**：需求函数可写、策略可复现（固定 seed）、世界模型可干预
  （do-operator 改需求参数 = "把饥阈值 60→80"做反事实）
- **他者行为可学**：所有 NPC 行为来自同一策略类，世界模型学"另一个策略"
  比学黑箱容易且可审计（标准 MARL 问题）
- **封闭世界 + CRN 成立**：无 LLM 黑箱，研究协议的四条前提全部保住

## 验收：探针 3（纯涌现微世界）

在依赖最小子集就绪后：无 LLM、无手写行为规则；行为 = 需求奖励 + 好奇探索 +
世界模型想象训练。观察能否学会"下雨前避险"等目标行为；通过标准：
涌现策略 ≥ 规则基线的生存效率，且行为在事件日志中呈可审计结构。
