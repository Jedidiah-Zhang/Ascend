# 玩家行动 — 综述

> - 设计状态：讨论中
> - 适用范围：玩家体验目标、需求背景及玩法划分
> - 上级：[游戏平台](../综述.md)

## 目标与边界

定义玩家在世界中的角色、可做的事情及形成的游戏体验。世界观、核心循环和首期玩法随模块讨论逐步确定。

## 已明确的基因编辑动机

基因编辑用于区分个体的观测能力／范围与需求，这是已明确的机制动机。原设计还包含人格、心理需求、主观关系、群体规则和跨代变化，需结合下述需求背景重新讨论。

当前优先在有限小地图、全域持续演化的环境中验证核心玩法。接受较小空间的前提，是它能在一定程度上支持这些差异带来的选择与后果。局部生境可以验证部分适应性差异，但不能据此认定它已替代探索、新生物发现与跨族群交互。具体基因、性状、成本、改造方式和主体控制方式均待讨论。

### 原设计意图的核对

以下为从旧文档中恢复的玩法意图，作为重设计时需核对的需求背景；旧参数、技术选型与完整功能清单不因此成为新方案的已确认要求。

- **主题**：[游戏概要与世界观](../../归档/游戏综述与世界观.md)提出“在肉体的不断自我改造中，智慧生命还能保持原本意志吗？”改造同时涉及能力、需求与群体偏好；效率、力量和社会稳定的提升可能伴随形态与意志的改变。
- **玩家位置**：[管理制度](../../归档/群体社会/管理制度/设计.md)将玩家定位为世界内的个体。管理能力通过设施、信息与社会关系逐步获得，玩家可以一直选择个体视角，而非默认拥有全知控制权。
- **核心体验**：[玩法进程](../../归档/玩家行动/玩法进程/设计.md)强调“观察 AI 驱动的 NPC 如何被你改变”。直接性状变化可以明确展示，长期后果通过行动、对话、记录、关系和群体结构体现。行为实现技术仍按新设计另行讨论。
- **探索与基因来源**：[基因操作](../../归档/基因系统/基因操作/设计.md)包含寻找特殊生物、捕获与分析、提取门槛、标记后返回，以及与智慧族群交换研究许可。多样性既提供生存条件差异，也提供未知性状与不同获取路径。
- **创造与传承**：旧基因操作区分编辑、育种、克隆和从零创造。育种产生新变体，编辑应用已知基因；克隆和创造还涉及个体经历与身份。它们不能全部归结为属性加减。
- **生产与社会后果**：[饮食兼容](../../归档/基因系统/饮食兼容/设计.md)连接作物改造、消化能力与供给链；[人格与心理](../../归档/生命个体/人格与心理/设计.md)及[关系图谱](../../归档/群体社会/关系图谱/设计.md)涉及同一活动或事件对不同个体产生不同体验与解释。
- **长期身份议题**：[死亡机制](../../归档/玩家行动/死亡机制/设计.md)还探索了知识传承、身体更替与意识延续。这是后续范围讨论的背景，不预先纳入首期。

### 后续设计需验证的问题

- 相同环境中的个体，是否因感知能力不同而获得实质上不同的信息？
- 不同身体需求是否改变可利用资源、生存成本或适宜活动条件？需求差异不预设主体必然采取某种策略。
- 改造如何影响心理需求、偏好及对事件的理解，并经个体经历和交互产生群体后果？具体映射待讨论，不能把某种社会结果写成必然发生。
- 局部环境差异、昼夜等时间变化和资源配置，能否在有限空间中提供多种有价值的适应方式？具体机制为候选。
- 改造是否带来可理解的收益与代价，而非所有场景中都更强的单向升级？
- 玩家能否通过实际结果理解差异，并作出下一次改造或环境调整的选择？
- 玩家以世界内个体的权限，能否通过观察、对话和设施记录理解后果，而非依赖全知面板？
- 有限地图能验证哪些探索与基因获取过程？哪些原有体验仍需更多内容或空间才能验证？

这些问题用于检验玩法，不预先决定遗传表示或智能体技术。身体性状及作用规律由世界模块定义；观测处理、记忆和决策由智能体模块定义；本模块记录玩家如何利用这些能力形成玩法。

## 设计进度与待决依赖

已明确核心动机，首期玩法及具体机制尚未确定、新方案未实施。小地图验证目标见上述问题清单，地图组织见[世界组织](../世界组织/设计.md)。先验证能力差异能否形成可理解的选择和后果，再决定扩展内容；世界性状、智能体接口和玩家信息权限仍需共同讨论。

## 关联模块

物质、生命、遗传和社会机制由世界模块定义；本模块组合这些能力，定义玩家角色、可用指令和输入映射。改变世界状态的动作效果仍由世界机制执行。NPC 控制对接[智能体](../../智能体/综述.md)，玩家输入与反馈对接[表现层](../表现层/综述.md)。玩家对垂直空间、实时控制和长时间推进的需求参与空间与时间设计。
