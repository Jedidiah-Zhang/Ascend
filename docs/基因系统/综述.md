# 基因系统 — 综述

> **本大类未实现**——以下为设计意图。当前无任何基因数据结构、基因操作、
> 饮食兼容代码。

基因系统是游戏的核心差异化机制。基因操作是玩家改变世界的主要手段。

## 子模块关联

```
基因操作 → 饮食兼容
    ↓
  个体系统（人格、生理、身体）
```

- **基因操作**定义四种改造方式（编辑、育种、克隆、从零创造）、兼容性矩阵、自动生成机制
- **饮食兼容**是基因系统的一个具体应用方向——消化基因决定食物吸收率，形成"改作物→改消化基因→大规模种植"的投产链

## 形态生成（morphogenesis）

**形态完全由基因组合构建**——不存在独立于基因的"物种形态"：

- 基因定义形态基元（轴向/附肢/头部/尾/翼），身体语法（body grammar）把基因组合解析为完整骨架（段轴 + 挂点 + 功能映射）
- 物种 = 出生基线基因组合（如 `human_base`），基因操作（编辑/育种/克隆/从零创造）改变组合 → 形态随之改变
- 合法性约束由语法校验，非法组合被拒绝
- 部位与功能挂钩（翼→飞行、鳃→水下呼吸）；渲染层按同一语法计算部件挂点与层列表（见 生命个体/身体部位/设计.md、表现层/视觉风格/设计.md）

## 与其他大类的接口

- → **心智系统**：基因为 LLM 提供不可改变的性格底色
- → **生命个体**：基因同时影响生理需求参数、身体形态构建、人格分布参数
- → **群体社会**：基因影响关系记录的方式（同一事件不同基因记录不同看法）
- → **世界框架**：不同群系的生物携带不同基因，驱动探索
- → **玩家行动**：基因操作、育种、种植、畜牧都依赖基因系统
