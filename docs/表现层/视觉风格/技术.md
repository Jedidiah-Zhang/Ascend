# 视觉风格 — 技术

前端 3D 渲染由 `scripts/world/main_world.gd` 编排，相机/光照拆分为协作类
（`camera_rig.gd` 正交摆位与阴影覆盖几何、`lighting_controller.gd` 太阳高度角
驱动的光照阴影调制），地形为合并 ArrayMesh，玩家为红色方块占位。

## 节点结构

```
Main (Node3D, main_world.gd)
├── World (Node3D)
│   ├── Camera3D             正交投影，沿 (1,1,1) 方向俯视，锁死旋转
│   ├── SunLight (DirectionalLight3D)  太阳光，方向由游戏时间驱动
│   ├── WorldEnvironment     后处理、雾效、天空色
│   ├── Terrain (Node3D)
│   │   └── ChunkPool (Node3D)
│   │       └── Chunk_<cx>_<cy> (MeshInstance3D)    每 chunk 一个合并 ArrayMesh
│   ├── Water (Node3D)
│   │   └── WaterPlane (MeshInstance3D)  半透明水面 plane（depth-fog shader）
│   ├── Entities (Node3D)    实体容器（当前仅玩家红色方块）
│   ├── Caves (Node3D)       洞穴子场景（空占位，未实现）
│   └── WeatherFX (Node3D)   天气特效（空占位，未实现）
├── TerminalLayer (CanvasLayer, z=100)
│   └── TerminalWidget
├── DebugLayer (CanvasLayer, z=200)
│   ├── DebugOverlay
│   └── EventLog
└── PauseLayer (CanvasLayer)
    └── PauseMenu
```

## 相机配置

```gdscript
# Camera3D 初始化
camera.projection = Camera3D.PROJECTION_ORTHOGONAL
# 摆位：焦点 + (1,1,1).normalized() × 距离，look_at 焦点
var dir := Vector3(1, 1, 1).normalized()
_camera.position = focus + dir * distance
_camera.look_at(focus, Vector3.UP)
# 正交 size = 距离 × tan(FOV/2)
camera.size = distance * tan(deg_to_rad(CAMERA_3D_FOV * 0.5))
# near/far 紧贴可视地形 slab（阴影范围 = 相机视锥）
```

| 参数 | 值 |
|------|-----|
| 投影 | 正交 (Orthogonal) |
| 方向 | (1,1,1) 归一化（俯角 ≈35.3°），look_at 焦点 |
| 旋转 | 锁死（固定方向） |
| FOV | 5°（极小值近似正交） |
| 距离 | 默认 400，滚轮 ±40 步长，clamp(60, 1200) |
| 跟随 | 每帧 `camera.position = focus + dir × distance` |

## 地形渲染（合并 ArrayMesh）

### 构建

每 chunk 用 `TerrainMeshBuilder.build_data`（后台纯数据）生成顶点/法线/UV/
顶点色 AO，`make_mesh`（主线程）组装合并 ArrayMesh 并挂材质。逐 tile 生成
顶面（带 AO）与可见侧壁（海拔差形成悬崖），水面 tile 与低于裁剪线的 tile 跳过。

### 地形类型映射

`TERRAIN_TO_MESH` 表把后端 TerrainType 映射到材质。深水/浅水不占网格（走
Water plane），浅水/深水分别映射为对应水面材质。

### 水面

独立于地形网格的单层 `PlaneMesh`（`WaterPlane`），覆盖整个世界范围，
`water_depth_fog.gdshader` 深度雾效让深水区更暗。

### 流式加载

`ChunkStreamMachine` 状态机驱动流式加载：

- 视野内缺失的 chunk → 发 `get_chunks` 请求（含 tile 数据）
- 数据到达 → 后台构建 → 主线程挂载合并 ArrayMesh
- 超出视野 → 由缓存淘汰机制移出（见存档系统/技术.md 的 LRU）

## 光照

### 太阳光（DirectionalLight3D）

`lighting_controller.gd` 根据游戏时间与后端天气参数计算太阳高度角/方位角，
驱动太阳位置、光照强度与阴影开关：

- 太阳高度角低于 `SHADOW_CUTOFF` 时关闭阴影
- 低角度时按比例放大阴影覆盖范围、压扁 pancake（`SHADOW_LOW_ANGLE_EXPAND`）
- 阴影覆盖距离 = 可视半径 × 余量（正午 1.35 倍，低角度放大到 3 倍）

### 环境光（WorldEnvironment）

环境色随昼夜因子插值，背景为深灰蓝基调。

### 局部光源

`OmniLight3D`（篝火/火把/营火）未实现——当前场景无局部光源。

## 遮挡虚化（未实现）
