# 视觉风格 — 设计

> **本方案为已实现的目标架构（Issue #38 前端地形 2D 扁平化重构，阶段 1-4 已完成）**：
> 地形从 3D 海拔几何改为 **2D 扁平化**（海拔保留为后端数据，不作为渲染几何），
> 2D TileMapLayer 平铺 + 海拔五信号 + 显示值追赶 + 分层 pawn + CanvasModulate/局部光源。
> 各节标注"未实现"的为后续增量（天气粒子、洞穴、基因外观差异）。

## 场景表现

- **2D 正俯视平地形**：地形用 `TileMapLayer` 方 tile 平铺渲染（**90° 正俯视**，Y-sort）。海拔不抬升 tile——没有遮挡、没有阴影系统、没有倾斜网格的读取负担。正俯视把"可读性优先"这一第一价值观做到极致，方形网格对建造/规划/资源管理最友好
- **像素风**：低分辨率像素点阵贴图（最近邻过滤），保持像素美学
- **混合管线**：2D 场景 + CanvasLayer 叠加 UI（终端、F3 面板、事件日志等保持不变）
- **角色与生物**：Sprite2D 侧视 billboard + Y-sort（y 位置排序），2D spritesheet 动画帧驱动，水平翻转（flip_h）表示左右朝向。形态完全由基因组合构建（morphogenesis）：身体语法（body grammar）计算部件挂点，部件按槽位拆分拼接（头/躯干/附肢/基因变异层/装备层）叠加渲染——环世界做法。四足/鸟类等只需不同基因组合 + 对应部件资产，机制零改动。状态图标/名称浮层为独立节点，悬浮在头顶，不占身体像素预算
  - *当前实现（阶段 4）*：分层部件渲染路径已就位（`pawn_renderer.gd` 体型规格 → Sprite2D 部件，含变异/装备槽位占位），默认物种规格为纯色占位；朝向用部件偏移镜像表达；名称浮层已实现。动画帧与基因驱动外观待 genome 定型后接入
- **植物与灌木**：Sprite2D 分层，经典俯视策略游戏做法
- **建筑与岩石**：Sprite2D 像素资产或简化 2D mesh，数量少品种少
- **基因外观差异**：角色 Sprite2D 分层叠加（基础体 + 基因变异层），简单纹理/颜色叠加即实现

## 地图呈现

- **固定正交相机**：锁死 **90° 正俯视**，方 tile，无近大远小。玩家始终画面中心，鼠标滚轮缩放
- **TileMapLayer 流式加载**：地形以 chunk（200×200 cell）为单位，每 chunk 一个 TileMapLayer。加载/卸载策略沿用现有流式逻辑（LRU + 视野半径）
- **地形材质**：8 种纯地表材质（草/沙/砾石/沃土/岩/冻土/沼泽/水），映射为 TileSet 中不同 tile（与后端 TerrainType 枚举对齐）。地貌形态（山巅/陡坡）与水深从场推导，不进枚举——水面层单独 TileMapLayer（半透明 + 动画水位）
- **环境表现**：WorldEnvironment 提供全局后处理——色调映射、雾效，配合天气系统实时调整（晴天/阴天/暴风）

## 海拔的视觉表达（五信号）

海拔不再抬升几何，用五个 2D 信号表达高差（数据来自后端 elevation/slope 数组）：

| 信号 | 做法 |
| --- | --- |
| 地形材质色 | 8 种材质映射色块/纹理（草→沙→砾石→沃土→岩→冻土→沼泽→水），第一层级 |
| **崖壁贴片** | 相邻 tile 海拔差 > 阈值时，高侧边缘画悬崖 sprite——高度差只在**带边界**处表达，不连续渲染 |
| **固定方向投影** | 光照方向固定，高地形南/东侧下方铺半透明阴影贴片，纯 2D 伪立体 |
| 装饰密度 | 海拔越高岩石/砾石装饰越密（确定性哈希，非随机）。雪顶不再硬编码——覆雪是动态状态，由雪状态自然累积形成动态雪线（见状态渲染） |
| 等高线调试层 | 500m 间隔 contour，挂调试面板（对齐 ALPINE 2000m 阈值），开发期有用、平时可关 |

原则：**海拔是数据、不是几何**——"高 23.5m 还是 24m"不渲染，但"这里有陡坡、那边是山"一目了然。陡坡/山巅不可通行边界（海拔/坡度场推导，不在材质枚举）由崖壁贴片画清，玩家不会"点着走不动"才意识到。正俯视下这些信号最清晰（崖壁边沿、投影贴片、色块都在方正网格上直读）。

## 状态渲染（显示值追赶）

覆雪/湿润/结冰的视觉采用**显示值追赶真值**（后端是真值，前端是渲染缓存）：

- 前端持有 `display_*` 缓存，向后端真值渐进收敛
- **逐帧随机抽样**：每帧随机抽 N 个 tile，被抽中的显示值 `+= step`（step 由追赶速率决定）——不同 tile 错开推进，雪"一片片铺开"，避免"整块同步变白"
- 初雪/暴雪事件 → 临时提高抽样密度/step（快下快铺）
- 追赶速率快于感知阈值（偏差有界，几秒到几十秒收敛）
- 结冰=冰面渐凝 + 覆雪厚度着色 + 湿润=土壤加深色调，共用同一框架
- **纯视觉缓存**：可真随机，不进存档、不参与逻辑
- 全屏下雪变白是覆雪"冬天来了"的视觉宣言——是表现，不是噪音（状态数据走 chunk 通道，不经事件系统，日志不刷屏）

## 光照方案

- 2D 场景采用 **CanvasModulate**（全局昼夜色调）+ 局部 **PointLight2D**（火把/营火/建筑窗户）
- 全局明暗由游戏时间驱动（昼夜循环），夜间暗色 + 局部光点
- 遮挡虚化不再需要——平地形无遮挡，整类问题消失

## 洞穴与地下

- 洞穴层（`layer_id=-1/-2`）为独立 TileMapLayer，与地表层天然分离——"屋顶隐藏"问题不复存在（无 3D 屋顶）
- 洞口 = 地表 tile 上的入口贴片（暗色坑洞 sprite），点击/交互下潜
- 洞穴内局部点光源（火把 PointLight2D），暗色调调色板
- 洞穴渲染用更暗的色调 + 局部光照，视野内雾化

## 天气视觉

- **GPUParticles2D**：雨滴、雪花、沙尘、落叶——2D 粒子
- **雾效**：CanvasModulate 色调 + 半透明遮罩由后端湿度/温度参数驱动浓度
- **云层**：简单的半透明移动 sprite/粒子云团
- **覆雪/结冰/湿润**：见"状态渲染（显示值追赶）"节——雪厚度着色、冰面渐凝、土壤加深色调

## 配色基调

- 全局背景色由 WorldEnvironment 的 clear color 控制，深灰蓝基调
- 调试 UI 不变——CanvasLayer 覆盖在场景之上，半透明黑底 + 绿色标题
- 白天/黄昏/夜晚通过 CanvasModulate 颜色 + 环境光强度 + 后处理色调映射实现

## 相机约束

| 自由度 | 状态 |
|--------|------|
| 俯仰角 | 锁死 **90°（正俯视）** |
| 水平旋转 | 锁死（正俯视无旋转需求） |
| 投影模式 | 锁死正交 |
| 缩放 | 鼠标滚轮自由 |

> 正俯视贴合"可读性优先"第一价值观，方 tile + Y-sort 对建造/规划/布局最友好，
> 也是玩家对"俯视角生存经营模拟"的直觉形态。像素资产尚未定型（现状为占位），
> 不迁就等轴；未来如需立体感可再评估等轴，但初期锁死正俯视以降低复杂度。
