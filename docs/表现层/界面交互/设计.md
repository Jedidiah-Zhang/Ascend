# 界面交互 — 设计

## 操作方案（键鼠）

| 输入 | 动作 | 处理方 |
|---|---|---|
| WASD / 方向键 | 玩家移动 | 本地即时移动（客户端预测），每 0.2s 节流上报后端权威实体（player_move），回显滞后零纠正、仅真偏离才纠正 |
| E | 交互 | 发送 `player_interact` 请求（后端返回"未实现"标记） |
| Esc | 菜单 | 打开本地暂停菜单（`pause_menu.gd`） |
| 鼠标滚轮 | 相机缩放（距离 60–1200） | 纯前端 |
| `/` | 切换调试终端（调试模式开启时） | 纯前端 |
| F3 | 切换调试面板 + 事件日志（调试模式开启时） | 纯前端 |

设计原则：

- 玩家移动等高频操作前端本地响应，保证手感；后端持有权威玩家实体（上报坐标越界时钳制到地图边界），传送等服务端主导的位置变更经 `player_teleported` 事件推送前端吸附
- 游戏逻辑操作（交互、菜单）发请求由后端裁决
- 终端打开时独占键盘输入，相机控制与玩家移动暂停，但网络消息仍持续处理
- 所有调试 UI 均为半透明覆盖层，`mouse_filter = IGNORE` 不拦截游戏操作

## 调试终端

Minecraft 命令行式的全屏半透明控制台，开发调试期的主要交互入口：

- `/` 打开/关闭；输入行 + 滚动输出区（上限 500 行），绿色提示符 `$ `
- 本地指令（`clear`）经 `register_command` 注册后前端直接处理；其余指令（`tp`、`lang` 等）原样转发后端 `terminal_cmd`，输出回显；`help` 同时显示本地与远程帮助
- 指令历史（↑/↓ 翻阅，上限 100 条）、光标编辑（←/→/Home/End/退格/Delete）、PageUp/PageDown 翻页
- 完整指令表见 [终端指令](./终端指令.md)

## F3 调试面板

Minecraft F3 风格，屏幕左上角分区显示，0.25s 节流刷新。当前 10 个分区：

| 分区 | 内容 | 数据来源 |
|---|---|---|
| 性能 | FPS / TPS / MSPT / 各阶段微秒耗时 | 引擎自取 + main_world 计时器 + minute_change 推算 TPS |
| 内存 | 静态/视频内存、节点数 | Performance 单例自取 |
| 时间 | 第 N 天 HH:MM | minute_change 事件 |
| 相机 | 位置、缩放 | 每帧推送 |
| 玩家 | 坐标、区块、海拔 | 每帧推送 |
| 气候 | 温度/湿度/气候带 | chunk 数据 + 天气事件 |
| 天气 | 降水、温/湿/风（含体感描述）、光照强度、日出日落 | `get_weather` API 每 1s 轮询 |
| 区块 | 已加载/放置中/缓存/待发送计数 | main_world 统计 |
| 地形 | 逐格海拔、坡度 | chunk 数据（玩家移格时刷新） |
| 状态追赶 | 抽样密度倍率/加速剩余/收敛中 chunk 数 | state_display_chaser 统计 |

## 事件日志

屏幕右侧与 F3 面板对称的实时事件流（随 F3 一同开关）：

- 显示最近 20 条，新事件插入顶部，0.5s 节流重绘；标题/描述全部走 `tr()`（`lang/*.json`）
- 每条格式 `[HH:MM] 事件描述 [区块 x,y]`；日期变更插入 `── 第N天 ──` 分隔线（翻译键 `event_log.*`）
- **位置过滤**：带位置的天气事件（温度/湿度/风/日照/降水）仅显示玩家周围 3×3 chunk 内的，避免全图事件刷屏

## 设置界面（主菜单 / 暂停菜单共用）

覆盖层 `settings_screen.tscn`（CanvasLayer layer=400，process_mode ALWAYS
保证暂停期间可交互）；标准控件 + 「傍晚营地」主题（暖琥珀选中态、圆角、
键帽形态）。架构：`Settings` autoload 薄门面装配四个纯逻辑 RefCounted
（scripts/settings/），UI 壳只做控件装配与转发。

- **入口**：主菜单「设置」按钮、暂停菜单「设置」项；打开期间两处菜单的
  输入全部放行给设置界面，ESC（或改绑后的菜单键）关闭
- **分页**：
  - **通用**：语言（简体中文 / English，立即生效）；调试模式（默认开启；
    关闭后 `/` 控制台与 F3 信息面板/事件日志不可呼出，已打开则自动隐藏）
  - **显示**：分辨率（预设档位按屏幕尺寸过滤 + 恒含当前值）× 窗口模式
    （窗口化 / 无边框全屏 / 独占全屏；无边框下分辨率禁用——跟随桌面）
  - **按键**：8 个 InputMap 动作（move_* / interact / menu / zoom_*）改绑
    ——「＋ 添加」进入捕获态，冲突/重复拒绝并提示，点击键帽删除，恢复默认；
    ESC 保留为取消键不可绑定；`menu` 动作被暂停菜单与设置界面实际消费
  - **音频**：预留禁用页（音频系统尚未上线）
- **即时生效**：选择即应用并落盘，无确认/回滚流程
- **持久化**：`settings.cfg` 与后端存档同级——`~/.ascend/settings.cfg`
  （跟随 `ASCEND_SAVE_ROOT` 环境变量重定向），非 Godot `user://`
- **语言机制**：前端与后端共用仓库根 `lang/*.json`（扁平点分键 +
  `{param}` 插值；GDScript `String.format()` 与后端 `str.format(**kwargs)`
  同构）；前端经 LocaleCatalog 注册 TranslationServer，UI 统一 `tr()`；
  进入世界 / 游戏内改动经 `terminal_cmd "lang <locale>"` 幂等同步后端
  （main_world 在 `world_initialized` 及 `locale_changed` 时发送）
- **主题**：`assets/ui/settings_theme.tres` 运行时加载（该目录不入库，
  缺失回退默认主题）
