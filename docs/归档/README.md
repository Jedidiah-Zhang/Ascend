## 2. 使用方式

需要查阅旧需求、参数或实现经验时，可引用本文档或明确标为“旧设计”的具体链接。重新采用其中任何方案时，在对应新模块中记录需求、比较和讨论结论，不直接恢复其规范地位。

新架构图将在相应设计确定后编写，旧图不用于描述新目录所代表的架构。
