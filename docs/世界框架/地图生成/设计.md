# 地图生成 — 设计

## 双层地图结构

```
大地图（选点/远行）          详细地图（活动/建造/社交）
─────────────────────      ─────────────────────────
          ┌───┬───┬───┐
          │   │   │   │    每个格子展开 →
          ├───┼───┼───┤    固定尺寸的 tile 地图
          │   │ ■ │   │    200×200 tile
          ├───┼───┼───┤
          │   │   │   │
          └───┴───┴───┘
```

- **大地图**：整个大陆的分块网格，每个格子是一个分块。俯瞰视角，用于选点、远行规划、了解区域分布。分块的核心作用是**坐标定位 + 群系区分**——每个分块有独立的群系标签，格子的密度决定了群系地图的精细度。地图是有界矩形（默认 100×60 km，创建世界时可调），不是无限延伸
- **详细地图**：玩家脚下的无缝连续 tile 地图。没有分块边界——走到哪加载到哪，分块只是大地图层的概念，不影响详细地图的连续性

### 两层生成

地图分两层生成，层 1 一次生成整个大陆宏观场，层 2 按玩家所在区域按需展开为详细 tile：

- **层 1 宏观场**（100m/格，1000×600 格）：海拔、气候（温度+降雨）、水力侵蚀后的地表、河流网络、湖泊盆地、**距水距离场**（多源 BFS：海/河/湖，供材质"按距水多远"分布）。一次生成约 5-30 秒，存于 `ContinentData`，启动时由 `GameEngine` 主动触发；生成结果缓存在 `continent.bin`，之后加载秒级恢复
- **层 2 详细 tile**（每 chunk 200×200 tile，1 tile = 1m = 1/100 格点）：从层 1 采样宏观海拔/距水/气候等**低频连续场**，按层次规则分类材质，再叠加河流河道与湖泊水面。按 chunk 请求时现算，可并行；已落盘的 chunk 从存档恢复

## 水文

侵蚀与河流是地图的骨架，决定地形起伏与水体分布。

### 侵蚀

降雨驱动的水力侵蚀（10 轮迭代）：水从高处流向低处，沿途侵蚀地表、下游沉积。侵蚀力度正比于流量平方根与坡度，质量守恒。结果是高低起伏的地表——山脉有河谷，平原堆积沉积物。

### 河流

河流网络用**三级方向场追踪**：从流量累积的源头出发，沿混合方向场积分到海。山地跟随海拔梯度（山谷自然弯曲），平原跟随流量场（指向下游主流），分水岭与兜底靠 Dijkstra 到海代价场。追踪后做 Chaikin 平滑，产出连续弯曲坐标的河流路径，消除格子线。

河流有 Strahler 分级（主流深、支流浅），宽度随流量对数增长。支流在 2 格内碰到主流即汇入，形成树状网络。

### 湖泊

湖泊是侵蚀后留下的洼地——填洼算法检测出"填平后升高超 1m"的区域，每个连通分量是一个湖盆。湖面高度 = 盆地最低溢出口（水满则溢）。湖泊大小取决于洼地面积，是侵蚀的被动副产物而非主动放置。

## Z 轴

为支持洞穴层（提供特殊基因生物的栖息地），地图引入 Z 轴，但拆成两个正交概念避免 3D 复杂度：

### 渲染 Z（连续高度）

每个 tile 存连续高度值（float）+ 局部梯度值（float），作为**纯数据**导出给前端。前端用这两个值做高度场渲染（详见《表现层/视觉风格/技术.md》）。

这是纯视觉数据，事件/寻路/碰撞不碰——"tile 高 23.5m 还是 24m"对游戏逻辑无意义。

### 逻辑 Z（离散层 id）

层 id 枚举：`0=地表，-1=浅洞，-2=深洞`。每层内部是纯 2D 平面，寻路/碰撞/视野/势力范围全保持 2D 算法。

- 实体和事件带 `layer_id` 字段（默认 0=地表），空间索引按 `(layer_id, chunk_x, chunk_y, sub_cx, sub_cy)` 分桶——不同层天然隔离
- 跨层交互用两个 2D 事件联动（地表塌方 ↔ 洞穴顶部塌落），而非 3D 事件
- 洞穴生物挂在 `layer_id=-1`，与地表种群隔离，杂交/迁徙需显式跨层动作

洞穴层的 chunk 数据结构待定（未实现），当前只有地表层（layer_id=0）的生成与存档。

## 分块

### 定位

分块 ≠ 加载单元。分块是大地图层的概念——给世界贴上一层坐标网格，每个格子标记一种群系。详细地图是完整连续的，玩家行走时感受不到分块边界。

分块的三重作用：
- **坐标定位**：大地图上选点、远行路径规划、标记地点
- **群系区分**：每个分块一个群系类型，格子的密度决定了群系地图的精细度
- **并行单元**：不同分块的生成可分配到不同线程（生成期并行；分块模拟并行未实现）

### 加载

只加载玩家附近的 chunk——启动时预生成出生点周边 5×5 个 chunk，运行时按请求懒加载。远离的 chunk 由缓存淘汰机制移出内存（已落盘的从存档恢复）。**未实现**：按视野半径的主动加载/卸载窗口、大地图快速旅行。

## 大地图

### 分块信息

网络响应在请求时下发每个分块的：群系类型、气候档位、是否可通行（`passable`）；请求带 `force_fields` 时附 `altitude/temperature/humidity/rainfall` 四个场值，带 `include_tiles` 时附紧凑二进制 tile 数据。

- **已知标记**（聚落位置、遗址、资源点）：存于 ChunkData.markers（通用字典），**未实现**——尚无系统写入，也不下发前端
- **通行属性**（移动速度）：移动速度倍率在每类地形的属性中已定义（`movement_cost`），但**未实现**——无消费方、不下发前端，网络响应只含能否通行
- 大地图 UI（放大/缩小切换、选点、手动标记、迷雾）**未实现**

## 群系生成

每个分块在首次生成时确定群系类型。群系由大陆物理模型（纬度梯度 + 大陆度 + 雨影）计算温雨，经群系隶属度映射派生，相邻分块的群系有自然过渡——不会出现"热带雨林隔壁是冻土"。
群系决定分块内的：

- 地形构成（水体比例、山地分布、平原面积）
- 生物种类分布（野生生物、怪物——未实现，仅模板数据）
- 资源类型（矿产、可采集植物——未实现，仅模板数据）
- 环境参数（温度、湿度基线）

群系详细参数由群系生态模块定义。

### 基底分类（tile 级）

每个 tile 的基底材质（TerrainType，8 种纯地表材质）在 chunk 生成时确定。
issue #42 收窄语义：材质枚举只表达地表（草/沙/砾石/沃土/岩/冻土/沼泽/水），
地貌形态（山巅/陡坡）与水体深浅**从场推导**，不进枚举。

分类函数（输入全为**低频连续场**，细节噪声退出分类——相邻 tile 输入连续
→ 材质区域连续，根治碎斑）：

```
f(宏观海拔, 坡度, 距水距离, 气候温雨, 湿度, 群系偏移) → TerrainType
```

层次规则（顺序即优先级）：

```
 1. 宏观海拔 < 0             → WATER（海洋；河/湖由 render 后叠加为 WATER）
 2. 海拔 > 岩线(bias) 或 坡度>裸岩 → ROCK
 3. 寒带（年均温 < 冻土线 bias）：近水积水 → MARSH
 4. 寒带非沼泽               → PERMAFROST
 5. 干旱（年降雨 < 干旱阈值 bias）：高/中海拔 → GRAVEL
 6. 干旱低海拔               → SAND
 7. 距水 < 沙滩带            → SAND
 8. 距水 < 冲积带 且 低海拔   → FERTILE_SOIL
 9. 距水 < 湿地带 且 湿度高   → MARSH
10. 默认                     → GRASSLAND
```

- **气候**：chunk 中心气候档位与温雨值（整 chunk 复用，不逐 tile 采样），经群系隶属度 → TerrainBias（岩线偏移/干旱阈值/沙滩带/冲积带/沼泽倾向/冻土线）
- **海拔**：宏观海拔（双线性插值）；**距水**：层 1 距水距离场（多源 BFS）双线性插值；**坡度**：宏观海拔 8 邻域梯度（不含 ±50m 细节噪声，噪声纹理不产生虚假陡坡）
- **细节噪声（±50m）只进海拔存储**：供渲染的崖壁/阴影/等高线信号，退出材质分类
- **边界有机化**：来自低频场连续性的自然过渡，不是阈值抖动——沙只在岸/旱、岩只在山/坡、冻土只在寒带
- **雪顶不再硬编码**：高海拔低温（天气温度场含 chunk 海拔直减）→ 雪状态自然累积，见《地形状态》

**随机性口径**：确定性 seed 派生——同 world seed 完全可复现（存档/回归测试依赖）。随机体现在"斑块细节"，宏观事实（山还是平原、什么群系、材质区域）由连续场决定，不随机。

**通行语义**：材质注册表给面级基线（passable/buildable/movement_cost/fertility）；
水面通行按水深实时推导（`water_passability`，浅水可涉水、深水不可）。
边级可通行（邻域海拔差阈值）属 #30 垂直维度范畴，暂未实现。

> 动态层（湿润/覆雪/结冰）——见《地形状态/设计.md》。（雪顶由动态覆雪自然形成，无静态雪线装饰）

## 特殊分块（未实现）

- **长生种聚落分块**：稀有，生成时标记为特殊群系，建筑和 NPC 由群体社会模块管理
- **遗址分块**：内含古代设施/稀有基因/可研究物品
- **玩家建造的分块**：玩家在空分块上从零建造据点。分块内的人工建筑和地形改造持久保留

当前无任何特殊分块机制。

## 与其他模块的接口

- → **群系生态**：分块生成时，群系类型决定该分块的生物、资源、环境参数（生物/资源部分未实现）
- → **时间系统**：大地图快速旅行触发长途移动时间跳转（未实现）；分块加载/卸载与时间模式无关
- → **群体社会**：聚落位置注册到大地图分块索引；分块的所有权、势力范围在大地图上可见（未实现）
- → **玩家行动**：建造只在详细地图内发生；采集和探索依赖分块的群系资源分布（未实现）
- → **表现层**：详细地图用 tile 渲染（已实现）；大地图抽象色块+图标渲染（未实现，当前仅地形预览）
