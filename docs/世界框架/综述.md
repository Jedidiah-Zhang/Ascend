# 世界框架 — 综述

世界框架定义游戏的物理基础：空间、时间、物质、事件。

## 子模块关联

```
地图生成 → 群系生态 → 季节气候 → 地形状态
                ↑          ↓
                └── 时间系统 ──┘
                 ↓
              物品系统
                 ↓
              实体系统
                 ↓
    ═══════ 事件系统 ═══════
         （底层状态变更协议）
```

- **地图生成**定义双层地图结构——大地图（有界矩形分块网格，用于选点和远行规划）+ 详细地图（固定 200×200 tile，无缝拼接，用于活动/建造/社交）
- **群系生态**定义群系 = 气候 + 生态内容（地形、植物、生物、资源）。8 个气候档各细分 2 个陆地子型（共 16 陆地 + 3 海洋），基础群系为温带落叶林、沙质沙漠、砾石戈壁，后续按需扩展
- **季节气候**定义气候（8 档离散分类，指导群系分布）+天气（连续值，六项可扩展参数：温度、降雨量、日照、海拔、湿度、风速）。解析算架构，四层叠加（年均基线+季节调制+昼夜偏移+大气扰动），降水为事件驱动模型。天气数据通过 15 种事件发布到 WorldTree（4 种 per-parameter 变化 + 降水起止 + season_change + per-chunk sunrise/sunset + 极端天气各起止），并暴露 get_weather 查询 API
- **地形状态**在基底类型上叠加湿润/覆雪/结冰三层动态状态（1B/格/状态），由统一天气场驱动：C 加速统一演化内核（结算/脉冲同公式），事件三通道（降水涂抹 / 小时脉冲 / 日档快进），阈值穿越发区域级叙事事件。积分量（状态数组 + 结算日）随 TileGrid 持久化（见地形状态/设计.md、技术.md）
- **时间系统**定义基底时钟（2h=1天）、短跳（睡觉/移动）和长跳（闭关）三种时间跨越，以及快进期间的世界模拟方式（短跳/长跳当前未实现，见时间系统文档）
- **物品系统**Minecraft 式简洁模型——格子系统 + 可堆叠/不可堆叠。六类物品：工具（耐久/修理/报废）、食物（饱腹+消化标签）、建材、基因样本（生物样本→研究室提取，基因不进入背包）、资源、假肢装备（**未实现**，见物品系统/设计.md）
- **实体系统**定义世界中一切值得个体化的存在物（生物/植物/掉落物/建筑）的数据形态与生灭语义。玩家只是 controller=PLAYER 的生物实体；birth/death 是世界内因果事件，spawn/despawn 是表现层视野概念
- **事件系统**是连接所有模块的**总线**。各模块不直接耦合，所有变化（天气、NPC 行动、玩家操作）统一作为事件发布到总线上流转。事件之间形成有向图（因果、观测、传播等关系）。事件总线是快进模拟的驱动骨架（快进推演未实现）
- **存档系统**定义世界状态的持久化——实时写入（玩家无需时刻存档）+ 手动快照回退点。一个存档位 = 一个世界（实时状态 + 快照集合）。存档是世界外元操作：走状态通道，不产生历史、不进因果图。内容经加密防其他工具直读/篡改，密钥随档分发可移植

## 与其他大类的接口

- → **生命个体**：环境参数（温度、湿度）作为生理需求的输入；物品（食物）满足饱腹（生命个体未实现）
- → **群体社会**：季节影响资源供给，间接影响社会稳定性（群体社会未实现）
- → **基因系统**：不同群系的生物携带不同基因，驱动探索动机（基因系统未实现）
- → **玩家行动**：种植采集依赖季节和群系；威胁事件触发防御需求（玩家行动未实现）
- → **表现层**：地图、群系、季节的视觉呈现
- → **时间系统**：世界时钟驱动天气与日历事件；快进期间的人生轨迹摘要供心智系统检索（反思/对话上下文，未实现）
