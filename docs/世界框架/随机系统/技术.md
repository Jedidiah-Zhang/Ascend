# 随机系统 — 技术

随机系统（Loom of Fate）提供世界级确定性随机源：`ascend/fate/` 负责种子派生与独立随机流，`ascend/save/manifest.py` 负责种子协议层序列化。

## 模块结构

```
ascend/fate/
├── __init__.py      # 公共 API 导出（LoomOfFate / FateStream / derive / format_fate_path / MASK_256）
├── derive.py        # 派生原语（sha256 规范编码，256-bit）
└── loom_of_fate.py  # LoomOfFate 织机 + FateStream 命运流
```

种子协议层（`SEED_MAX` / `parse_seed` / `seed_to_hex`）单源在 `ascend/save/manifest.py`。

## 派生原语（derive.py）

`derive(parent, *parts) -> int`：纯函数，同参同值，跨进程/跨平台位级一致。

- 编码：版本字节 `\x01` + parent 32B + 各分量类型标签/长度前缀
  - str：`b"s"` + 2B 长度前缀 + UTF-8 字节（>0xFFFF 抛 `ValueError`）
  - int：`b"i"` + 32B 有符号大端（±2^255，超出抛 `OverflowError`）
- 输出 = 完整 sha256 摘要 → 256-bit（0..2^256-1），碰撞抗性生日界 2^128
- **禁用内建 `hash()`**：PYTHONHASHSEED 按进程加盐，跨进程不确定
- 编码无歧义：`("a", 1) ≠ ("a1",)` 有测试锁定
- 分量为 str/int 之外类型抛 `TypeError`

## 命运织机（loom_of_fate.py）

### LoomOfFate

```python
loom = LoomOfFate(world_seed)                       # 世界根 seed（256-bit）
stream = loom.stream(entity_id="42", purpose="decision", tick=3912)
child = loom.domain("environment").domain("weather")  # 子织机（path 累积）
seed = loom.derive("world", "birth_point")          # 原始派生种子
```

- `derive(*parts)`：在织机作用域内派生种子（含 path 累积）。
- `domain(*names)`：创建子织机，path 累积；非 str 名抛 `TypeError`。
- `stream(*parts, entity_id?, purpose?, tick?, **extra)`：获取确定性随机流。
  - 身份规范（构造顺序固定）：path + parts + sorted(extra) 键值对 + entity_id + purpose + tick。
  - `domain("a").stream("b") ≡ stream("a", "b")`（有测试锁定）。

### FateStream

`FateStream(random.Random)` 子类，携带身份的确定性随机流：

- 身份派生：seed = `derive(root, identity)`，任何人可重算。
- 禁重播种：`seed()` 覆写为 `RuntimeError`——可复现性由身份派生保证。
- `fate_path`：身份可读字符串（str 分量 `/` 连接，末尾 int tick 渲染为 `@tick`；中间 int 分量如块坐标内联）。诊断/回放/事件溯源用，不承诺可解析回身份。
- `fork(*parts)`：以自身身份继续派生子流（身份 = 自身身份 + parts）。
- 构造绕过 `random.Random.__init__` 的 `self.seed(x)` 分派（会命中禁重播种覆写），直接以 C 级实现播种。

**MT-safe 方法约束**：黄金 hash 承诺路径只允许 `random/randint/randrange/uniform`（纯整数/乘法运算，位级稳定）；禁 `gauss/normalvariate/expovariate` 等走 `math` 超越函数的方法（末位平台相关）。现有天气用法已合规。

## 种子协议（manifest.py）

- `SEED_MAX = 2^256 - 1`（1..2^256-1；0 = 随机占位）。
- `seed_to_hex(seed) -> str`：小写 hex，无 `0x` 前缀，小 seed 短表示（`42` → `"2a"`；满宽度 256-bit 为 64 字符）。
- `parse_seed(raw) -> int`：hex 字符串 / int / None；`""`/`"0"`/None/纯空白 = 0（随机占位）；bool、`0x`/符号前缀、非法 hex、越界均抛 `ValueError`。

**协议边界**：map_preview / save_create / save_list / world_initialized 全部 hex 字符串化。Godot JSON 解析器原生仅 int64——256-bit 整数直传精度丢失。

**随机定案点**：map_preview 收到随机占位时后端 `randint(1, SEED_MAX)` 定案并随响应回传 hex 种子——前端预览与创建使用同一种子，确定性一致。种子唯一随机源 = 后端。

## namespace 登记

各系统在 `derive`/`stream` 中使用的命名空间分量（新增须登记）：

| 域 | 身份形状 | 消费者 |
| --- | --- | --- |
| `weather` | `("weather", "texture", "channel", name, i)` / `("weather", "texture", "wind")` / `("weather", "texture", "wind_dir", i)` / `("weather", "feature", "block", bx, by, "segment", seg_idx)` / `("weather", "proxy", "temp" / "rain")` / `("weather", "tile_noise")` | 天气场（atmosphere / features / field） |
| `world` | `("world", "birth_point")` | 出生点选择（game.py） |
| `npc`（规划） | `("npc", entity_id, purpose, tick)` | NPC 心智系统（动工前置：实体 ID 确定性） |

标签唯一性是**约定问题**（hash 只负责把标签差异扩散为流独立）。

## 整合点

- **WeatherEngine**（`weather/atmosphere.py`、`features.py`、`field.py`）：各通道/噪声 seed 经 `derive` 派生（见 namespace 表），替代裸 seed 偏移。
- **GameEngine**（`game.py`）：出生点 `pool[derive(seed, "world", "birth_point") % len(pool)]` 确定性选取；随机占位 `randint(1, SEED_MAX)` 定案；`world_initialized` 事件 seed 以 hex 字符串发布。
- **WorldTree**（`world_tree/event.py`）：`Event.fate_path: str | None` 字段——事件随机性来源的流身份（None = 事件不消费随机流）；归档落 SQLite `events.fate_path TEXT` 列。生产示例：天气降水事件 `"weather/precip/{cx}/{cy}@{tick}"`。
- **handlers**（`preview_handler.py`、`save_handler.py`）：seed 经 `parse_seed` / `seed_to_hex` 协议解析与序列化。
- **前端**（`map_step.gd`）：`SEED_HEX_MAX_LEN = 64`、`_is_valid_hex_seed` 校验（1..64 位 hex，无 0x 前缀，大小写均可，归一小写）；仅占位（未定案）时用后端预览响应回传的 seed 定案（在途旧响应不回写用户显式种子）。
