# 随机系统 — 技术

随机系统提供世界级确定性随机源：随机取值统一经
`backend/ascend/world/kernel/rng.py` 的地址纯函数（WC-5），
`ascend/world/kernel/` 负责种子派生与地址随机，
`ascend/save/manifest.py` 负责种子协议层序列化。命名空间与用途登记在
**机制声明**（`AddressUse(namespace, purpose)`，`world/modules/*`），
编译器校验全局唯一；打包身份由 `world/declarations/impl_digests.json` 承载。

## 模块结构

```
ascend/world/kernel/
├── rng.py        # Address / address_seed / address_value / draw_fixed（WC-5）
├── digest.py     # 规范字节编码与内容摘要（世界身份，WC-1.1）
└── fixed.py      # 定点原语（核心随机只提供整数与定点；浮点是孤岛的事）
```

种子协议层（`SEED_MAX` / `parse_seed` / `seed_to_hex`）单源在 `ascend/save/manifest.py`。

## 地址随机（rng.py）

```python
address = Address("weather", "proxy", ("temp",), time=0, draw_index=0)
seed = address_seed(world_seed, address)        # 256-bit 派生值
raw = address_value(world_seed, address, minimum=0, maximum=99)
q = draw_fixed(world_seed, address, bits=30)    # Q(30) 的 [0,1) 均匀值
```

- **地址 = 命名空间 + 实例 + 用途 + 时间 + 抽取序号**（WC-5.1）；不存在
  流状态、消费顺序或进度条（WC-5.2）。同一地址在任意两条干预臂中取值
  逐位相同——CRN 配对与反事实可复现的物理基础（WC-7.3）。
- 取值只依赖（世界种子, 地址）：换求值顺序、跳过、新增抽取都不改变既有
  地址；这正是地址纪律的结构性保证。
- 编码规则：版本字节 `\x01` + parent 32B + 各分量类型标签/长度前缀
  - str：`b"s"` + 2B 长度前缀 + UTF-8 字节（>0xFFFF 抛 `ValueError`）
  - int：`b"i"` + 32B 有符号大端（±2^255，超出抛 `OverflowError`）
- 输出 = 完整 sha256 摘要 → 256-bit（0..2^256-1），碰撞抗性生日界 2^128
- **禁用内建 `hash()`**：PYTHONHASHSEED 按进程加盐，跨进程不确定
- 编码无歧义：`("a", 1) ≠ ("a1",)` 有测试锁定（`backend/tests/world/test_kernel.py`）
- 256-bit → 离散区间用**取模映射**（WC-5.6）：span ≤ 2⁶⁴ 时分布偏差
  ≤ 2⁻¹⁹²，视为可忽略

## 命名空间登记

命名空间与用途是**声明的一部分**：机制声明的 `AddressUse(namespace, purpose)`
（`world/meta/declarations.py`）进模块摘要与世界身份；编译器拒绝重复的
（命名空间, 用途）组合（`world/compile/compiler.py`）。研究观测噪声的地址
由 `ObservationSpec.noise_address` 声明。

## 消费点

- **WeatherEngine**（`weather/atmosphere.py`、`features.py`、`field.py`）：
  各通道/噪声 seed 经 `Address` + `address_seed` 派生（结构化分量序）；
  纹理/代理/特征段/瓦片噪声各占独立地址。
- **GameEngine**（`game.py`）：出生点
  `pool[address_seed(seed, Address("world", "birth_point")) % len(pool)]`
  确定性选取；随机占位 `randint(1, SEED_MAX)` 定案；`world_initialized`
  事件 seed 以 hex 字符串发布。
- **研究层**（`world/research/`）：观测噪声、控制世界与 CRN 配对全部经
  地址随机；验收 L3-CRN 断言未干预地址逐位一致。
- **WorldTree**（`world_tree/event.py`）：`Event.address_path: str | None`
  字段——事件随机性来源的**溯源标签**（None = 事件不消费随机地址）；
  归档落 SQLite `events.address_path TEXT` 列。生产示例：天气降水事件
  `"weather/precip/{cx}/{cy}@{tick}"`。
