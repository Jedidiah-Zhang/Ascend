# 群系生态 — 技术

## 群系数据

- 每个群系类型一个 `BiomeTemplate`，定义：TerrainBias（地形偏移）、生态参数（water/mountain/tree_ratio）、生物列表（权重，未消费）、资源列表（权重，未消费）
- 分块生成时由 `biome_from_attrs()` 算主隶属群系，取模板实例化
- 16 陆地群系 + 3 海洋群系，枚举 `BiomeType`（int 0-18）

## 群系细分

每气候档 2 个子型，细分维度用连续场：

```python
@dataclass
class _SubdivConfig:
    dimension: str        # "rainfall"/"temperature"/"altitude"/"moisture"
    low: BiomeType        # 低端子型
    high: BiomeType       # 高端子型
    value_min: float      # 归一化下限（大陆场实际值域）
    value_max: float      # 归一化上限
    split: float = 0.5    # 分界点
```

`biome_membership(attrs)` 返回 `[(BiomeType, weight), ...]`，权重和为 1.0。三角形隶属函数：
```
c_lo=0.25, c_hi=0.75
w_lo = max(0, 1 - |v - c_lo| / 0.5)
w_hi = max(0, 1 - |v - c_hi| / 0.5)
归一化后 w_lo + w_hi = 1
```

边界处（v≈0.5）两权重各 0.5 → 平滑混合。

## TerrainBias — 群系对地形分类的偏移

```python
@dataclass(slots=True)
class TerrainBias:
    rock_line_delta: float = 0.0     # 岩线海拔偏移 (m)，+值=更高海拔才出岩石
    arid_rainfall_mm: float = _ARID_RAINFALL_MM  # 干旱降雨阈值 (mm/年)
    beach_band_m: float = _SAND_BEACH_BAND_M     # 沙滩带宽 (m)，距水 < 此值 → SAND
    alluvial_band_m: float = _ALLUVIAL_BAND_M    # 冲积带宽 (m)，距水 < 此值 且低海拔 → FERTILE_SOIL
    marsh_tendency: float = 0.0      # 沼泽倾向 [0,1]，距水近 + 湿度判 MARSH 的加成
    permafrost_temp_c: float = _PERMAFROST_TEMP_C  # 冻土线温度 (°C)，年均温低于此 → PERMAFROST
```

基线 = `TEMPERATE_DECIDUOUS_FOREST`（全默认 = config 阈值）。tile 生成时
`bias = Σ weight_i × bias_i`，数值字段加权平均。chunk 边界因连续场 →
隶属度连续 → bias 连续 → 材质连续。字段名与层次分类规则的对应见
地图生成/设计.md 的层次规则（issue #42 重构：岩线/干旱/沙滩带/冲积带/
沼泽倾向/冻土线取代旧海拔带偏移）。

`creature_weights` / `resource_weights` 不混合，按主隶属选单一模板。

## 微地形生成

- tile 生成时从层1宏观场采样 chunk 级气候属性（温度/降雨取 chunk 中心值），海拔与 moisture 噪声逐 tile 变化
- `biome_membership()` 算隶属度 → 混合 TerrainBias
- `_classify(macro_elev, slope, water_dist, temp, rain, moisture, bias)` 按层次规则判定地表材质（输入全为低频连续场，细节噪声退出分类——见地图生成/技术.md）
- 群系模板定义子区域类型和出现概率，叠加噪声细节决定微地形
- 子区域边界自然渐变（隶属度混合），不硬切

## 积雪

积雪线**不作为群系**——它的范围会随季节变化。雪顶不硬编码装饰：高海拔低温
（天气温度场在 chunk 级已含海拔直减）→ 覆雪状态自然累积、低温不融，
形成动态雪线（见《地形状态/设计.md》）。

## 群系存在性

不强制保证子型存在。细分维度 value_min/value_max 基于大陆场实际值域（非理论极值），保证统计上大概率出现。稀有群系（出现但范围小）是重玩价值的来源。

诊断：跑多 seed 统计每个子型出现面积，确认无"理论存在但概率趋零"的设计失误。

## 生物种群（未实现）

- 规划：每个分块维护该群系下的生物种群计数（不追踪每个个体的实时位置）
- 离屏时种群按生态模型自周转（捕食-繁殖-死亡）
- 玩家进入时种群实例化为具体生物个体，分布到子区域

当前无实现：`creature_weights` / `resource_weights` 仅为模板数据，无消费方。

## 群系扩展

- 新增群系子型只需要：在 `data/biome.json` 加一项（`value` 追加 + `label_key`
  + `climate` 引用 + 生态参数 + `terrain_bias` + 权重），并视需要更新其
  `subdiv` 细分配置——`BiomeType` 枚举/`BiomeTemplate`/`_SUBDIV_CONFIGS`
  由数据驱动，算法代码零改动
- 不需要改 tile 生成代码（TerrainBias 自动生效）

## 整合点

群系模块是纯数据层，不包含运行时服务（无状态、无事件发布/订阅）。
