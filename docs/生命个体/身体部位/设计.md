# 模块化身体部位

> **本模块未实现**——以下为设计意图。

每个个体的身体**完全由基因组合构建**（morphogenesis）。不存在独立于基因的"物种形态"——物种只是出生基线（一套预设基因组合）。部位是模块化的——基因决定了长什么样，受伤时部位独立追踪。

## 身体结构

基因组合 → **身体语法（body grammar）** 解析 → 完整骨架：

```json
{
  "genome": {
    "axial":   { "segments": 2, "length": 1.0, "posture": "upright" },
    "limbs":   [
      { "type": "leg", "count": 2, "origin": 1, "length": 1.0 },
      { "type": "arm", "count": 2, "origin": 0, "length": 0.8 }
    ],
    "head":    { "eyes": 2, "ears": 2, "horns": 0, "gills": false },
    "tail":    null,
    "wings":   null
  }
}
```

解析输出：

- **身体轴**（躯干段数/长度/姿态）→ 挂点坐标系
- **附肢**沿轴挂载（类型 × 数量 × 挂点段位 × 长度）
- **头部**装配（感官器官/角/口器/鳃）
- **功能映射**：腿→移动、翼→飞行、鳃→水下呼吸

**物种 = 出生基线**：`human_base` 是一组预设基因组合（直立 2 段 + 2 腿 2 臂 + 头部感官），不是独立的形态事实源。四足/鸟类/爬行只是不同的基因组合——基因编辑/育种/从零创造改变组合，形态随之改变。

**合法性约束**：语法校验拒绝非法组合（无移动手段、头部无感官、附肢数量超限等），后端生成时校验。

- 部位和功能挂钩：有翅膀才能飞，有鳃才能水下呼吸。部位受伤 → 功能降级或丧失
- 同一物种的个体结构可以不同（基因组合不同），实体系统因此拒绝类型继承树（见 实体系统/设计.md）

## 外伤

外伤具体到部位和类型，直接映射为 visible 标签：

| 外伤类型 | 表现 | 来源 |
|---|---|---|
| 割伤 | 部位健康↓，持续出血 | 利器、野兽爪击 |
| 瘀伤 | 部位健康↓，无出血 | 钝器、摔伤 |
| 烧伤 | 部位健康↓ | 火、高温 |
| 骨折 | 部位功能严重受限或丧失 | 重击、坠落 |
| 缺失 | 部位永久消失，功能归零 | 极端伤害、手术 |

## 内伤与疾病

不需要部位定位，用标签 + 严重度管理：

- **hidden 类**（需检查）：内出血、器官损伤、感染初期
- **visible 类**（外在症状）：发热、咳嗽、皮疹、呕吐
- **长期标签**（已确诊或持续）：慢性病、基因缺陷病、后遗症（"左腿旧伤，阴雨天疼"）

疾病有发展过程——感染从轻微到严重，治疗可截断。

## 基因与部位

| 基因方向 | 效果 |
|---|---|
| 轴向基因 | 躯干段数/长度/姿态——决定整体体型 |
| 附肢基因 | 腿/臂/翼/触角：类型 × 数量 × 挂点段位 |
| 头部基因 | 感官器官、角、口器、鳃 |
| 厚皮/甲壳 | 割伤/瘀伤减免 |
| 骨骼强化 | 骨折阈值提高 |
| 再生能力 | 部位自愈速度↑ |
| 免疫强化 | 感染概率↓、疾病进展更慢 |
| 凝血增强 | 出血时间缩短 |

## 假肢

部位缺失可被制作系统填补——义眼、义肢。假肢可附带原装部位没有的功能（工具手、夜视义眼）。基因做不到的，科技来补。槽位始终保留，可替换、可升级。

## 渲染约定

渲染层照抄同一抽象：body grammar 输出槽位表与层列表，`pawn_renderer` 按槽位叠加部件资产（见 表现层/视觉风格/设计.md）。部件资产按「部位类型 × 形态变体」组织（leg_2/leg_4/wing_avian/wing_bat…），不按物种组织。
