# 世界契约

> **版本**：v0.1（草案）
> **地位**：本文件是 Ascend 因果世界（第一阶段：世界基座）的唯一规范源。
> **语气三分**（正文中以「规范 / 说明 / 实现注记」标注）：
>
> - **规范**：必须成立，可以违反，可以判定；
> - **说明**：为什么这样定，引用《研究综述》与《工程符号体系》；
> - **实现注记**：当前代码位置与做法，不具规范效力。
>
> 理论记号沿用《[研究综述](研究综述.md)》；工程术语沿用《[工程符号体系](工程符号体系.md)》。若有冲突，以本契约为准。

## WC-0 定位与范围

**WC-0.1 承诺范围**（规范）
本契约只对**已声明的世界切片**承诺。第一阶段只含世界基座：世界如何生成、演化、被干预、被重放；**不含智能体**。观测映射 G、行动映射 Γ、冲突解析 Res 仅作为预留接口存在。

- 依据：综述 §1.1 / §1.2 的阶段划分；§2.2 智能体接口。
- 违反判据：任何验收依赖未声明切片的机制；或把智能体相关结论当作第一阶段交付。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

**WC-0.2 唯一规范源**（规范）
关于世界语义的规范陈述只能出自本契约。其他研究文档、设计文档只能引用条款，或明确标注为实现注记。

- 违反判据：两份文档对同一语义给出不同且都自称规范的陈述。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

**WC-0.3 真值地位**（规范）
世界语义以**可执行离散语义**为真值：状态值定义在声明的刻度上；机制在声明的算术域与舍入规则下求值；论文与文档中的实数公式只是意图说明。

- 依据：综述 §2.1（W_t 与 F）；设计决定 D1。
- 违反判据：同一输入在不同平台或不同求值顺序下产生不同结果；或机制语义依赖未声明的浮点行为。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-1 世界身份

**WC-1.1 身份组成**（规范）
世界身份 =（契约版本，世界种子，参数集 θ，结构声明摘要，数值内核与预计算表摘要，随机算法标识与地址登记摘要）。

**WC-1.2 身份变更**（规范）
身份任一组分发生变化即为**新世界**。轨迹、快照、实验产物必须携带身份摘要；对不上即拒绝。

**WC-1.3 因果结构可改**（规范）
世界的因果结构（变量、依赖边、机制）是**声明数据**，可以增删改。调整结构 = 生成新世界；**不在一局运行内修改**。需要"规律中途变化"的研究场景，由世界自身声明切换计划，作为后续阶段的特性引入。

**WC-1.4 世界族与跨世界配对**（规范）
同契约版本、同声明格式、仅结构或参数不同的一组世界称为**世界族**。跨世界实验必须显式声明族成员与配对方式（通常共享同一实验单位 ω）。

- 依据：综述 §1.1（研究者定义状态、规律与因果关系）；设计决定 D3。
- 违反判据：结构变化后沿用旧身份摘要；跨世界比较未声明配对；运行中静默更换规律。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-2 空间

**WC-2.1 空间域**（规范）
空间域 S 有限、可索引，具有声明的邻接与边界结构。空间声明是世界的组成部分，进入身份摘要。

**WC-2.2 支撑域**（规范）
每个机制显式声明其空间偏移集合、边界算子、聚合与广播规则。影响只能沿声明路径传播。

**WC-2.3 无隐式耦合**（规范）
禁止机制读取声明之外的量；禁止未声明的全局量参与求值。

- 依据：综述 §2.1、§2.4.2；工程符号体系 §3.2。
- 违反判据：在声明无路径的两个位置之间出现可测影响；机制读取未登记的全局变量。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-3 状态

**WC-3.1 槽位字段**（规范）
状态空间是**槽位**的积。每个槽位必须声明：标识；载体（场 / 实体 / 全局）；值域（类型、单位、刻度与分辨率、缺失值）；持久类（状态 / 派生 / 参数）；更新位置（阶段/微步）；权限（可干预 / 可观测 / 可记录）；所有者（产生它的机制）。未登记的槽位不存在。

**WC-3.2 闭合公理**（规范）
W_t 是未来演化的**充分统计量**：给定 W_t、未来干预序列与 ω 后缀，未来轨迹唯一。凡影响未来的信息都必须有槽位；删除全部派生数据并重算后，后续轨迹不变。

**WC-3.3 义务即状态**（规范）
排队事件、延迟结算、积分状态、时间相位等"欠未来的账"必须作为状态槽位登记，并声明其结算规则。

**WC-3.4 持久类**（规范）
状态是 W_t 的组成部分；派生是 W_t 的纯函数，只读、不得影响未来（若影响，则升格为状态）；参数定义世界实例，世界内不可改，改变参数 = 换世界。

**WC-3.5 规范编码**（规范）
相等、序列化与摘要使用同一份**规范编码**。"同初态"定义为：全部状态槽位的规范编码逐位相等。

**WC-3.6 权限与可干预性**（规范）
只有声明为可干预的槽位能作为干预目标。纯读出（没有更新点、没有下游消费者）不可干预。

- 依据：综述 §2.1、§2.2（W_t 与观测边界）；工程符号体系 §2。
- 违反判据：未来轨迹依赖未登记状态（缓存、全局变量、文件、时钟）；删除派生数据后轨迹改变；未登记槽位被干预。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-4 演化与数值内核

**WC-4.1 机制与微步**（规范）
F = F^(R) ∘ … ∘ F^(1)。每个机制声明：标识；读集坐标（同帧更早微步，或带 lag 的帧边界值）；写集；参数；随机地址；定义域与值域。声明的因果结构由这些接口构成。

**WC-4.2 求值纪律**（规范）
每个槽位在每阶段至多一个写者；同阶段并行机制只读取该阶段开始前已确定的值；时间展开图无环；求值顺序由图导出，不由调度或调用顺序决定。

**WC-4.3 机制无内部持久内存**（规范）
机制是声明输入到输出的纯函数。跨帧记忆只能是状态槽位。

**WC-4.4 数值内核**（规范）
状态值是声明刻度上的整数。允许的基本运算是一份封闭清单：加减乘除（带缩放与舍入）、取整、限幅、溢出规则、整数开方、查表插值。超越函数（正弦、指数、对数等）以**预计算表**（摘要进世界身份）或声明过的整数算法实现。语义核禁止 `math`、浮点字面量、numpy。确需浮点的机制作为**孤岛**：必须声明固定求值序与舍入规则，附误差界，且误差远小于状态刻度。

> **说明（工程选择边界）**：定点、预计算表与语义核禁 `math` 是**为满足综述"可控制、可追溯、可复现"而选择的工程约束**，不是综述的直接义务——若采用浮点，按"孤岛"规则（固定求值序、舍入与误差界）即可。

**WC-4.5 确定性卫生**（规范）
时钟、外部 I/O、未声明熵、无序集合迭代、并行完成顺序、内存布局均不得影响求值结果。

- 依据：综述 §2.1（F 的分解与函数性）；工程符号体系 §3；设计决定 D1。
- 违反判据：同一机制在两次求值或两个平台上产生不同结果；机制携带跨帧私有状态；语义核出现浮点运算。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-5 随机

**WC-5.1 地址 → 值**（规范）
随机值是（算法标识，世界种子，地址）的**纯函数**。地址 = 命名空间 + 实例 + 用途 + 时间 + **抽取序号**。不存在流状态、消费顺序或进度条。

**WC-5.2 顺序无关、缺抽不回收**（规范）
任意抽取顺序、跳过、新增，都不改变其他地址的值。被跳过地址永不重新编号。

**WC-5.3 稳定身份**（规范）
地址中的实例标识必须稳定：坐标、出生时派生的 ID 等。禁止 `uuid4`、数组下标、遍历序号、内存地址。

**WC-5.4 显式共享**（规范）
相关随机只能通过相同地址或声明共享的随机源产生；禁止隐式相关（如依赖调用顺序）。

**WC-5.5 地址登记**（规范）
全部命名空间与用途登记为机器可读数据；其摘要进入世界身份。

**WC-5.6 范围映射**（规范）
256 位整数到离散区间的映射规则必须声明（如取模；偏差量级 ≤ 2⁻¹⁹² 视为可忽略）。核心语义不提供随机浮点；确需时走 WC-4.4 的浮点孤岛。

**WC-5.7 批量噪声**（规范）
噪声场由地址派生的种子驱动；噪声生成算法属于机制，受 WC-4 全部约束。

**WC-5.8 记录**（规范）
研究记录保存**结构化地址**（值可由种子与地址重算）；人类可读路径仅作展示。

- 依据：综述 §2.1（U_t 与平行世界共享随机）；工程符号体系 §4；设计决定 D4。
- 违反判据：同一地址在两条干预臂中取值不同；改变无关执行路径后其他地址取值改变；地址依赖不稳定身份。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-6 干预

**WC-6.1 定义与注入点**（规范）
值干预 do(v ← x)：在槽位 v 的声明更新点，把本帧生成结果替换为 x，并断开 v 的原入边；v 在本帧不更新时，替换其帧初携带值。机制/结构替换不属于世界内干预（见 WC-1.3）。

**WC-6.2 记录**（规范）
干预以**逐帧独立记录**进入时间线，只追加。同一帧、同一目标出现多条记录时，后到覆盖先到；持续干预 = 窗口内逐帧记录；撤销 = 后续帧不再记录，既有记录不改写。

**WC-6.3 校验**（规范）
执行前校验：目标槽位存在、取值属于值域、槽位允许干预、注入点已接线。任一不满足即拒绝（fail-closed）。

**WC-6.4 传播**（规范）
干预效果只沿干预后图的后代传播；干预结束后世界自然演化，不自动恢复干预前的值。

**WC-6.5 外部性**（规范）
干预属于外部输入 I_t，不属于 W_t。快照只包含已发生的记录；未来干预由实验计划提供。

- 依据：综述 §2.1、§2.4.2；设计决定 D2。
- 违反判据：撤销干预改写历史帧结果；干预结果与"机制恰好算出该值"在数值上不可区分之外还留下别的痕迹；未接线目标被静默忽略。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-7 轨迹、配对与反事实

**WC-7.1 轨迹唯一性**（规范）
轨迹 =（世界身份，W₀，干预记录序列，ω）↦ {W_t}。输入固定后轨迹唯一。

**WC-7.2 同初态与实验单位**（规范）
"同初态" = 状态槽位规范编码逐位相等；"同实验单位" = 共享世界种子、随机算法标识与地址空间。

**WC-7.3 CRN 配对**（规范）
以同初态、同 ω、不同干预序列运行的多条轨迹构成配对；未干预地址的随机值逐位相同。

**WC-7.4 反事实**（规范）
从任意帧 t 的完整状态出发，保持 ω 后缀、更换干预序列，得到唯一反事实轨迹；t 之前的事实前缀逐位不变。

**WC-7.5 重放与检查点充分性**（规范）
快照 + 后续输入重放，必须与不中断运行逐位一致。这构成"完整状态"的操作定义。

**WC-7.6 帧原子**（规范）
世界状态只在帧边界提交；不存在任何边界处可见的部分提交。

- 依据：综述 §2.1（平行世界式）、§2.4.2；工程符号体系 §4。
- 违反判据：同输入两次运行结果不同；反事实运行改变事实前缀；从快照继续与不中断运行分叉。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-8 存档与版本

**WC-8.1 快照内容**（规范）
快照 = 规范编码的完整状态 + 已发生的时间线前缀 + 实验上下文（身份、种子等）。派生数据不进入快照。

**WC-8.2 原子性**（规范）
快照写入原子：要么完整，要么不存在。任一环节失败即快照失败。

**WC-8.3 身份校验**（规范）
契约版本、结构摘要、算法标识、数值内核/表摘要不匹配时拒绝加载。不提供迁移承诺。

- 依据：设计决定 D2/D3/D5；工程符号体系 §4。
- 违反判据：读档得到与不中断运行不同的未来；部分写入被当作有效快照；身份不符仍加载。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-9 失败语义

**WC-9.1 定义域**（规范）
F 是部分函数：每个机制声明定义域；越界或未分类输入即失败，不得静默截断（除非截断本身是声明过的机制语义）。

**WC-9.2 轨迹作废**（规范）
帧计算失败 → 该轨迹作废；失败点之后的输出不具真值地位。

**WC-9.3 表现层降级**（规范）
画面、提示、网络展示可以降级，但不得回写世界语义。

**WC-9.4 数值边界**（规范）
溢出、NaN/无穷的产生与传播规则必须声明。

- 依据：综述 §2.1（F 的定义域）；设计决定 D1。
- 违反判据：机制报错后世界继续推进并被当作有效轨迹；NaN 静默扩散进入存档；表现层故障改变轨迹。
- 证据：见对账表（`research/acceptance/clause_evidence.py`）。

## WC-10 记录与观测

**WC-10.1 双通道**（规范）
研究记录（全真值）与观测 G 严格分离。G 只在帧边界取值，是状态的纯函数，按槽位声明的可见性、量化与缺失规则生成。

**WC-10.2 无泄漏**（规范）
调试字段、事件载荷、缓存、存档都不得绕过 G 向观测通道泄露真值。

**WC-10.3 预留接口**（规范）
行动 → Γ → I 与冲突解析 Res 的接入点保留；智能体内部状态不属于 W（后续阶段按其契约声明）。

**WC-10.4 记录是证据**（规范）
记录可重算、有界；研究协议要求记录时，记录缺失即失败。

- 依据：综述 §2.2、§2.4；工程符号体系 §6。
- 违反判据：观测包含真值字段；观测可在帧内多次读取；G 依赖研究记录。
- 证据：条件性接口；见对账表（`research/acceptance/clause_evidence.py`）。

## WC-11 治理

**WC-11.1 条文语气**（规范）
条款编号 WC-x.y；三类语气（规范 / 说明 / 实现注记）必须可区分。实现注记不具规范效力。

**WC-11.2 证据对账**（规范）
每条规范条款至少对应一条正例检查与一条只破坏该条件即变红的负例。CI 双向覆盖：无检查的条款与无条款的检查都视为失败。骨架见附录 B。

**WC-11.3 变更流程**（规范）
条款变更升契约版本；仅声明数据变更（结构、参数、切片）= 新世界身份，契约版本不动。实验产物记录两者。

**WC-11.4 文档从属**（规范）
《第一阶段实施定义》《世界基座》各篇等降级为实现注记，只允许引用条款。状态表、机制表由声明数据生成或校验。

## 附录 D 声明数据格式（草案）

声明数据与正文条款绑定；文件位置与命名可调，语义以条款为准。声明载体为
**模块声明**（`backend/ascend/world/modules/*`，Python 冻结数据类；内容参数在
`data/*.json`），研究侧投影为 `research/equations/equations.json`（生成物，禁止手改）。

### D.1 状态槽位声明（模块声明，`world/meta/declarations.py`）

槽位声明字段：`id`（点分小写）、`on`（载体实例类型：`global` / `lattice.*` / `entity.*`）、
`persist`（`state` / `derived` / `parameter` / `external`）、`domain`（类型/字宽/上下界/单位/缺失/枚举）、
`permissions{intervene, observe, record}`、`writer`（state/derived 必填单写者）、`recompute`（derived 必填）、
`initial`，以及研究投影元数据（`role` / `schedule` / `quantization` / `metric` / `valid_domain` /
`epsilon` / `external_source` / `external_writer` / `access_interventions` / `research_trace` /
`observation_protocols`，见 D.2）。字段级不变量在声明构造时拒绝；集合级校验（引用存在、单写者、
无环、值域、见证）在编译器完成。

- 场粒度：`lattice` 实例槽位按实例坐标取值（流式 lattice 的实例为 chunk 坐标）：field 作用域机制在实例内逐格求值，实例值为逐格数组；instance 作用域机制每实例求值一次，实例值为标量；非场槽位挂在 `global` 单例或 `entity.*` 实例；
- 参数由 `ParameterDecl` 承载（默认值/值类型/范围/单位/来源/是否可干预），不占槽位；
- 未认证的研究元数据不写占位值：投影期 fail-closed 拒绝（不存在"待定字段"通道）；
- 规范摘要：`module_digest` = 声明 + 各机制实现源码 + 源文件依赖内容的规范摘要（`world/meta/validate.py`），
  进世界身份；
- 规范编码（WC-3.5）：状态槽位按 `id` 排序；标量原样，定尺寸场按行主序值序列，流式场按坐标升序的条目；相等、序列化与摘要共用同一份规范载荷（规范 JSON：键排序、紧凑分隔符、UTF-8，见 `world/kernel/digest.py`）。

### D.2 机制接口声明（模块声明 + equations.json 投影）

机制声明的**事实源**是模块声明（`backend/ascend/world/modules/*`，实现绑定在
`world/meta/declarations.py` 的 `MechanismDecl`），研究侧投影为
`research/equations/equations.json`（生成物，禁止手改）。每条机制：`id`、`output`（输出槽位）、`equation`（规范语义
字符串，可执行子集）、`function`（实现）、`parents[]`、`parameters[]`、
`random_sources[]`、`boundary_cases[]`、`witnesses[]`；每条父引用：
`{parent, argument, lag, source_microstep, spatial_offsets, entity_relation,
aggregation, broadcast, boundary_operator, guard, metric, valid_domain,
analysis_role, modulus_kind, lipschitz, jump_bound}`。

**误差界元数据（`modulus_kind`；误差传递语义）**：

- `modulus_kind = "linear"`：`lipschitz: float ≥ 0` 必填，且必须通过见证
  否证器核验（任一见证两点差商 ≤ L）；不得携带 `jump_bound`；
- `modulus_kind = "jump"`：`lipschitz` 必须缺省（不存在连续性声明），
  `jump_bound: float > 0` 必填（有界跳变）；
- 传播：线性边参与路径乘积；跳变边的下游目标只报"条件成立（路径含跳变边）"，
  **不得按 0 静默计入解析界**；
- 节点误差元数据：`math.error_budget`（ε）与 `valid_domain`。ε 是不可由实现
  推导的**经验前提**，须遵守"不双计"：确定性派生量不另立 ε，其不确定性经
  父节点传播；未声明即"未认证"（fail-closed）；
- 证据分级：`witnessed`（否证器通过）与 `derived`（包络层推导，见
  `research/equations/enclosure.py` 与 V5 包含对拍）在报告与后续 `certificate` 中区分。

约束：写集互斥（单写者）；读坐标满足 WC-4.2；地址满足 WC-5；误差界输出须
通过 G3/G7 门禁（缺证/矛盾即红，无宽容默认）。

### D.3 随机地址登记（机制声明内联）

登记载体：机制声明的 `AddressUse(namespace, purpose)`（`world/meta/declarations.py`）；
研究观测噪声的地址由 `ObservationSpec.noise_address` 声明。`(namespace, purpose)`
全局唯一由编译器校验（重复即拒绝），并进模块摘要与世界身份。

- 取值：`(ALGORITHM, 世界种子, 地址)` 的纯函数（WC-5.1）；地址分量序 =
  命名空间 + 实例 + 用途 + 时间 + 抽取序号；256-bit → 离散区间用取模映射（WC-5.6）；
  实现：`ascend/world/kernel/rng.py`（地址分量按类型标签编码：字符串带 2 字节长度
  前缀，整数固定 32 字节补码；`sha256` 派生 256 位值后取模映射）。

### D.4 世界身份（`WorldProgram`，进 manifest）

- 程序身份 `program.identity` = 契约 + 模块摘要（含实现源码与源文件依赖）+
  参数值 + 旋钮 + 调度 + 内核摘要的规范摘要（`world/compile/compiler.py`）；
- 世界身份 `world_identity(seed)` = 程序身份 + 种子的规范摘要（WC-1.1）；
- manifest 记录声明视图（`declaration_settings()`：声明 ID + 程序身份 + 观测协议
  版本摘要）与程序视图（`settings()`：身份 + 契约 + 内核 + 模块摘要）；读档比对
  不一致即 fail-closed 拒载。

### D.5 条款↔证据（对账表）

字段：`clause`、`checks[]`、`positive`、`negative`、`status`。
