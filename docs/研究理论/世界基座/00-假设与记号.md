# 世界基座 00：假设与记号

## 1. 文档定位

本目录服务于第一阶段“可执行的因果真值”。全局概念和符号以[研究综述](../研究综述.md)为准，本篇只给出数学附件共同使用的速查定义。世界基座讨论声明和引擎是否一致，以及这些声明在给定假设下具有哪些数学性质；它不默认智能体能够观察完整状态，也不把引擎真值的存在等同于学习者能够识别真值。

数学陈述统一标记为以下类型：

| 类型 | 含义 |
| --- | --- |
| 定义 | 规定本文采用的对象或术语 |
| 设计约束 | 为使研究协议闭合而要求实现满足的条件 |
| 文献结果 | 在明确假设下直接采用的已有结论 |
| 已证明命题 | 本项目给出纸面证明或可核验形式化证明的结论 |
| 待证明命题 | 尚不能作为研究结论使用的猜想 |
| 经验假设 | 需要由数据检查其适用性的条件 |
| 实验判据 | 对某个具体构造预先规定的通过标准 |

探针与数值实验只能支持某个具体构造与预测一致，不能把文献结果或一般命题“实验性证明”为真。

## 2. 世界与状态

世界规范统一记为 $\mathfrak W$，环境状态统一记为 $X_t$，二者不得重用同一符号：

$$
\mathfrak W=
\left(
\mathcal S,
\mathcal V,
\{\mathcal J_v,\mathcal X_v,\rho_v\}_{v\in\mathcal V},
\Theta,P_0,
\mathcal E^{\mathrm{world}},P_E,
\mathcal F,\prec,\mathcal D
\right),
$$

$$
X_t=\left(X_{v,t}(j)\right)_{v\in\mathcal V,\,j\in\mathcal J_v}.
$$

逻辑帧内部使用微步 $r\in\{0,\ldots,R\}$。$X_t^{-}$ 是观测前干预到达前的边界状态，$X_t=X_{t,0}$ 是观测前干预后的状态：

$$
X_t^{-}\xrightarrow{\mathbf d_t^{\mathrm{pre}}}X_t=X_{t,0}
\rightarrow X_{t,1}\rightarrow\cdots\rightarrow X_{t,R}=X_{t+1}^{-}.
$$

时间展开节点记为 $(v,j,t,r)$。时间展开图记为 $G^{\mathrm{unroll}}$。如果节点 $u$ 是节点 $v$ 的直接父节点，记为 $u\in\operatorname{Pa}_{G^{\mathrm{unroll}}}(v)$。同一逻辑帧内的边必须遵守微步偏序 $\prec$，跨逻辑帧的边必须指向未来，因此 $G^{\mathrm{unroll}}$ 无环。

对变量实例 $(v,j)$ 的更新方程统一写为：

$$
X_{v,t,r}(j)
=
f_{v,r}\left(
X_{\operatorname{Pa}(v,j,t,r)},
E^{\mathrm{world}}_{v,j,t,r};\theta
\right).
$$

固定 $X_{0,0}$、全部外生实现、干预计划和行动计划后，方程必须唯一确定轨迹。固定延迟、积分器、事件队列和动态随机场如果影响未来，都属于 $X_t$ 的组成部分。

## 3. 随机性

本研究使用下列随机源：

| 记号 | 含义 |
| --- | --- |
| $E^{\mathrm{world}}$ | 世界结构方程的外生随机源 |
| $E^{\mathrm{obs},i}$ | 智能体 $i$ 的观测噪声 |
| $E^{\mathrm{policy},i}$ | 智能体 $i$ 的学习和决策随机源 |
| $E^{\mathrm{resolve}}$ | 多智能体冲突解析随机源 |
| $P_0$ | 初始完整状态分布 |
| $P_E$ | 原始外生源的联合分布 |

**设计约束**：原始随机源按稳定地址独立派生。需要共享原因或时空相关时，使用显式共享外生变量或动态随机场表示。经过共享变量生成的下游噪声可以相关，但不能继续被称为相互独立的原始噪声。

长度为 $T$ 的随机实验单位统一记为：

$$
\omega=
\left(
X_{0,0},
E^{\mathrm{world}}_{0:T},
\{E^{\mathrm{obs},i}_{0:T}\}_{i\in\mathcal N},
\{E^{\mathrm{policy},i}_{0:T}\}_{i\in\mathcal N},
E^{\mathrm{resolve}}_{0:T}
\right).
$$

其中 $\mathcal N$ 表示实验涉及的全部主体。同一 $\omega$ 的不同干预臂构成 CRN 配对；不同重复使用独立 $\omega$。完全观察 $X_t$ 本身不保证外生实现可恢复，第一阶段依赖引擎记录或可重算随机地址取得外生真值。

## 4. 干预与干预后图

单个干预统一记为：

$$
d=(T_d,\tau_d,\mathrm{rep}_d,\mathrm{dur}_d,\mathrm{ver}_d,\mathrm{pri}_d)\in\mathcal D.
$$

$T_d$ 是目标，$\tau_d=(t,r)$ 是开始时间和微步，$\mathrm{rep}_d$ 是替代值或替代机制，$\mathrm{dur}_d$ 是持续范围，$\mathrm{ver}_d$ 是处理版本，$\mathrm{pri}_d$ 是冲突优先级。干预类型由目标、替代物和持续范围的组合读出。多个干预组成计划 $\mathbf d$。

节点 hard-do 写为 $do(X_{v,t,r}(j)=x)$，含义是只替换该时间节点的结构方程。机制干预写为 $do(f_v\leftarrow f'_v)$。参数干预写为 $do(\Theta=\theta')$，并作为环境变化单独报告。行动干预写为 $do(A_t^i=a)$，只替换该行动节点的策略方程。

对干预目标集合 $I$，将目标节点的原入边删除并接入替代方程，所得图记为：

$$
G^{\mathrm{unroll}}_{\bar I}.
$$

干预后的祖先、路径和误差传播都只在 $G^{\mathrm{unroll}}_{\bar I}$ 中计算。

## 5. 观测与系统状态

智能体观测统一写为：

$$
O_t^i=g_i(X_t,B_t^i,E_t^{\mathrm{obs},i}),
$$

交互历史统一写为：

$$
H_t^i=(O_0^i,A_0^i,\ldots,A_{t-1}^i,O_t^i).
$$

智能体世界模型对查询 $q$ 的输出统一写为：

$$
\widehat P_i(O_{t+1:t+k}^i\mid H_t^i,q).
$$

完整闭环系统状态统一记为：

$$
\Sigma_t=(X_t,\{M_t^i\}_{i\in\mathcal N_t}).
$$

身体状态属于 $X_t$，记忆、信念和可学习策略参数属于 $M_t^i$。它们对其他智能体不可见，不代表它们可以从研究者定义的闭环状态中省略。

## 6. 查询与可识别性

候选世界模型类记为 $\mathfrak U$，数据协议记为 $\Pi$，目标查询记为 $Q$。查询在 $(\mathfrak U,\Pi)$ 下可识别，当且仅当：

$$
P_{U_1}^{\Pi}=P_{U_2}^{\Pi}
\Longrightarrow
Q(U_1)=Q(U_2),
\qquad
\forall U_1,U_2\in\mathfrak U.
$$

实验查询规格记为：

$$
\mathcal Q=(\mu_H,\nu_d,\nu_k,\phi,q_{\mathrm{mode}}).
$$

$\mu_H$ 是起始历史或状态分布，$\nu_d$ 是干预分布，$\nu_k$ 是预测地平线分布，$\phi$ 是结果函数，$q_{\mathrm{mode}}$ 是分布预测、平均效应、配对效应或结构恢复。

## 7. 误差与复杂度记号

| 记号 | 含义 |
| --- | --- |
| $n$ | 变量模板或节点总数（计数族；链长等局部计数可沿用 $n$ 并在文中说明口径） |
| $d$ | 离散变量的最大值域大小 |
| $\kappa_i$ | 节点 $i$ 的父变量数 |
| $\mathcal C_i$ | 节点 $i$ 的合法父上下文集合 |
| $C_i=|\mathcal C_i|$ | 合法父上下文数量，最多为 $d^{\kappa_i}$ |
| $p_{\min,i}$ | 被动协议下节点 $i$ 最稀有合法上下文的概率 |
| $m$ | 总实验单位数或总运行数，必须说明如何分配到上下文 |
| $m_c$ | 上下文 $c$ 中相互独立的实验单位数 |
| $T$ | 一次实验的时间长度 |
| $T_0$ | 宏观稳定性分析中的烧入时间 |
| $W$ | 宏观稳定性观察窗口长度 |
| $\varepsilon_i$ | 节点 $i$ 的机制近似误差上界 |
| $\Lambda_{u,v}$ | 方程关于父变量 $u$ 的逐坐标 Lipschitz 常数 |
| $\ell$ | 损失函数 |
| $S$ | 概率预测的适当评分规则 |
| $\delta$ | 失败概率 |

连续回归中的平方误差记为 MSE，平方根记为 RMSE。两者的收敛指数不同，实验报告不得只写“误差”而不说明是哪一种。

## 8. 假设按协议声明

本研究不再采用“全局默认全观测、无混杂、平稳”的统一假设。每项假设只在具体协议中生效。

### 8.1 声明一致性协议 $\Pi_{\mathrm C}$

* 世界变量和原始外生源对研究者可追溯。
* 固定 $(X_{0,0},\omega,\mathbf d,\mathbf A)$ 后轨迹唯一。
* 时间展开图在声明范围内无环。
* 实现中的所有未来决定因素均被纳入状态、外部输入或随机源。

### 8.2 研究者识别协议 $\Pi_{\mathrm R}$

可观测性、因果充分性、最小性、忠实性、平稳性、干预目标可知性和支持覆盖必须随查询逐项声明。世界对研究者可追溯只负责提供 oracle，不会自动使一个受限数据协议下的查询可识别。

### 8.3 单智能体协议 $\Pi_{\mathrm A}$

智能体只能访问 $H_t^i$ 和查询中明确提供的信息。任何完整状态、方程版本、随机地址或研究者干预标签的泄露都会改变研究问题，必须被记录为另一种观测协议。

### 8.4 多智能体协议 $\Pi_{\mathrm M}$

主体间干扰被视为系统本身的一部分。每个结果以联合行动或联合策略为索引，策略学习造成的非平稳性必须进入状态或被明确建模为环境变化。
