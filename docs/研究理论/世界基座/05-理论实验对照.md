# 世界基座 05：理论与实验对照计划

> 记号按[工程符号体系](../工程符号体系.md)。

## 1. 对照原则

数学附件、世界验收和经验探针承担不同职责。

* 数学附件说明一个结论在给定假设下是否成立。
* 世界验收检查声明和引擎是否实现了这些假设与语义。
* 经验探针测量具体生成器、估计器和样本范围中的有限样本行为。

因此，本篇不再把探针称为"验证定理"。当实验曲线符合理论速率时，只能说明当前构造与该速率相容；当实验偏离时，应检查有限样本区间、估计器、数据生成条件和理论假设，而不是直接宣布一般理论失败。

## 2. 实验登记格式

每个确认性实验至少登记：

| 项目 | 内容 |
| --- | --- |
| 协议 | $\Pi_{\mathrm C}$、$\Pi_{\mathrm R}$、$\Pi_{\mathrm A}$ 或 $\Pi_{\mathrm M}$ |
| 陈述类型 | 设计约束、文献结果、已证明命题、经验假设或实验判据 |
| 实验单位 | $\omega$ 的组成和独立重复层级 |
| 查询 | $\mathcal Q=(\mu_H,\nu_d,\nu_k,\phi,q_{\mathrm{mode}})$ |
| 构造 | 分量方程、参数、干预和观测映射 |
| 估计器 | 模型类、超参数选择和训练协议 |
| 主指标 | 精确定义的 MSE、RMSE、TV、评分或配对效应误差 |
| 样本量 | 总运行数、每上下文样本数和重复数 |
| 判据 | 方向、容差、置信区间和多重比较处理 |
| 失败处理 | 预先列出的诊断，不含事后移动判据 |

同一干预对的两个臂可以共享 $\omega$，不同重复必须使用独立 $\omega$。单条世界长轨迹中的多个时间点不能未经依赖分析直接当作独立重复。

## 4. 数学附件实验

### 4.1 L1：离散局部估计

对固定 $C_v$ 的条件概率表，分别改变每上下文独立样本数 $m_c$，测量平均和最大 TV。预期的有限样本主趋势为 $m_c^{-1/2}$。改变 $\kappa_v$ 时必须区分两个效应：每个上下文内的误差由 $m_c$ 决定，总运行成本由 $C_v\leq\chi^{\kappa_v}$ 决定（$\chi$ 为值域大小上界，见[样本复杂度](01-样本复杂度.md)）。

现有 S1 使用总样本 $m$ 下近似均匀出现的父上下文。它可以观察误差曲线，但若要直接检验分层预算，应改为精确控制每个上下文的 $m_c$。

### 4.2 L2：连续局部回归

现有 S2/S2b 的指标是 RMSE，因此理论参考斜率为 $-1/(\kappa_v+2)$，不是 MSE 的 $-2/(\kappa_v+2)$。S2b 只代表"全部其余分量作为输入"的高维回归基线，不代表一般未知 DAG 学习。

确认性版本应固定同一个目标函数跨样本量变化，避免每个 $m$ 重新抽取函数造成额外层级混合，并分别报告函数间和样本间不确定性。

### 4.3 P1：误差传播

现有 S3 的对齐误差构造用于检查几何和是否被脚本正确实现。现有 S4 用于检查汇聚路径应求和。二者是已证明代数命题的回归测试，不需要通过随机重复再次证明命题本身。

确认性实现测试应在 $\mathcal G^{\mathrm{unroll}}_{-\mathcal X}$ 上生成路径，加入一个上游路径经过干预节点的例子，确认该路径在节点干预后（断边语义）被删除。

### 4.4 D1：被动与主动覆盖

设合法上下文数为 $C_v$。主动分层总运行数为 $C_v m_c$，被动采样为使稀有上下文获得 $m_c$ 个样本，主要量级为 $m_c/p_{\min,v}$。比较总运行数时，参考比值是：

$$
\frac{1}{C_v\,p_{\min,v}},
$$

而不是 $1/p_{\min,v}$。现有 S5 使用两个上下文，因此其参考量级应为 $1/(2p_{\min})$。

## 5. 引擎诊断实验

旧 E1 至 E6 保留为历史诊断，但在新框架中重新定位。

| 编号 | 可以提供的信息 | 不能支持的结论 |
| --- | --- | --- |
| E1 | 给定天气序列和线性检验器的滞后预测功效 | Granger 图等于真实因果图 |
| E2 | 指定温度分布在零度附近的几何质量 | Tsybakov 条件噪声或分类快速率 |
| E3 | 原始时间序列和相邻风场的相关描述 | 去趋势随机残差的 mixing 常数或通用有效样本量 |
| E4 | 若干特征对天气读出的预测能力 | 父集完整性或残差独立性，除非直接检验留出残差 |
| E5 | 当前随机地址实现对执行顺序扰动的稳定性 | 任意节点干预已满足全部反事实语义 |
| E6 | 当前特征下温度、降雨和邻区条件概率的描述 | 空间因果方向或智能体因果理解 |

E1 至 E6 可以帮助选择第一批世界切片和实验参数，但不能代替 C/W 系列验收。

## 6. 正式的第二阶段准备实验

I0 检查观测等价模型能否被保留干预区分，I1 检查概率预测与 CRN 配对效应是否被正确分开。另设 I2 检查主动覆盖成本：

* 使用 $C_v=4$ 个二元父上下文，其中一个上下文概率为 $p_{\min}$。
* 被动采样直到每个上下文至少获得 $m_c$ 个独立实验单位。
* 主动采样对每个上下文固定取得 $m_c$ 个独立实验单位。
* 主动总量应为 $4m_c$，被动等待量由 $m_c/p_{\min}$ 主导。
* 比值按 $1/(4p_{\min})$ 解释。

CRN 只在同一个实验单位的不同干预臂之间使用。为了估计一个条件分布而重复采样时，必须使用不同的独立实验单位，不能反复重放同一个 $\omega$ 冒充新增样本。

## 7. 判读规则

实验结果统一标为以下四种状态：

* **确认性通过**：判据、参数和样本量在看结果前冻结，并在独立实验单位上通过。
* **确认性失败**：冻结判据未通过，结果和诊断完整保留。
* **pilot**：用于选参数、发现问题或曾在看结果后调整构造，不能作为确认性证据。
* **信息性结果**：描述数据性质，但没有预注册的理论判据。

任何"限制"都不能同时在总表中标为 PASS。修正构造后必须产生新的实验编号或版本，并保留旧结果的状态。
