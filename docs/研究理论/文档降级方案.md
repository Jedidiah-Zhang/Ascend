# 文档降级改造方案

> **目的**：落实《[世界契约](世界契约.md)》WC-0.2 与 WC-11.4——关于世界语义的规范陈述只能出自契约，其余文档降为实现注记或引用。
> **原则**：只加注记、只改引用，不改动实现细节的文字本身；避免"两份规范"。

## 1. 处理清单

| 文档 | 当前性质 | 处理 | 备注 |
| --- | --- | --- | --- |
| `研究综述.md` | 理论基准 | **保留**，作为契约的依据来源 | 空章节（已有工作梳理/框架与命题/验证与评估方案/边界与局限）由命题表反向取材 |
| `工程符号体系.md` | 记号约定 | **保留**，标注"术语候选" | 术语须在 WC 内重新定义并注明来源 |
| `第一阶段实施定义.md` | 规范+实现混合 | **降级**为实现注记 | 文首加统一注记；正文语义段落改为引用 WC-x；W0–W5 验收改为指向 #50 的条款生成 |
| `世界基座/01..11` | 对着实现写的说明 | **降级**为实现注记 | 每篇文首加统一注记；语义陈述改引用条款，实现细节保留 |
| `世界契约.md` | **唯一规范源** | 保持 | 新增条款须走 WC-11.3 变更流程 |

## 2. 统一注记（置于降级文档文首）

```markdown
> **实现注记**：本文记录当前实现的做法与背景，不具规范效力。
> 世界语义以《[世界契约](世界契约.md)》条款为准；若本文与契约冲突，以契约为准。
```

## 3. 引用替换要点

- "世界必须唯一生成轨迹" → 引用 WC-7.1；
- "状态充分性 / 缓存不能影响未来" → 引用 WC-3.2 / WC-4.3；
- "随机地址/CRN" → 引用 WC-5；
- "干预执行器语义" → 引用 WC-6；
- "完整存档" → 引用 WC-7.5 / WC-8；
- 原文中的"实施状态：P2 已实现"等句子：**删除或移入文末附录**，不得与条款并列。

## 4. 执行方式与时点

1. **注入注记**（机械操作）：为《第一阶段实施定义》与《世界基座》全部篇目加统一注记；
2. **术语重定义**：契约 WC 条款已定义状态、机制、地址、干预等术语；符号体系中的同名条目注明"以契约定义为准"；
3. **验收指向**：删除"W0–W5 验收定义"的规范地位，改为"检查由 #50 依据 WC-11.2 生成"；
4. **时点**：在 #48 开工前完成第 1、3 步；第 2 步随 #49 机制身份工作一并完成。

## 5. 验收

- 任意世界语义陈述都能回溯到 WC-x 条款；
- 除《世界契约》外，没有文档自称规范；
- grep 检查：降级文档中出现"必须/应"等规范措辞处，均带条款引用。
