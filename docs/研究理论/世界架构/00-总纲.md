# 世界架构 00：总纲

> **地位**：架构设计文档（工程形态），不具世界语义的规范效力；世界语义以《[世界契约](../世界契约.md)》条款为准。
> **关系**：本总纲定义 Ascend 世界的**目标工程形态**——声明式世界工具包。所有世界模块按此形态接入；旧形态（`ascend/causal`、`ascend/runtime`、`ascend/num`、`ascend/weather`、`ascend/space` 的框架部分）按《[01-重构计划](01-重构计划.md)》分批替换，不留兼容层。

## 1. 目标

| 性质 | 含义 |
| --- | --- |
| **可加** | 新增世界模块 = 新增声明包 + 证据；不改框架核心 |
| **可调** | 复杂度（分辨率/周期/实体数/结构）是声明的旋钮，不是代码开关 |
| **可信** | 每个声明有证据义务；研究层与世界严格分离 |

## 2. 核心式子

```
运行一个世界 = WorldProgram + 种子 + 初始状态 + 输入时间线
WorldProgram = 编译（模块包集合 ⊕ 参数 ⊕ 旋钮 ⊕ 调度）

世界 = 实例图上的声明式更新系统
     = 实例与关系 × 槽位 × 机制 × 时间 × 随机 × 不变量
```

声明是唯一事实源；代码只提供**内核实现**（内核原语与模块实现体）与**解释器**（编译器/运行时）。

## 3. 五层架构（依赖只向下）

```
┌ 研究层 ────────────────────────────────────────────────┐
│ 实验协议（单位/臂/查询/oracle/评分）· 控制世界 · 复杂度族 │
│ 观测 G ← 已提交状态        行动 Γ/Res → 干预时间线        │
└──────────────────────────────▲─────────────────────────┘
                               │ 只读已提交状态 / 只写外部输入
┌ 运行时 ──────────────────────┴─────────────────────────┐
│ WorldProcess：更新点调度 → 帧事务（影子→提交）→ 快照/重放 │
│ 物化无关；并行只改批次，不改结果                          │
└──────────────────────────────▲─────────────────────────┘
                               │ 编译产物（不可变）
┌ 编译器 ──────────────────────┴─────────────────────────┐
│ 模块合并 → 模板图 → 静态校验 → 更新点计划/内核绑定 → 身份 │
└──────────────────────────────▲─────────────────────────┘
                               │ 声明（唯一事实源）
┌ 声明层 ──────────────────────┴─────────────────────────┐
│ 模块包：实例/关系 · 槽位 · 机制 · 时间 · 随机 · 不变量     │
│ ＋ 参数 · 地址命名空间 · 复杂度旋钮 · 证据义务            │
└──────────────────────────────▲─────────────────────────┘
                               │ 原语
┌ 内核 ────────────────────────┴─────────────────────────┐
│ 整数/定点原语 · 冻结表 · 舍入/溢出 · 地址随机 · 内容摘要   │
└─────────────────────────────────────────────────────────┘
```

## 4. 一个核心抽象：两层图

**模板图（声明期）**：槽位与机制构成的依赖图——编译期校验无环、单写者、每父引用有见证。
**实例图（运行期）**：机制模板按实例模式展开为具体更新。实例只有三类：

| 实例 | 身份规则 | 例子 |
| --- | --- | --- |
| lattice | 层级 + 坐标 | tile 格、chunk 格、大陆格 |
| entity | 稳定派生 ID | 树木、设施、身体、资源堆 |
| global | 单例 | 时钟、海平面、全球温度 |

关系（边）：空间偏移、层级父子（restrict/prolong）、实体链接、归属。
机制 = 对实例模式的模板化更新；多分辨率、实体、全局归约、资源关系全部落在同一套模板里 —— **不引入任何"子系统"概念**。

## 5. 六种声明（元模型全部概念）

1. **实例与关系**：实例类型、身份规则、生命期；关系（空间偏移/跨层/实体链接）。
2. **槽位**：state / derived / parameter / external；值域、权限、写者、重算规则。
3. **机制**：父引用 + 方程 + 定义域 + 算术域 + 地址 + 实现绑定（参考/加速）。
4. **时间**：阶段（帧内序）、周期（日历）、事件（离散义务）——统一为更新点。
5. **随机**：命名空间与用途登记（地址 = 命名空间+实例+用途+时间+序号）。
6. **不变量**：值域/守恒/单调/总量检查（reject 或 record）。

模块包 = 上述六种声明的集合 + 参数 + 旋钮 + 证据义务 + 文档。
合法世界 = **依赖闭合的模块子集 + 参数 + 种子**。

## 6. 三种时间模式

| 模式 | 语义 | 用途 |
| --- | --- | --- |
| 阶段 phase | 帧内有序波次 | 同帧因果传播 |
| 周期 period | 日历纯函数（tick → 触发） | 慢变量（日/季/年） |
| 事件 event | 作为状态排队的离散义务 | 延迟/条件行为 |

事件不是子系统：**事件 = 状态槽位 + 触发机制**。

## 7. 研究层：三协议 + oracle

| 协议 | 内容 | 约束 |
| --- | --- | --- |
| 观测 G | 观察者类 → 视野/采样/量化/缺失/噪声地址/版本 | 只读已提交状态；帧边界；纯函数；泄漏审计 |
| 行动 Γ·Res | 行动 →（目标、效果、时长、成本、失败）；冲突规则 | 确定性（稳定键或声明随机流） |
| 实验 E | 实验单位 ω、臂、查询、划分、oracle、评分 | 按单位划分；预注册 |

**oracle**：`oracle(快照, 干预计划, 地平线, ω 后缀) → 真实轨迹/观测`。
**控制世界模板**：观测等价/伪相关/无效干预/机制替换的世界对构造。

两点身份严格分开：**世界身份**（模块/参数/内核/种子）与**协议身份**（观测/行动/查询/评分版本）。

## 8. 设计原则与反模式

**原则**：单一事实源；轴正交；纯函数 + 记忆即槽位；无证据不生效；fail-closed；物化无关；研究层不入世界；组合封闭；**复杂度是声明而不是代码开关**。

**反模式**：模块间私聊（读别人缓存/内部状态）；事件总线驱动状态；`if module_enabled`；隐藏状态（私有内存/迭代器/时钟）；研究参数写进世界；把派生当状态。

## 9. 与旧形态的关系

旧形态（`causal/` 注册表、`runtime/` 调度、`num/`、`weather/ mechanisms`）是本架构的一个**非正交特例**：只有全局与单层场、只有阶段模式、声明与实现混合。重构按《01-重构计划》分阶段替换；每个阶段完成时同步删除被替代的旧代码与旧测试，不留兼容层。
