# 世界架构 01：重构计划

> **地位**：执行计划（实现注记）。设计意图见《[00-总纲](00-总纲.md)》；世界语义以《[世界契约](../世界契约.md)》条款为准。
> **纪律**：本重构按 [CONTRIBUTING](../../../CONTRIBUTING.md) 的"设计原则（必须遵守）"执行——深模块低耦合、无补丁式代码、数据与算法拆分、不承诺向后兼容；开发顺序"需求 → 接口 → 测试 → 代码"；提交遵循 Conventional Commits（中文）。

## 1. 理念符合性（原则 → 做法）

| 原则 | 本重构的做法 |
| --- | --- |
| **深模块低耦合** | `ascend.world` 只暴露四个入口：`ModulePack`/`WorldSpec`（声明）、`compile_world`（编译）、`WorldProcess`（运行）、研究协议（`ObservationSpec`/`ActionSpec`/`ExperimentSpec`/`Oracle`）。元模型、编译器、运行时、内核为内部模块，不跨层互相引用实现细节 |
| **无补丁式代码** | 不写兼容层、不做渐进式适配器。每个阶段到达删除点即删除被替代的实现与测试；过渡期双轨**最多一个阶段**，且在本表登记删除阶段 |
| **数据与算法拆分** | 结构声明（槽位/机制/模块/不变量）是代码（要绑定函数与实现体）；内容（`data/*.json`：地形/气候/群系/天气/世界参数）仍是数据，改内容不改代码 |
| **不承诺向后兼容** | 新世界身份即新世界；旧档 fail-closed 拒载；旧 API 直接删除，同阶段同步删除/重写旧测试 |
| **前后端分离** | 不影响：网络协议与前端不变，只重构后端内部 |
| **测试先行** | 每阶段先写 `backend/tests/world/` 的接口测试（预期行为），再写实现；阶段结束全绿才提交 |

### P0 新核心地基 + 玩具切片（本批）

**交付**：

```
backend/ascend/world/
  kernel/     fixed.py · tables.py · frozen_tables.py · rng.py · digest.py
  meta/       declarations.py · validate.py · digest.py
  compile/    program.py · compiler.py
  runtime/    state.py · evaluate.py · process.py
  research/   observation.py · action.py · experiment.py · oracle.py
  modules/    clock.py · toy.py
  evidence/   witnesses.py · acceptance.py
backend/tests/world/  ...
```

**要点**：

- 元模型六种声明全部落地：实例与关系、槽位、机制、时间、随机、不变量；模块包 = 声明集合 + 参数 + 旋钮 + 证据。
- 模板图 / 实例图两层：语法 `when{mode,key}`（phase/period/event）+ `Parent{slot,lag,relation,aggregation}`；编译器做单写者、无环、阶段序、周期刻度、地址唯一、见证重跑、身份可复现六类静态校验。
- 帧事务：阶段内影子写、提交时整帧发布、失败整帧回滚（承接 WC-7.6/WC-9.2 语义，实现为新核心的 `WorldProcess`）。
- 研究层最小闭环：观测协议 G（帧边界、白名单、量化、泄漏审计）、行动 Γ/Res（行动 → 干预 → 可回放）、实验/oracle（同 ω 配对、逐位可复现）。
- 玩具切片：时钟 + 链式/空间最小世界，提供 W0（帧内顺序）、W1（节点干预与 CRN）、W2（持续/机制语义的可手算变体）的新核心等价验收。

**删除**：无（新核心独立；`causal/` 等旧框架在 P2 删除，本阶段不产生兼容层）。

**验收**：

1. `pytest backend/tests/world -q` 全绿；
2. W0/W1/W2 在新核心上通过（`world/evidence/acceptance.py`）；
3. 同一 `WorldSpec` 两次编译身份逐位一致；改模块/参数/旋钮/种子任一 → 身份变化；
4. 帧事务：提交前不可见、失败回滚、记录延后；
5. oracle：同一 ω 的干预臂与基线臂未干预地址逐位一致（CRN）。

**P0 完成记录（2026-09-18）**：

- 交付 `backend/ascend/world/`（kernel/meta/compile/runtime/research/modules/evidence）
  与 `backend/tests/world/`（85 项测试）；新核心不依赖旧框架任何模块。
- 六种声明、两层图、三种时间模式、帧事务、快照/重放、G/Γ·Res/实验/oracle 最小闭环
  全部落地；编译器静态校验覆盖单写者、同帧序、见证覆盖与重跑、地址唯一、身份可复现。
- W0/W1/W2 在新核心通过；CI 增加 `world-core` job（`pytest tests/world`）。
- 关键语义决策：`lag=0` 同帧（影子）、`lag=1` 帧初、`lag=k≥2` 历史；
  历史以初始值预热（世界"自始如此"稳态）；失败三相位（提交前可重试 /
  提交中、提交后世界失效）。
