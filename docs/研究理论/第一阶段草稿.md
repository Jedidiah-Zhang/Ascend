# 第一阶段理论综述

> 状态：讨论中（逐块与负责人评估，未定稿）
> 本综述从"构建有因果 ground truth 的世界"这一目标出发推导第一阶段理论范围，
> 不沿用既有文档结构，而是以目标为轴重新组织。

## 目标

回答第一阶段最终问题：

> 一个有已知因果 ground truth 的动态世界，在什么条件下能被正确识别？

## 理论五块（依赖顺序）

| #  | 块             | 要回答的问题                                             | 现状                                           |
| -- | -------------- | -------------------------------------------------------- | ---------------------------------------------- |
| ① | **定义** | 世界的因果长什么样：变量、边、公式、时间、空间、观测接口 | **已闭合**（A–F）                       |
| ② | **清单** | 世界应该有哪些类型的因果（判据：每类都改变"识别难度"）   | 分类学正在定（九格清单），未定稿               |
| ③ | **识别** | 观测者从数据学因果：什么条件下能学、学到什么程度         | 只有时间识别（滞后边）；空间识别、部分观测空白 |
| ④ | **干预** | 主动实验能绕过哪些识别困难                               | 理论雏形（do 数学）；引擎实现属工程，不急      |
| ⑤ | **评估** | "学会了"的度量；误差随样本量、噪声、结构复杂度怎么变     | 基本有（误差传播），需对齐到"识别成败"         |

## 已定结论（第①块讨论产物）

### A. 世界是一台机器

- 世界状态 = 所有变量的当前值；时间按 tick 离散推进；
  每个 tick 每个变量用公式从"上一刻的值 + 掷骰子"算出新值。
- tick 是**观测粒度**，不是因果粒度：tick 内部有计算顺序
  （场 → 派生 → 事件），同 tick 因果存在；
  但观测者以 tick 为单位看世界，看不到 tick 内部的先后。

### 因果 = 相关 + 方向

- 方向是因果唯一比相关多的东西。
- 方向只能来自三处：**时间先后**（跨 tick）、**动手干预**、**天生先验**。
- 失去方向的因果，在观测层面就只剩相关。
- 相关 ⊃ 失去方向的因果——还存在完全没有因果联系的相关。

### 相关背后的三层真相

| NPC 看到的 | 真相（ground truth）            | 例子                   |
| ---------- | ------------------------------- | ---------------------- |
| 相关       | 真因果 · 方向可见（跨 tick）   | 先下雨，后涨水         |
| 相关       | 真因果 · 方向不可见（同 tick） | 温度 ↔ 降水类型       |
| 相关       | 无因果边 · 共同原因            | 闪电与雷声（都因放电） |
| 相关       | 无因果边 · 纯巧合              | 有限样本里碰巧一起动   |

- 同 tick 因果与共同原因**观测等价**：从数据上完全分不开。
- 纯巧合随样本增多自己消失，但 NPC 样本有限，会被骗。

### 设计含义

- 世界要有意安排**迷惑项**（共同原因、伪相关陷阱）——
  否则识别任务太简单，研究无难度可测。
- 每条边"给不给方向线索"（延迟 / 干预途径 / 先验）是设计开关：
  重要的同 tick 因果要么延迟化、要么给 NPC 干预途径。
- NPC 认识世界分三层：预测规律（够生存）→ 时间因果（跨 tick 边）→ 干预确认方向。

### B. 空间：场是矩阵，因果图只管场与场之间

**1. 格子间影响不算因果边**——是卷积核（相关长度）；画成边会让图爆炸。

**2. 表示**：图连类型（场间因果边），矩阵连实例（tile 元素）。
chunk 级缓存与理论兼容：值从连续场采样，矩阵不必真存。

**3. 颗粒度**：矩阵元素 = tile。真正的设计参数是**相关长度**，用 N_zones 倒推：
硬约束 `1 tile ≪ 相关长度 ≪ 世界宽度`；N_zones（每维度独立天气区数）
由研究样本需求 + 游戏体验倒推，相关长度 = 世界宽度 ÷ N_zones。
初值 N_zones = 8（大陆 200 chunk 宽 → 相关长度 ≈ 25 chunk），探针实测校准。

**4. 变量类型学**：两个维度交叉——

|                        | 标量（全世界一个值） | 场（每 tick 一张矩阵） |
| ---------------------- | -------------------- | ---------------------- |
| 演化（随 tick 变）     | 季节相位、全球平均温 | 温度、湿度、降雨       |
| 慢（极少变，可被改造） | 大地构造参数         | 地形海拔               |

另加**静态量**（永不改变，如地轴倾角）。

**5. 场间因果两种方式都要**：逐点（局部映射）+ 跨空间（平流/径流）。
跨空间 = 空间版"滞后边"。

**6. 核与演化统一为卷积**：各向同性；平流 = 核换中心，扩散 = 核变宽。

**7. 空间误差度量**：逐格最大为主（保守，与时间版理论一致），加权作补充。

**8. 边界**：截断（世界不是环面）。

**9. do 权限**：演化/慢变量全允许；**静态量舍弃 do**
（do 静态量 = 换一个世界，归生成参数研究）；**单格 do 保留**——
空间传播定理的探针，优先用于静态场（扰动持久、沿因果边传播）。

**10. 合法边三规则**：时间尺度兼容（快→慢默认禁止，除非声明积分器）/
空间类型转换（场→标量 = 聚合，标量→场 = 广播，场→场 = 逐点或跨空间）/
演化语义（静态量无入边）。

**11. 节点两类**：机制节点（真方程 + 噪声，世界的因果实体）
vs 统计量/派生节点（纯函数、无噪声，被组成部分全决定）。

**12. 场的时间演化**：演化方程 `F(t+1) = 漂移 + 扩散（卷积核，范数 < 1）+ 噪声`，
非逐 tick 独立采样。扩散是"场内空间滞后"的唯一代表，与时间版自相关对称。

**13. 多尺度三层**：一个因果角色一层，三层——

| 层     | 驱动源               | 长度        | 演化         | 振幅角色             |
| ------ | -------------------- | ----------- | ------------ | -------------------- |
| 大尺度 | 静态场（纬度、海拔） | ≈ 大陆宽度 | 无           | 气候带差异（几十度） |
| 中尺度 | 噪声 + 大尺度调制    | = 相关长度  | 漂移 + 扩散  | 天气变化（几度）     |
| 小尺度 | 噪声                 | 1–2 tile   | 每 tick 重掷 | 噪声底（零点几度）   |

- 三个角色：静态空间因果（NPC 靠梯度学）、演化空间因果（靠先后学）、无因果噪声（迷惑项）
- 相邻尺度长度比 ≥ 10（可分）；每层声明：驱动源、相关长度、振幅、演化方式
- 空间滞后三分谱系：场内扩散 / 场间跨空间（平流径流）/ 离散空间边

### C. 噪声：未建模机制的化身

**意义**：世界的机制无穷多，因果图只画一部分。没画进图的机制真实存在、
真实运行，它们的影响通过"骰子"进入已建模的变量。噪声 = 显式图之外的世界。

**三个层次**：

| 层         | 实现？             | 进图？ | 性质                                          |
| ---------- | ------------------ | ------ | --------------------------------------------- |
| 显式机制   | 真实代码           | 进     | 研究主体（声明边 + ε 预算 + 探针）           |
| 声明的噪声 | 真实代码，真实运行 | 不进   | 结构已知声明（相关长度等）——可控的背景干扰  |
| 真未知     | ——               | 不进   | **不允许**（ground truth 世界必须全知） |

- 机制的实现是全的（世界完整）；图的裁剪是有意的（研究选择，将来改图不动工程）；
  噪声结构是设计定死的（识别难度可控）。
- 每个机制做一次建模决策：**显式化（进图）还是坍缩为噪声**，由研究目的驱动。

**技术决策**：

1. **有界噪声**（均匀）——未建模机制本身有界（世界值域有界），"最坏错多少"永远可算
2. **加性 + 乘性都做**：`值 = 公式 + 骰子` 与 `值 = (公式+c)×骰子−c`（偏移乘，回避零点怪癖）
   - 乘性 = 异方差结构：父变 → 子的波动大小跟着变，是 NPC 可用的方向线索
   - 分配：大部分机制加性；**降雨量乘性**（现实：湿润区波动大、干旱区波动小，天然按比例）
3. **谁掷骰子**：机制节点掷；统计量不掷；静态/参数不掷；慢变量的变化 = 改造行为（非骰子）
4. **独立性纪律 + 有控制的违反**：默认所有骰子独立（因果充分性前提）；
   **故意让两个骰子相关 = 共享一个未建模机制**——迷惑项（闪电/雷声）的干净实现方式
5. **白噪声为主**（每 tick 重掷，不记上次）
6. **空间结构跟随相关长度**：小尺度层空间白噪声（每格独立）；中尺度层噪声相关长度 = 核宽度

**噪声振幅（信噪比）是设计参数**：决定该变量的识别难度，倒推法定值，归 ② 块。

**识别研究的完整对象**：NPC 从数据学到的规律 = 显式图 + 未建模机制的模式。
第一阶段要问两层：NPC 还原多少显式图；NPC 把噪声结构学成了什么（迷惑当因果，还是因果当迷惑）。

### D. 因果延迟的种类

**两个理论角色**：延迟是方向线索的载体（跨 tick 边是 NPC 学方向的主要途径）；
延迟步数是识别难度参数（越长越难学）。

**1. 延迟档次按世界时间层级定**：世界有时间层级（tick/小时/天/季节），
每个档次是"可学时间结构"的一种，各至少一个代表——

| 档次             | 例子             | 引擎代表候选      |
| ---------------- | ---------------- | ----------------- |
| 同 tick          | 温度 → 降水类型 | ✓ 已有           |
| 短滞后（小时级） | 降雨 → 径流     | 径流结算          |
| 中滞后（天级）   | 降雨 → 土壤湿润 | DaySummary 日结算 |
| 长滞后（季节级） | 季节 → 植物生长 | 生态（待实现）    |

**2. 固定延迟为主**（雨下后 3 tick 必涨水——NPC 数格子就能学）；
分布延迟（1–5 tick 随机生效）模糊时间签名，以后作为难度选项。

**3. 时间滞后三分谱系**（与 B 点空间谱系对称）：

| 结构               | 物理                 | 声明                            |
| ------------------ | -------------------- | ------------------------------- |
| 离散滞后边         | 某 tick 突然生效     | 边标注滞后步数                  |
| 连续衰减（积分器） | 影响持续、按指数衰减 | 快→慢的合法通道（B.10 的出口） |
| 同 tick            | 当场生效             | 方向不可见                      |

**4. 观测约束**：每档延迟 ≥ NPC 采样周期——比采样还短的延迟对 NPC 等效于同 tick，
白设计。延迟档次与 F 点（观测接口）配合定。

### F. 观测接口：观测映射 O

**核心对象**：`观测数据 D = O(世界真值 X) + 观测噪声`。
O = 每个可观测变量的感知声明（空间范围 × 时间节奏 × 感知形式），
是识别问题的**输入规格**——"什么条件下可识别"里的条件之一。

**概念一：O 是信息瓶颈**
世界的全信息经 O 压缩成 NPC 的数据。可识别性 = 因果结构的信息压缩后还剩多少。
tier 分类把 12.3°C 与 14.9°C 都压成"舒适"——**观测粒度造成的不可识别**，
是确定性损失，可精确刻画，与噪声无关。

**概念二：三类"看不见"理论地位不同**

| 看不见的根源                         | 性质                             |
| ------------------------------------ | -------------------------------- |
| 有损投影（分类、视野截断、采样稀疏） | 确定性损失，可精确刻画           |
| 观测噪声                             | 随机扰动（独立于过程噪声的一层） |
| 隐藏变量（未观测机制）               | 结构性缺失（C 点迷惑项）         |

**概念三：NPC 的因果是感知层的因果**
感知量 = 机制变量的投影；NPC 学到的图是感知量之间的图，不是机制变量之间的图。
许多"因果律"是感知层产物（"0°C 以上下雨"是感知层现象；机制层只是
"降水类型由温度阈值决定"）。两层因果的对应关系 = 第二阶段 NPC 认知的理论地基。

**概念四：可识别性 = 三元函数**

```
可识别性 = f(世界的条件, 观测的条件, 学习者的条件)
              ①②块         F点 O          ③块
```

三个自变量独立设计；第一阶段的研究 = 在这个三元空间画出可识别/不可识别的边界。
第一阶段聚焦 NPC 视角（部分观测正是研究空白）；全观测仅作探针自检，不设常设档。

**工程注脚**：观测记录器直连世界状态（每 tick 场矩阵全量有值），绕过事件系统；
事件流（tier 变化才发）是游戏逻辑的稀疏通知，与研究数据流无关。
感知量 = 派生节点（纯函数投影），与 B.11 统计量同类，逐变量声明。
