# 研究平台 — 综述

> - 设计状态：讨论中
> - 适用范围：自定义因果实验环境、研究声明接入、实验组织及协议适用性
> - 上级：[整体架构](../整体架构.md)

## 1. 目标与边界

接入按研究规则声明的因果实验环境与可选智能体，提供研究配置、实验运行和证据管理。官方游戏世界只是可选的实验环境之一；研究者可以整体替换它，定义不具有空间、实体或玩法的因果系统。研究问题、形式化、识别假设及评价定义由[研究材料](../研究方案与理论.md)提供；本平台记录这些要求如何由实际运行组合满足。

本平台组织实验单位、分支、配对、观测协议和评价；系统内作用的合法性及实际求值／演化由所选环境依据其声明执行。实验不依赖智能体或游戏启动流程，也不以装配官方世界为前提。

## 3. 已明确的使用方向

### 自定义因果实验环境

研究者可按研究声明流程制作自己的因果系统，整体替换官方游戏世界；替换范围不限于世界内的机制或参数。只有变量、结构方程和外生随机量的非空间因果系统也属于接入目标，不应为了通过接口而虚构地图、身体或秒制时钟。

环境按适用研究规则声明变量／状态、生成机制、因果依赖、随机性、干预与观测语义，以及模型需要的求值顺序或时间演化规则。声明、实现绑定、校验和证据核验应形成完整接入流程；具体格式、执行接口和能力要求仍待设计。这里不规定所有环境都采用固定步长或逐帧演化。

研究准入按所选协议核验实际因果系统的声明、实现及验证证据，不以官方来源或是否具有游戏世界形式作为合格依据。审查须说明适用范围和已支持的研究保证；仅有可加载产物或声明元数据不构成合规证明，证据不足时不能授予相应资格。检查项、证据接口及自动化程度仍待协议对接确定。

模组作者负责构建可安装产物，使用者无需编译。研究侧的无界面装配继续独立于游戏菜单；共享包解析及加载能力的归属仍待确定。

### 使用世界库时的实验空间

选择世界库空间能力的实验使用有界空间及全域演化，相关规则由[空间系统](../世界/世界框架/空间系统/设计.md)维护。通过空间规模、环境分辨率和并行实例数控制成本；显示及只读观察范围不裁剪实验演化区域。非空间因果系统不因缺少几何空间而被拒绝接入。

验收时将核对实际模块组合的边界和更新计划，并在相同初态与输入等确定性条件下验证改变观察位置、范围或关闭显示不影响轨迹；这不表示每个机制每个步都必须更新。

### 使用世界时钟时的时间读出

使用[时间系统](../世界/世界框架/时间系统/设计.md)的实验，以其秒制本地时间及关系建立实验时间锚点。候选运行记录包括域身份、本地时刻、逻辑帧、相对倍率和现实耗时；配置倍率、模拟时长与吞吐率分开，不默认按现实速度运行。其他因果系统按自身声明解释求值顺序或模型时间，不强制映射成游戏逻辑帧。

现实时间采样属于运行测量；时间记录格式及协议帧号与本地秒数的对应仍待细化。

### 研究适用性与复现

依据[游戏模组政策](../游戏平台/模组管理/设计.md)，社区算法无需统一满足研究规范。本平台按具体协议检查所选模块的声明、可干预点、随机语义和验证证据；游戏加载成功不能作为满足研究要求的证据，单纯调用日志也不等于不透明算法内部的因果真值。

需要精确续跑的实验可锁定实现、配置、种子、模型、输入及摘要。改变机制或配置后按协议建立新身份或分支，不冒充原实验续跑。此策略不限制游戏按兼容路径继续原存档。

给定逐步输入的世界重放、重新运行智能体的闭环复现与统计重复性分开定义；固定版本和种子不是 GPU、多线程或任意算法位级复现的充分条件。具体保证随协议及实现证据确认。

理论文档保留原文。下面是对接工作，不表示已完成研究合规验证：

| --- | --- | --- |
| 世界库的有界空间 | 与[世界契约](../研究理论/世界契约.md) WC-2.1 方向一致；坐标量化及状态接口未定 | 接口细化后逐条核对，阻塞采用该能力的证据声明 |
| 世界库的本地时钟与步内阶段 | 新时间基础确定，协议中的帧与本地秒数尚待映射 | 时间及记录接口明确后核对采用该时间系统的干预和观测时刻 |
| 模块声明与可追踪粒度 | 游戏允许不透明算法，研究须检查实际可观测和可干预范围 | 选择实验机制时核对，不能推断完整因果真值 |
| 自定义因果系统与准入 | 支持整体替换实验环境；通用声明、执行接入及合规审查接口未定 | 阻塞自定义因果环境的研究资格认定，需与环境声明契约共同细化 |
| 理论条款的适用范围 | 现有世界契约含空间、槽位、阶段及帧等约定；其他因果系统的对应方式尚未核对 | 区分通用研究义务与模型类的专属约定，不把游戏结构当作统一门槛，也不声称既有证据已覆盖所有系统 |
| 初态、随机实验单位、配对与分支 | 通用运行接口尚未定稿 | 阻塞实验组织与精确重放实现 |
| 遗传与社会评价 | 使用世界机制，效应区分及宏观统计由本平台组织 | 遗传、智能体和社会机制明确后制定协议 |

遗传／环境效应及多智能体评价的理论来源为[研究综述](../研究理论/研究综述.md)和[多智能体研究](../研究理论/多智能体/00-总纲.md)。

## 5. 关联与推进顺序

先明确因果实验环境的声明、执行接入和证据契约，再按实际环境对接执行与记录能力。采用官方世界时，由[世界框架](../世界/世界框架/综述.md)定义演化、[运行支撑](../世界/运行支撑/综述.md)提供执行、记录与快照；[智能体](../智能体/综述.md)按需接入。通用研究接口不以世界专属状态与实体接口为唯一实现形式。

接入验收需包含一个不依赖空间、身体及游戏时钟的最小因果系统，按声明完成适用协议要求的求值、干预、观测及证据核验，以检查研究接入没有隐含绑定官方世界。具体用例随协议接口确定，尚无实现证据。

研究配置、推进、干预和真值读取不通过玩家视野或玩法事件反向获取；研究界面及权限独立设计，共享可视化仅在接口明确后复用。
