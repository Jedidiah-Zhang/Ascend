# 研究平台 — 综述

> - 设计状态：讨论中
> - 适用范围：实验组织、协议适用性及新世界能力对接
> - 上级：[整体架构](../整体架构.md)

## 1. 目标与边界

装配世界与可选智能体，提供研究配置、实验运行和证据管理。研究问题、形式化、识别假设及评价定义由[研究材料](../研究方案与理论.md)提供；本平台记录这些要求如何由实际运行组合满足。

本平台组织实验单位、分支、配对、观测协议和评价；世界内作用的合法性及实际演化仍由世界负责。实验可以只运行世界，不依赖智能体或游戏启动流程。

## 3. 已明确的使用方向

### 实验空间

研究选择有界空间并使用其全域演化能力，通用规则由[空间系统](../世界/世界框架/空间系统/设计.md)维护。通过空间规模、环境分辨率和并行实例数控制成本；显示及只读观察范围不裁剪实验演化区域。

验收时将核对实际模块组合的边界和更新计划，并在相同初态与输入等确定性条件下验证改变观察位置、范围或关闭显示不影响轨迹；这不表示每个机制每个步都必须更新。

### 时间读出与现实锚定

以[时间系统](../世界/世界框架/时间系统/设计.md)提供的秒制本地时间及关系建立实验时间锚点。候选运行记录包括域身份、本地时刻、逻辑帧、相对倍率和现实耗时；配置倍率、模拟时长与吞吐率分开，不默认按现实速度运行。

现实时间采样属于运行测量；时间记录格式及协议帧号与本地秒数的对应仍待细化。

### 研究适用性与复现

依据[游戏模组政策](../游戏平台/模组管理/设计.md)，社区算法无需统一满足研究规范。本平台按具体协议检查所选模块的声明、可干预点、随机语义和验证证据；游戏加载成功不能作为满足研究要求的证据，单纯调用日志也不等于不透明算法内部的因果真值。

需要精确续跑的实验可锁定实现、配置、种子、模型、输入及摘要。改变机制或配置后按协议建立新身份或分支，不冒充原实验续跑。此策略不限制游戏按兼容路径继续原存档。

给定逐步输入的世界重放、重新运行智能体的闭环复现与统计重复性分开定义；固定版本和种子不是 GPU、多线程或任意算法位级复现的充分条件。具体保证随协议及实现证据确认。

## 4. 理论与工程的待决对接

理论文档保留原文。下面是对接工作，不表示已完成研究合规验证：

| 对接项 | 当前关系／缺口 | 影响与解决时机 |
| --- | --- | --- |
| 有界空间 | 与[世界契约](../研究理论/世界契约.md) WC-2.1 方向一致；坐标量化及状态接口未定 | 接口细化后逐条核对，阻塞相应证据声明 |
| 本地时钟与步内阶段 | 新时间基础确定，协议中的帧与本地秒数尚待映射 | 时间及记录接口明确后核对干预和观测时刻 |
| 模块声明与可追踪粒度 | 游戏允许不透明算法，研究须检查实际可观测和可干预范围 | 选择实验机制时核对，不能推断完整因果真值 |
| 初态、随机实验单位、配对与分支 | 通用运行接口尚未定稿 | 阻塞实验组织与精确重放实现 |
| 遗传与社会评价 | 使用世界机制，效应区分及宏观统计由本平台组织 | 遗传、智能体和社会机制明确后制定协议 |

遗传／环境效应及多智能体评价的理论来源为[研究综述](../研究理论/研究综述.md)和[多智能体研究](../研究理论/多智能体/00-总纲.md)。

## 5. 关联与推进顺序

[世界框架](../世界/世界框架/综述.md)定义演化，[智能体](../智能体/综述.md)定义主体实现，[运行支撑](../世界/运行支撑/综述.md)提供执行、记录与快照。先收束装配、状态和读写接口，再细化实验协议对接、工具与交付。

研究配置、推进、干预和真值读取不通过玩家视野或玩法事件反向获取；研究界面及权限独立设计，共享可视化仅在接口明确后复用。
