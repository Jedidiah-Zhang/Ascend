# 因果建模工作台 — 测试

> - 适用范围：会话契约、工作区状态与 Qt 交互的验证目的、入口及覆盖限制
> - 上级：[研究平台](../综述.md) · [设计](设计.md) · [实现](实现.md)

## 1. 目的与范围

测试按会话、无控件状态层和 Qt 界面分层验证。下表列关键保证的代表入口；完整清单由 [CMakeLists.txt](../../../testbench/workbench/CMakeLists.txt) 维护，输入、步骤和断言查所属测试源码。实际通过情况以运行与 CI 为准。

共用的端到端基准为设计中的[场景 A](设计.md#场景-a可手算的完整实验)：三变量递推式给出可手算参考值，用于核对检查点、干预传播、差值与重放。示例组件 `ascend::experiment_model` 提供装配与参考序列；测试还使用双输入、输入／采样失败、实例化不确定及状态捕获失败模型，验证成功示例不能覆盖的边界。

自动化验证接口与交互行为，不证明任意模块的因果声明真实、完整或具有研究资格；桌面可读性与打包后运行的覆盖限制见第 6 节。

## 2. 运行方式与验证环境

构建与整套 CTest 命令集中在[实现文档](实现.md#4-构建与运行入口)。在配置时加 `-DASCEND_WORKBENCH_BUILD_GUI=OFF` 可只构建无界面会话库与测试。

| 层次 | 源码／程序 | 运行条件 |
| --- | --- | --- |
| 会话 | [test_session.cpp](../../../testbench/workbench/test_session.cpp)／`ascend_session_tests` | 无 Qt，参数选择用例 |
| 状态层 | [test_workspace_model.cpp](../../../testbench/workbench/test_workspace_model.cpp)／`ascend_workspace_tests` | `QCoreApplication`，仅 QtCore 与 Qt Test，不创建控件 |
| 界面 | [test_workbench_ui.cpp](../../../testbench/workbench/test_workbench_ui.cpp)／`ascend_workbench_tests` | Qt Test 按对象名操作控件，等待异步命令完成 |

程序在 `build/workbench/tests/` 下，可传入用例名单独运行（多配置生成器加配置子目录）。推荐用 CTest 按组筛选，例如：

```bash
ctest --test-dir build/workbench --build-config Debug -R '^workspace\.' --output-on-failure
```

CTest 为界面用例注入 `QT_QPA_PLATFORM=offscreen` 与构建目录截图路径。会话测试从源码加载语言资源，界面测试同时验证运行目录资源副本及源码回退。

开发环境为 Linux x86-64、Qt 6.11.2 发行版共享库，使用 GCC／Clang 的 Debug／Release 及 Clang AddressSanitizer＋UndefinedBehaviorSanitizer 构建。[workbench.yml](../../../.github/workflows/workbench.yml) 在 Linux 与 Windows 安装 Qt 6.8.3 并运行测试；跨平台通过情况以 CI 实际运行为准。

## 3. 用例

本节用例前缀为 `session.`，验证不依赖 Qt 的会话行为。

| 关键保证与验证目的 | 用例入口（省略前缀） | 重要边界／设计依据 |
| --- | --- | --- |
| 类型编辑与精确比较 | `adapter_int64`、`comparison_limits` | 四种标量适配器；整数超过 2^53 的显示与曲线区别、非法解析及差值溢出；WB-09、12 |
| 打开、检查与配置修订一致 | `load_and_check`、`config_revision` | 同值不增修订，旧运行不受草稿影响，应用建立新运行；目录含适配与语言信息；WB-08、09 |
| 运行方式不改变轨迹，状态限制有效 | `step_run_stop`、`state_rules`、`limits` | 单步与批量等价，停止后可继续；未设输入自主推进，非法相位与超限请求拒绝；WB-08、10 |
| 分支隔离、干预传播及比较可核对 | `checkpoint_branches`、`branch_order`、`intervention_errors` | 场景 A；交换分支顺序与原运行继续推进不改变分支／检查点；非法目标、类型或分支数拒绝；WB-12 |
| 失败按实际执行范围保留结果 | `partial_branch_failure`、`failure_paths`、`exception_boundaries` | 输入失败不推进，采样失败不抹去推进；分支仅比较共同有效帧；捕获与分支采样异常转诊断并保留原运行；WB-11 |
| 输入记录忠实且重放时序正确 | `record_inputs`、`dual_input_replay`、`partial_input_records` | 输入变化有记录，同帧多输入只推进一次，部分驱动成功不丢失；WB-13 |
| 重放逐帧核对且不修改当前运行 | `replay`、`autonomous_replay` | 不一致定位首个分支／帧／字段，实现缺失被拒绝；无输入及混合驱动均核对全部采样；WB-13 |
| 保存打开按续跑资格分类 | `save_open_round_trip`、`open_rejects_and_falls_back`、`open_exploration_only` | 覆盖 WB-16 的拒绝、只读与接管条件；拒绝保持会话，接受刷新目录 |
| 会话文案按域解析与回退 | `localized_texts` | 无资源或英文语言使用默认模板，中文资源覆盖会话消息 |
| 模块库命令维护一致的可用集合 | `module_packages` | 重复、缺失与无模块库情形给出诊断，卸载更新列表；WB-17 |
| 世界模块贯通会话与状态记录 | `space_module`、`time_module`、`terrain_module` | 空间配置／查询、时钟推进／暂停、地形生成／逐格修改及检查点状态；地形干预分支与重放；WB-17、18 |
| C ABI 载体覆盖与卸载 | `dynamic_module_package` | 动态包覆盖内置工厂并运行；卸载恢复内置登记，活动实例保活；ENV-19、WB-17 |
| 装配草稿与系统文件边界明确 | `system_assembly`、`system_file` | 工厂合并、实现标识、默认配置、观测显式取消及输入推导；未应用规格不影响旧运行；系统文件不含规格，解析失败不改会话；WB-18 |
| 多层作用域可装配与往返 | `nested_system_assembly` | 转接／连接互斥、同一目标重复转接或导出拒绝、规格引用导出、三层接口逐层转接／导出、嵌套运行记录重放、移除级联清理与文件往返、嵌套作用域移除后模块包需求清理；移除后可诊断并修复；WB-18 |
| 项目文件失败不污染会话 | `project_workflow`、`project_errors` | 新建／保存／打开，非空目录、多入口、项目外记录与 I/O 拒绝；写入失败保留原文件；WB-16 |
| 项目包需求与载入集合一致 | `project_module_packages` | 自动载入及保存同步；含无需求项目的坏包／重复包拒绝、版本冲突、暂存后失败不提交、保存失败不留临时需求；WB-16 |
| 运行记录与草稿身份分离 | `project_record_history`、`project_record_lineage` | 重复保存与新运行记录区分，历史快照保留；打开记录不替换草稿，重建核对实现并使用记录规格，跨会话修订号碰撞不误报已应用；WB-16 |

## 4. 工作区状态层用例

本节用例前缀为 `workspace.`，验证 [WB-19](设计.md#wb-19-工作区状态层与面板协议) 的规则可脱离控件执行。

| 关键保证与验证目的 | 用例入口（省略前缀） | 重要边界 |
| --- | --- | --- |
| 身份通知、文件关联与检查报告清理一致 | `identity_notice`、`check_store` | 各身份意图更新对应路径与未保存标记；清检查而保留诊断日志，保存为静默簿记 |
| 控件可用性由状态统一派生 | `busy_controls`、`controls_matrix`、`packages_controls` | 空会话、编辑、运行、检查点与分支的组合；忙碌禁用编辑，空包列表禁用卸载 |
| 结果可用性与页签同步 | `results_availability`、`results_panels` | 新结果打开页签，已打开不抢焦点；手动关闭后可重开；编辑态空轨迹关闭结果页签 |
| 采样与观测更新不引起无关重建 | `samples_append`、`observations_changed` | 增量仅发采样标志，越界序列忽略；观测相同不重复发观测标志 |
| 独立视图持有正确数据并定向通知 | `comparison_stored`、`record_store`、`diagnostics_log` | 比较与记录各自可读，诊断按批次累积并截断到容量，空批次不通知 |

本节用例前缀为 `workbench.`。界面测试通过控件触发命令，核对状态与表格／曲线读数；状态层单测不能替代这些连接路径验证。

| 关键保证与验证目的 | 用例入口（省略前缀） | 重要边界／设计依据 |
| --- | --- | --- |
| 空窗口、打开示例、检查与展示切换正确 | `windowLoadsExample`、`stepAndVariableSwitch` | 空会话无模板残留；目录与规格可读，配置变化标陈旧；切换信号不改变演化；WB-07～09 |
| 停止与大批量推进可操作 | `stopDuringRun`、`runNThroughput` | 只读请求不占用忙碌标记，停止可继续；上限路径、轨迹增量与密集波形绘制；测量条件见实现 |
| 分支实验从界面端到端贯通 | `branchComparisonAndReplay` | 场景 A；干预前后值、差值曲线、非共同帧空值、游标与检查点联动、重放和重建；WB-12、13、15 |
| 失败与关闭保持正确生命周期 | `failedStateControls`、`closeWhileRunning`、`abandonedWorkbench` | 失败后禁用与恢复，运行中关闭等待线程，未启动析构释放资源；WB-10、11 |
| 语言资源与分发路径可用 | `uiTextFallback`、`resourceResolution` | 缺失／损坏资源回退并诊断，运行目录优先、源码回退，副本修改重启生效；WB-14 |
| 菜单与面板入口一致 | `menuBarStructure`、`dockTitleDoubleClick`、`dockFloatDockStress` | 菜单和按钮同源、占位禁用、查看菜单显隐、最后页签保留、浮动／回停反复操作 |
| 项目与记录交互可恢复且失败可定位 | `projectRecordRoundTrip`、`openProjectFailure`、`openProjectPackages` | 保存接管续跑、包载入后列表与页签同步、不可读记录禁用、本次错误展示及会话保留；WB-16 |

## 6. 人工核对与后续范围

已知 Qt 停靠区回归与受影响版本见[实现限制](实现.md#3-当前实现范围与限制)；升级后需复测标签化与浮动分组。打包后的运行尚不在上述自动化范围；完整声明／绑定编辑与依赖图的测试随功能落地建立。
