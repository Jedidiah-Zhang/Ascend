## 2. 实现方案

### 工具与引擎连接

工作台提交模型编辑和运行请求，接收目录、依赖、诊断与结果。模型计算和检查由引擎完成。客户端可维护选择、布局和编辑状态，但不能形成另一份独立的模型语义。

候选接口采用稳定模型标识关联定义、图节点、诊断及运行结果；标识规则、版本信息及来源位置须与引擎共同设计。同进程调用或跨进程服务尚未确定。

### 首版落地顺序

1. 引擎提供最小模型的目录与来源信息后，接入只读浏览。
2. 增加声明及绑定编辑，联通引擎检查、诊断与依赖视图。
3. 接入单机制和小模型试运行，展示结果及执行路径。
4. 干预与输入接口明确后，加入条件对比，核对与无界面运行的一致性。

函数代码优先交由已有编辑器维护，工作台提供定位或跳转。布局、保存及外部修改处理随对应接口细化，不提前实现完整 IDE。
