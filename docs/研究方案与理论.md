# Ascend 研究方案与理论框架

## 1. 研究定位

Ascend 既是一个可交互模拟世界，也是一个用于研究世界模型和具身智能的因果实验平台。平台的核心价值不是让程序世界自动等同于真实世界，而是使研究者能够完整声明世界的状态、生成机制、随机性和干预，并在同一随机实验单位上生成可验证的平行轨迹。

研究的基本问题是：**智能体能否从有限感知和行动历史中形成具有干预泛化能力的世界模型，而不仅仅是在训练观测分布内进行统计预测。**

完整概念、符号和结论边界见[研究综述](研究理论/研究综述.md)。该综述是研究理论的唯一总纲，本篇只保留仓库级入口和执行路线。

## 2. 三个研究阶段

### 2.1 第一阶段：因果世界

第一阶段建立可执行的因果真值。世界声明必须完整定义状态、帧内更新阶段、结构方程、空间父模板、随机地址与合法干预。固定初始状态、随机实验单位、干预和行动后，轨迹必须唯一，实际引擎必须与参考声明逐节点一致。

这一阶段验证的是“声明与实现是否一致”，不是“学习器是否从数据中发现了因果”。具体契约见[世界契约](研究理论/世界契约.md)与[第一阶段实施定义](研究理论/第一阶段实施定义.md)。

### 2.2 第二阶段：反事实与认知

第二阶段限制学习者的信息权限，只向智能体提供自身观测、行动和记忆。研究先判断目标因果查询在给定模型类和数据协议下是否可识别，再评价智能体对未见行动和外部干预的概率预测与配对效应。

通过实验只能说明模型在注册查询族上具有操作性因果能力，不能自动说明其内部恢复了唯一真实因果图。具体方法见[反事实与认知](研究理论/反事实与认知/00-总纲.md)。

### 2.3 第三阶段：多智能体

第三阶段将其他智能体的私有状态、策略响应和联合行动纳入闭环系统。研究分别定义受控直接效应、策略总效应、溢出效应和联合策略效应，再以预注册宏观统计量研究群体结构。

稳定宏观模式必须在明确时间窗口、独立随机种子和零模型下成立，不能仅凭单次长轨迹解释为社会涌现。具体方法见[多智能体](研究理论/多智能体/00-总纲.md)。

## 3. 执行顺序

研究遵循严格依赖：

$$
\text{世界语义闭合}
\Longrightarrow
\text{查询可识别性成立}
\Longrightarrow
\text{单智能体能力可评价}
\Longrightarrow
\text{多智能体效应可分解}.
$$

当前首先完成第一阶段。第二、三阶段文档（[反事实与认知](研究理论/反事实与认知/00-总纲.md)、[多智能体](研究理论/多智能体/00-总纲.md)）为暂定框架，待第一阶段完成后再完善。实现可以从天气或其他最小世界切片开始，不要求一次声明整个游戏世界，但进入研究数据集的每个机制都必须满足相同的状态、随机性、干预和追踪契约。

第一阶段（世界基座）已完成：声明式世界核心（`olam/`）已接管生产——六种声明 + 编译器（C0/C1/C2 静态校验与身份）、帧事务运行时、干预时间线（终端 `do` 指令组 + net 研究 API 同源）、研究记录（逐机制留痕、可重算）与统一验收 runner（C0–C2/W0–W7/I0–I1/L3 全部判据 + 变异探针 + CI 门禁），验收判据全绿。完整存档 W4 双跑逐位一致；天气、地形与世界生成已按声明接入，黄金向量与参考实现逐位对拍通过。观测隔离（W5）以性质级判据覆盖，按协议派生的观测映射层待智能体接入（阶段二）。见[世界架构 00：总纲](研究理论/世界架构/00-总纲.md)。

## 4. 证据层级

本研究区分四类证据：

* 数学证明说明命题在明确假设下成立。
* 声明对拍说明引擎实现符合世界规范。
* 确认性实验说明预注册构造在独立实验单位上满足判据。
* pilot 和信息性探针用于选择参数、发现失效模式和形成后续假设。

数值探针不能替代一般证明，世界真值的存在也不能替代学习协议下的可识别性证明。早期探针的归档与判读状态见 `kheker/historical/`。
