# Ascend

> Ascend 致力于探索人工智能（AI）能否通过与模拟环境交互学习世界运行规律，并计划进一步开发一款以基因改造与族群演化为主题的模拟游戏。

[English](README.en.md) | 中文

## 项目简介

单纯观察到现象之间存在相关性，并不足以判断改变某一条件后会产生何种结果。Ascend 计划构建规则明确、条件可控的模拟环境。研究者可以调整初始条件，或设定智能体（能够感知环境并采取行动的 AI 程序）的行为，并比较相应结果，以评估智能体能否学习环境中的因果关系，而非仅依据既有模式作出预测。

项目的长期目标还包括一款以基因改造与族群演化为主题的模拟游戏。游戏与研究工具面向不同用途；研究者可以使用游戏中的模拟世界，也可以构建专用实验环境。

## 项目结构与研究阶段

项目规划为两条并行发展的方向，共用世界核心能力：

```text
计划中的世界核心
├── 研究方向（三个递进阶段）
│   ├── 第一阶段：构建具有明确因果规律的世界
│   ├── 第二阶段：在世界中引入单个智能体
│   └── 第三阶段：研究多智能体互动
└── 游戏方向：基于世界核心发展玩法与客户端
```

两条方向并非前后阶段。“共用世界核心”指共享世界模拟能力，不代表研究与游戏使用同一个运行实例。研究者也可以接入自建的实验环境，不限于游戏中的世界。

## 项目现状

项目目前处于早期重构阶段。C++ 声明引擎与 Qt 研究工作台已支持小模型装配、运行、检查点干预对照，以及实验保存与重放；世界库已提供空间、基础时钟与单层地形模块。当前可体验范围与限制见[研究平台](docs/研究平台/综述.md)及[世界模拟](docs/世界/综述.md)。

完整的世界模拟、AI 智能体、批量实验管理与研究评价体系，以及可玩的游戏客户端仍未实现。Godot 客户端目前仅包含基础启动场景，尚无实际游戏内容。

## 构建与测试 C++ 原型

需要 CMake 3.20 与 C++17 编译器；界面另需 Qt 6.4 及以上的 Widgets 与 Test。按需选择[引擎](docs/研究平台/实验环境与声明接入/实现.md#4-构建与运行入口)、[世界库](docs/世界/世界框架/空间系统/实现.md#4-构建与运行入口)或[工作台](docs/研究平台/因果建模工作台/实现.md#4-构建与运行入口)的构建命令，在仓库根目录运行；构建选项与资源部署由这些入口维护，验证范围见[测试导航](CONTRIBUTING.md#测试)。

体验工作台：构建后运行 `build/workbench/ascend_workbench`，选择「打开内置示例」，按[实验操作说明](docs/研究平台/因果建模工作台/实现.md#体验一次实验)进行干预比较与重放。自动化界面测试使用离屏平台，手动启动界面需要显示环境。
